# 证明：$(5a)$ 的等价形式、阈值与最小增广

## 0. 记号

$$h=\operatorname{rank}[L;CA;C],\qquad
K=\ker[C;CA],\qquad N=\text{$K$ 的列基},\qquad d=\dim K.$$

$(5a)$ 是 4 块秩等式；$(A)$ 是行包含；核条件是 $\ker[L;CA;C]\subseteq\ker(LA)$。

## 1. T1：$(5a)\iff(A)$

$[LA;L;CA;C]$ 的行空间是

$$\operatorname{row}(LA)+\operatorname{row}(L)+\operatorname{row}(CA)+\operatorname{row}(C),$$

而 $[L;CA;C]$ 的行空间是 $\operatorname{row}(L)+\operatorname{row}(CA)+\operatorname{row}(C)$，后者包含于前者。两者维数相等 $\iff$ 行空间相等 $\iff$

$$\operatorname{row}(LA)\subseteq\operatorname{row}(L,CA,C)=:(A).\qquad\square$$

## 2. 核条件 $\iff(A)$

对有限维空间，$\ker M=(\operatorname{row}M)^\perp$（在标准点积下）。于是

$$\ker[L;CA;C]\subseteq\ker(LA)
\iff (\ker(LA))^\perp\subseteq(\ker[L;CA;C])^\perp
\iff \operatorname{row}(LA)\subseteq\operatorname{row}(L,CA,C).$$

逐元素写法：$\ker[L;CA;C]\subseteq\ker(LA)$ 就是

$$\forall v:\ Lv=0,\ Cv=0,\ CAv=0\ \Longrightarrow\ LAv=0,$$

这正是 $(A)$ 的“三重核”形式。$\square$

## 3. Lean 形式化链

文件：[`lean/ABridge.lean`](../../trash/lean_removed_2026-11-19/proof/5a_archive/lean/ABridge.lean)、[`lean/Factor.lean`](../../trash/lean_removed_2026-11-19/proof/5a_archive/lean/Factor.lean)。

### 3.1 打包映射

```lean
-- Factor.lean
public def tuple (L : V →ₗ[K] W) (C : V →ₗ[K] G) (A : V →ₗ[K] V) :
    V →ₗ[K] W × (G × G) where
  toFun v := (L v, (C v, C (A v)))

-- ABridge.lean
public def big (L : V →ₗ[K] W) (C : V →ₗ[K] G) (A : V →ₗ[K] V) :
    V →ₗ[K] W × (W × (G × G)) :=
  (L.comp A).prod (tuple L C A)
```

$\,\texttt{big}$ 就是 $[LA;L;C;CA]$，$\,\texttt{tuple}$ 就是 $[L;C;CA]$。

### 3.2 秩形式 $\iff$ 核条件

```lean
-- ABridge.lean
public theorem rank_eq_iff_ker_le
    (L : V →ₗ[K] W) (C : V →ₗ[K] G) (A : V →ₗ[K] V) :
    (finrank ↥(big L C A).range = finrank ↥(tuple L C A).range)
      ↔ ((tuple L C A).ker ≤ (L.comp A).ker)
```

证明：`big.ker = (L.comp A).ker ⊓ tuple.ker`（`big_ker`），再用两次秩-零化度；等维包含即相等。

### 3.3 核条件 $\iff$ 分解

```lean
-- Factor.lean
public theorem decomp_iff_ker
    (L : V →ₗ[K] W) (C : V →ₗ[K] G) (A : V →ₗ[K] V) :
    (∃ (Λ : W →ₗ[K] W) (G0 G1 : G →ₗ[K] W),
        L.comp A = Λ.comp L + G0.comp C + G1.comp (C.comp A))
      ↔ ((tuple L C A).ker ≤ (L.comp A).ker)
```

- $(\Rightarrow)$：在三重核上 $Lv=Cv=CAv=0$，故 $LAv=\Lambda Lv+G_0Cv+G_1CAv=0$。
- $(\Leftarrow)$：由 $\ker\texttt{tuple}\le\ker(LA)$，$LA$ 过 $\texttt{tuple}$ 分解；再把 $\Phi$ 按分量拆成 $\Lambda,G_0,G_1$（`exists_comp_eq_of_ker_le`）。

### 3.4 合并

```lean
-- ABridge.lean
public theorem decomp_iff_rank ... :
    (finrank ↥(big L C A).range = finrank ↥(tuple L C A).range)
      ↔ (∃ Λ G0 G1, L.comp A = Λ.comp L + G0.comp C + G1.comp (C.comp A))
```

这就是 `T1 + 核条件 + 分解` 的完整链。

> 并新增 `tuple_apply : tuple L C A v = (L v, (C v, C (A v)))`。这不是数学改动。

## 4. 阈值（T3/T4）

在约化坐标下 $(A)\iff$

$$\operatorname{rank}[W_J(\Theta);B_{A,T};W_J(\Theta)\bar A_T]
=\operatorname{rank}[W_J(\Theta);B_{A,T}].$$

**T3**：

$$\max_{\mathcal S\supseteq E}\dim(\mathcal S+\operatorname{row}B)=\min(d_C,\ k+\dim V),$$

$$\{\operatorname{rank}=d_C\}\ne\emptyset\iff k+\dim(E+\operatorname{row}B_{A,T})\ge d_C.$$

实用充分条件：$2p+q_0\ge n$。

**T4**：秩满 $\Rightarrow(A)$；秩满集是开集；故 $\Omega^\star$ 满测度。

证明思路（[proof/A](../../archive/proof_notes_dimV_line/A_分支A的完整证明.md) 引理 1–3）：

1. 引理 1（泛位置）：$\max_{\mathcal S\supseteq E}\dim(\mathcal S+\operatorname{row}B)=\min(d_C,k+\dim V)$；
2. 引理 2：$\operatorname{rank}[W_J;B]=d_C\Rightarrow(A)$（行空间已满，$W_J\bar A_T$ 的行自动落在其中）；
3. 引理 3：秩满集是开集（所有 $d_C$ 阶子式非零）；
4. 故 $\Omega^\star$ 含非空开集，补集是真 Zariski-闭集，测度零。

## 5. 最小增广 $q_0=\sum_j\eta_j$

这是 **P1 Theorem 2**（源论文）：

$$q_0=\sum_{j=1}^r\eta_j,\qquad \text{要加的行数}=q_0-r=\sum_{j=1}^r(\eta_j-1).$$

- **上界**：`p1` 的链式构造显式给出 $q_0$ 行的 $(A)$-增广；
- **下界**：P1 Theorem 2 的论证（投影/商空间维数）；
- **项目状态**：项目**没有**独立复证这个下界；只有实例级的“$q_0$ 未高估”支持（子式插值、精确枚举），
     以及 `p1` 的构造性上界。FINAL 把这条列为“全项目阈值的核心，却只有一个来源”。

## 6. 候选族 q2：不提供硬度

$(A)$ 只要求 $\operatorname{row}(LA)\subseteq\operatorname{row}(L,C,CA)$，是**线性张成**条件。
即使限定 $R$ 的每一行取自候选族 $\mathcal U$，问题仍是

$$\min\{|\mathcal T|:\ \operatorname{row}(LA)\subseteq\operatorname{row}(L,C,CA)
+\operatorname{span}\{u:\ u\in\mathcal T\}\},$$

即线性拟阵上的最小基/最小张成集，贪心/消元多项式可解。它**不是**集合覆盖/命中集。
所以 q2 不提供 NP-hard 硬度。

## 7. 端点 q3：$d_{CA}=0$

若 $\operatorname{rank}[C;CA]=n$，则 $K=\ker[C;CA]=0$，$N$ 为空，$H=\mathcal LN$ 是 $q_0\times0$ 空矩阵，
$(S)$ 两端都只剩 $\operatorname{rank}[CA;C]$，自动成立。于是

$$\nu_{\min}=q_0,\qquad \text{整个问题多项式}.$$

这是 $(5a)$ 与 $(5b)$ 同时成立的**端点情形**；它说明 $(5b)$ 不是永远难，只是当 $d_{CA}>0$ 时才有内容。
