# 描述与意义：$E=W\oplus J$ 的投影与压缩

## 1. 内容

设 $E=W\oplus J$（即 $W\sqcup J=E$、$W\cap J=0$）。本目录提供：

- $\pi_W:E\to W$（沿 $J$ 的投影）、$\pi_J:E\to J$，且 $x=\pi_Wx+\pi_Jx$；
- 压缩 $T_W=\pi_W\circ A|_W:W\to W$；
- **桥梁**：若 $\psi\in J^{\perp}$，则 $\psi x=\psi(\pi_Wx)$ 且 $\psi(Aw)=\psi(T_Ww)$。

## 2. 为什么需要它

B.2 与 B.5 的 Lean 化都卡在**同一块**：

- B.2 要证 $Q_{\mathcal V}(\lambda)=\begin{pmatrix}-D_W^{\mathsf T}\\ \lambda I-T_W\end{pmatrix}$——需要把 $A$ 按 $W\oplus J$ 分块；
- B.5 要证"$\psi(j_0A)=0$ 且 $\psi|_W$ 是 $T_W$ 的左特征向量"——需要同一个分块。

有了本目录的两条桥梁引理，这两步都变成**代入**：
$\psi(Aw)=\psi(T_Ww)$ 与 $\psi(j_0A)=\psi(\pi_W(j_0A))=\psi(v_W)$。

## 3. 适用域

仅要求 $W,J$ 互补（$\mathrm{IsCompl}\,W\,J$）。与 $A$、$[C;CA]$ 的具体形状无关。
