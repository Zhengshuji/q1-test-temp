# 证明：$(5b)$ 的上界

## 0. 陈述

设 $(5a)$ 成立，$h=\operatorname{rank}[L;CA;C]$。则对一切 $\lambda\in\mathbb C$，

$$\operatorname{rank}[\lambda L-LA;CA;C]\le h.$$

约化形式：若 $F=\Lambda H$，则对一切 $\lambda$，

$$\operatorname{rank}(\lambda H-F)\le \operatorname{rank}H.$$

## 1. 原始 4 块形式

由 $(5a)$ 与秩的“行空间”解释：

$$(5a)\iff \operatorname{row}(LA)\subseteq\operatorname{row}(L,CA,C).$$

证明：$[LA;L;CA;C]$ 的行空间是
$\operatorname{row}(LA)+\operatorname{row}(L)+\operatorname{row}(CA)+\operatorname{row}(C)$，
它包含 $\operatorname{row}(L,CA,C)$；秩相等即行空间相等，故 $\operatorname{row}(LA)\subseteq\operatorname{row}(L,CA,C)$。

于是

$$\operatorname{row}(\lambda L-LA)
\subseteq\operatorname{row}(L)+\operatorname{row}(LA)
\subseteq\operatorname{row}(L,CA,C).$$

而 $[\lambda L-LA;CA;C]$ 的行空间是
$\operatorname{row}(\lambda L-LA)+\operatorname{row}(CA)+\operatorname{row}(C)$，
它落在 $\operatorname{row}(L,CA,C)$ 里，故

$$\operatorname{rank}[\lambda L-LA;CA;C]
\le \dim\operatorname{row}(L,CA,C)=h. \qquad\square$$

**注**：这里只用到 $(5a)$，没有用到任何谱信息；$\lambda$ 任意。

## 2. 约化铅笔形式

$(5a)$ 给出分解（T1 / `ABridge.decomp_iff_rank`）

$$LA=\Lambda L+G_0C+G_1CA.$$

右乘 $N$，并用 $CN=CAN=0$：

$$F=\mathcal LAN=\Lambda\mathcal LN=\Lambda H.$$

于是

$$P(\lambda)=\lambda H-F=\lambda H-\Lambda H=(\lambda I-\Lambda)H.$$

由 $\operatorname{rank}(AB)\le\operatorname{rank}B$（取 $A=\lambda I-\Lambda$、$B=H$）：

$$\operatorname{rank}P(\lambda)\le\operatorname{rank}H. \qquad\square$$

文件：[`lean/MyProof/Theorems/UpperBound.lean`](../../trash/lean_removed_2026-11-19/proof/5b_upper_bound/lean/MyProof/Theorems/UpperBound.lean)（依赖 `Pencil.lean`、`Factor.lean`、`ABridge.lean`，见 [`lean/README.md`](lean/README.md)）。核心定理：

```lean
public theorem pencil_upper_bound
    (Lam : Matrix m m K) (H : Matrix m n K) (lam : K) :
    (lam • H - Lam * H).rank ≤ H.rank := by
  simpa [Matrix.sub_mul, Matrix.smul_mul, Matrix.one_mul] using
    (Matrix.rank_mul_le_right (lam • (1 : Matrix m m K) - Lam) H)

public theorem pencil_upper_bound_mul ... :
    ((lam • (1 : Matrix m m K) - Lam) * H).rank ≤ H.rank :=
  Matrix.rank_mul_le_right _ _
```

线性映射形式：

```lean
public theorem pencil_upper_bound_linear
    (H : V →ₗ[K] W) (Lam : W →ₗ[K] W) (lam : K) :
    finrank ↥(((lam • 1 - Lam).comp H).range) ≤ finrank ↥H.range := by
  rw [LinearMap.range_comp]
  exact Submodule.finrank_map_le _ _
```

原始 4 块形式（用 `QProofFactor.tuple`）：

```lean
public theorem upper_bound_of_decomp
    (L : V →ₗ[K] W) (C : V →ₗ[K] G) (A : V →ₗ[K] V)
    (Lam : W →ₗ[K] W) (G0 G1 : G →ₗ[K] W)
    (hA : L.comp A = Lam.comp L + G0.comp C + G1.comp (C.comp A))
    (lam : K) :
    finrank ↥(tuple (lam • L - L.comp A) C A).range
      ≤ finrank ↥(tuple L C A).range
```

证明用**核包含**：若 $v\in\ker(\mathcal L,\mathcal C,\mathcal CA)$，则由分解
$LA=\Lambda L+G_0C+G_1CA$ 得 $LAv=0$，故 $(\lambda L-LA)v=0$，即
$\ker(\text{旧})\subseteq\ker(\text{新})$；同一定义域上核越大、像维数越小，再用秩-零化度。

**端到端版本**（从抽象 $(5a)$ 的秩等式出发）：

```lean
public theorem upper_bound_of_rank_eq
    (h : finrank (range (big L C A)) = finrank (range (tuple L C A)))
    (lam : K) :
    finrank (range (tuple (lam • L - L.comp A) C A))
      ≤ finrank (range (tuple L C A)) := by
  obtain ⟨Lam, G0, G1, hA⟩ := (QProofFactor.decomp_iff_rank L C A).mp h
  exact upper_bound_of_decomp L C A Lam G0 G1 hA lam
```

这里 `big L C A = (LA, L, C, CA)`、`tuple L C A = (L, C, CA)`；
`ABridge.decomp_iff_rank` 把秩等式翻成分解，再用 `upper_bound_of_decomp`。
所以“从 $(5a)$ 到上界”在**抽象线性映射语言**里是完整的；但具体矩阵
`[λL−LA; CA; C]` 到 `tuple` 的翻译仍未形式化。

## 4. 没有 $(5a)$ 时上界会失败

$$M=\begin{pmatrix}1&0\\0&0\end{pmatrix},\quad F=\begin{pmatrix}0&0\\0&1\end{pmatrix},$$
$$\operatorname{rank}M=1,\qquad \operatorname{rank}(1\cdot M-F)=2>1.$$

原因：不存在 $\Lambda$ 使 $F=\Lambda M$——$\Lambda M$ 的第二列必为零，而 $F$ 的第二列是 $(0,1)^{\mathsf T}$。等价地，$(5a)$ 不成立。所以引用上界时必须连同 $(5a)$ 或 $F=\Lambda H$ 一起引用。
