# 描述与意义：$d=0$ 边界

> 归档位置：`proof/d0_boundary/`。证明见 [02_证明.md](02_证明.md)，验证见 [03_验证.md](03_验证.md)，
> Lean 在 [lean/](lean/README.md)。商等价定理另有目录 [../quotient_equivalence/](../quotient_equivalence/README.md)。

## 1. 命题

设 $d=0$（即 $q=w=n-p$，$Z=0$）。则：

1. $(A)$ **自动成立**（$S=Z\cap V=0$，故 $A(S)=0\subseteq Z$）；
2. $(S)$ 等价于 $\operatorname{rank}\big[(\lambda I-A)V\big]=\dim V$ 对一切 $\lambda$，即
   $$V\cap\ker(\lambda I-A)=0\quad\forall\lambda ;$$
3. 若还要求 $[C;\mathcal L]$ 行满秩且 $\mathcal L$ 含 $L_0$，完整条件是
   $\operatorname{rank}[C;L_0]=p+r_0$ **且** 上式成立。

## 2. 为什么重要

- 它是**"$q=w$ 平凡"这个流传很广的错误的精确替代**：$Z=0$ 只让 $(A)$ 平凡，$(S)$ 仍有内容
  （$A$ 的特征值可以造成秩降）。
- 项目第二个实例（$n=6,p=1$，$Ae_5=e_0$、$Ae_i=e_i$）正是靠它被判定为 **$q_{\min}=\infty$**：
  $e_1..e_4\in V$ 且都是 $\lambda=1$ 的特征向量。
- 它也是 $(A)$ 与 $(S)$ **独立性**的最干净例子：$(A)$ 恒真时 $(S)$ 仍可失败。

## 3. 适用域

| 项 | 内容 |
|---|---|
| 假设 | $d=0$（$q=w$）、$[C;L_0]$ 行满秩 |
| 结论 | $(S)\iff V$ 里没有 $A$ 的特征向量 |
| 不涉及 | $d>0$ 的情形（那要用商等价 + 判据，见 [../quotient_equivalence/](../quotient_equivalence/README.md)）|
