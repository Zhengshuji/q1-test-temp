# 编码规模：多项式比特界（G-2）

**状态**：**[已证-纸面]**（命题 + 证明，本文件）$+$ **[精确验证 12/12]**（[verify_bitsize.py](verify_bitsize.py)，
只覆盖常数，见 §5）。依据：专家 2026-11-02 答复 §4.5 的四项要求。

## 1. 命题

设 $A\in\mathbb Q^{n\times n}$、$C\in\mathbb Q^{p\times n}$、$L_0\in\mathbb Q^{r\times n}$，
每个元素的分子与分母的二进制长度 $\le B$（输入比特数 $O(n^2B)$）。则：

**P1（常数规模）** 下列常数——$\ker C$、$\ker[C;CA]$、$\ker[C;L_0]$ 的有理基的条目、
把 $L_0N_C$ 归一化的 $T$、左逆 $(N_CT)^{+}$、以及商铅笔 $P(\lambda)$ 的系数——的比特长都是
$$O\bigl(n^2(B+\log n)\bigr).$$

**P2（编码规模）** chart-free 编码（本目录 §3）用
$$O(n^3)\ \text{个变量},\qquad O(n^3)\ \text{个方程（含 }\ X(\lambda)P(\lambda)=I_t\ \text{的系数匹配）},\qquad \text{次数}\le n .$$

**P3（表示）** 每个多项式约束都可写成**无除法算术电路**（每门一个辅助变量、方程次数 $\le2$），
电路规模与 P2 同阶；故不必展开成系数向量。

**P4（归约）** 于是 $\mathrm{DEC}(q)$ 到 ETR 是**多项式规模**的归约（输入比特数的多项式）。

## 2. 证明

**(1) 余子式界（Hadamard）** 设 $M$ 是 $k\times k$ 实（有理）矩阵，$|M_{ij}|\le H$。则
$|\det M|\le(\sqrt k\,H)^k$，故 $\det M$ 的比特长 $\le k(B+\tfrac12\log_2 k)+\log_2H$。
对 $n\times n$ 的输入，$H\le2^B$，故 $k=n$ 时 $\le n B+\tfrac n2\log_2 n$。

**(2) 基的条目是余子式之比** 对 $M$ 做**精确**行最简形，主元位置上的解由 Cramer 法则给出：
$x_i=\det M_i/\det M_{\rm piv}$，其中 $M_i$ 是 $M$ 的某个 $\le n$ 阶子矩阵。由 (1)，
分子分母的比特长 $\le O(nB+n\log n)$。这正是 P1 中 $\ker C$、$\ker[C;CA]$、$\ker[C;L_0]$
的基（用 Rational Gauss 消元；**不做**分数free 也不需要）。

**(3) $T$ 与 $(N_CT)^{+}$** $T_1$ 由解 $Bt=e_j$ 给出（$B=L_0N_C$，条目 $\le$ (2) 的界），
故 $T_1$ 的条目仍是余子式之比；$T_2$ 是 $\ker B$ 的基，同理。
$(N_CT)^{+}=\bigl((N_CT)^{\mathsf T}(N_CT)\bigr)^{-1}(N_CT)^{\mathsf T}$：其条目是
**二阶**余子式之比——行列式阶数仍 $\le n$，但输入条目的比特长已为 $O(nB+n\log n)$，故
$$\text{比特长}\ \le\ n\cdot O(nB+n\log n)=O\bigl(n^2(B+\log n)\bigr).$$
这正是 P1。

**(4) 商铅笔的系数** $P(\lambda)=R(\lambda Q_W-A_Q^W)$ 是 (2)(3) 中矩阵的乘积与和，
阶数 $\le n$、每个因子比特长 $\le O(n^2(B+\log n))$ ⟹ 系数比特长同阶（多项式）。$\square$

**(5) P2/P3/P4** 变量与方程的计数已在 §3 的表中给出（$X_0,\dots,X_{t-1}$ 贡献 $t^2q=O(n^3)$）；
每个约束对变量至多二次、对 $\lambda$ 的系数匹配是线性方程；把每个多项式写成电路只需
$O(\text{项数})$ 个辅助变量，项数 $\le$ 变量数的常数倍。归约规模 = 变量数 + 电路规模，
两者都是输入比特的多项式。$\square$

## 3. 与"多项式规模 ⟹ 多项式时间"的界限

专家 §11 明确提醒：**有**多项式规模编码 $\ne$ **有**多项式时间算法（$\exists\mathbb R$ 的判定仍可能很难）。
本命题只补上"归约是多项式规模"这一句，不声称算法。

## 4. 为什么这些常数必须显式给出

ETR 的规模是**以输入比特数为单位**的；若基变换的条目比特长不受控，归约就不是多项式的。
项目此前只写了"有理 Gauss 消元给出有理基，标准精确线性代数界保证比特长多项式"（§3 末），
没有给阶；本文件把阶写成 $O(n^2(B+\log n))$，并按专家 §4.5 分成四项。

## 5. 验证（覆盖范围）
