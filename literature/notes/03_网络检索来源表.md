## 7. 结论：文献检索对本证明的支撑

### (a) 本命题的 NP-hardness 在文献中是否出现过？

**结论：没有找到任何文献陈述本命题（"求行数最小的 R 使 [L₀;R] 满足 (5a)(5b) 是 NP-hard"）。该命题目前看是新的/开放的。**

检索证据：
1. **原始三篇文献（S01–S03）的摘要中没有任何计算复杂度结论**。S02 只说"the complete family of augmentations attaining this dimension is determined"（族被刻画出来），S03 只说阶谱端点与逐阶刻画——**都是"刻画"，不是"复杂度"**。
2. 检索关键词组合 `functional observer complexity`、`functional observer minimum order NP-hard`、`minimum order observer design complexity`、`minimum number of additional linear functionals`、`minimum augmentation functional observer combinatorial` **均未返回任何直接命中**。
3. **最接近的已发表结果是 S20（Zhang–Fernando–Darouach, IEEE TAC 2025）**：它证明的是"**从先验集合中选择最小传感器**以实现功能可观性与 SFO"是 NP-hard。**决策变量是 $C$（传感器/输出）而不是 $\mathcal L$（增广功能行）**。在 Fernando 的框架中两者通过 S02 的增广族参数化耦合，因此本命题是 **S20 的对偶版本（augmentation 侧）**，**不能**由 S20 直接推出。
4. 其他邻域硬度结果（S17、S18、S19）都是"传感器/输入选择"侧，**没有一条**涉及"功能观测器阶数 / 增广功能行的最小基数"。

**因此，证明文档在"贡献声明"中应当明确写：** 本命题在文献中是**新的**；已知的邻近硬度结果（S20）处理的是对偶问题；这既提高了贡献度，也要求证明**不得**依赖"文献已证"来蒙混。

### (b) 最佳归约起点（推荐）

**首选：Set Cover / Hitting Set（S07、S08、S09；Karp 1972）。**

理由：
1. **(5a) 天然是覆盖型约束。** (A) 的等价形式是 $\mathrm{row}(\mathcal LA)\subseteq \mathrm{row}(\mathcal L,C,CA)$——"用选出的行去**吸收/覆盖**一组目标方向"。集合覆盖的整数规划形式正是"用选出的列去**覆盖**每一行"，即 $Ax\ge 1$（S07 已核对原文给出此形式）。二者的"选择–覆盖"结构同型。
2. **S02/S03 表明可行解集合是离散组合族**（$\binom{s}{k}$ 个子集 $J$ 的选择，$s=n-p-r$、$k=q_0-r$）。这与 Set Cover 的解空间（$\mathcal S$ 的子族）是同一种离散选择，归约不需要把硬度藏进连续参数。
3. **同领域的成功先例都用这类归约。** S15（Olshevsky）的 $c\log n$ 不可近似性搬运自 Set Cover 的 Feige 下界；S20 对 minimal sensor placement 的 NP-hardness 同样走组合覆盖路线。沿用同一路线可让审稿人**立即认可**归约的合理性。
4. **免费获得不可近似性。** 以 Set Cover 为起点可顺带得到 $O(\log n)$ 级不可近似下界（S07 的 Feige 1998 $(1-o(1))\ln n$），使结论强于单纯 NP-hard。
5. **S16（minCIS）提供了可直接照搬的证明骨架**：先证判定版 ∈ NP（证书 = 所选子集；验证 (5a) 是多项式时间秩计算，验证 (5b) 需说明可在有限个 λ 或 gcd 条件上多项式验证），再由 Set Cover 归约证 NP-hard。

**次选（用于加强，而非主证）：**
- **S11（Natarajan 1995, ℓ₀ 最小化）** —— 若只想证"**仅 (5a) 已 NP-hard**"，可用"最小基数子集满足线性约束 / 稀疏近似"这一族。风险：需要自己补上"ℓ₀ NP-hard"的原始证明引用（本表未直接抓到该论文正文，见 §8）。
- **S12（Vardy 1997, 最小距离 NP-hard）** —— 用于回应"线性/秩条件应当好算"的质疑，属**辩护性引用**而非归约起点。

**必须避免的路线（重要警示）：**
- **不要**把 (S) 侧的连续参数 Θ 纳入 NP-hardness 的归约核心。S14/S29 显示：实多项式系统存在性的自然归属是 **∃ℝ（介于 NP 与 PSPACE 之间）**，而不是 NP。若归约中"可行性"必须靠求解连续 Θ 才能判定，结论会退化为 ∃ℝ-hardness，**不是** NP-hardness。正确做法（与 CLAUDE.md §5 一致）：**把组合选择放在"候选增广行族本身"**（S02 Theorem 3 / S03 的参数化），让硬度来自"从离散候选族中挑最小子集"，(S) 只作为**同一子集还需满足的额外谱条件**（使问题只会更难，且可显式构造满足 (S) 的实例）。
- **不要**声称这是 matroid 最小基问题。S13 已核对："任何两个基的元素个数相同，该数称为秩"，故 matroid 最小基无优化内容；本问题的可行族大小**不固定**。(应主动引用 S13 排除该误判。)
