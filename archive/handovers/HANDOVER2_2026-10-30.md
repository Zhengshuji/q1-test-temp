## 2. 我对项目的理解（请校验这一段）

### 2.1 问题与框架

给定 $(A,C,L_0)$，求最小行数 $q$ 的 $\mathcal L=[L_0;R]$ 使
$(5a)\ \operatorname{rank}[\mathcal LA;\mathcal L;CA;C]=\operatorname{rank}[\mathcal L;CA;C]$、
$(5b)$ 对**所有** $\lambda$ 同式成立。记 $\mathcal J=\operatorname{row}[C;CA]$、$j=|\mathcal J|$、$X=\mathbb C^n/\mathcal J$、
$B=\pi(\mathcal JA)$、$d=\dim X$；$\mathcal V=\operatorname{row}\mathcal L$、$\rho=\dim\pi(\mathcal V)$、$c=\dim(\mathcal V\cap\mathcal J)$，
则 $q=\rho+c$。

**我的理解**：
- $(5a)\iff\pi(\mathcal VA)\subseteq\pi(\mathcal V)$（docs/02 A.0，[已证]）；它**不是**"$\mathcal U=\pi(\mathcal V)$ 条件不变"就够——那只是单向，差一个 $B$；
- $(5b)\iff\lambda\pi(\mathcal L)-\pi(\mathcal LA)$ 在 $X$ 上**对所有 $\lambda$ 满秩 $\rho$**（B.1）；
- 于是 $q_{\min}=\min\{\rho+c:\ \exists\mathcal V\ \text{满足上述两条}\}$，而 $\rho$ 一侧的**算术下界** $\rho_{ci}=P(T,B,U_0)$ 已经多项式可算（$P$ 的递归定理 + $O(n^4)$ + Lean）。

### 2.2 层的参数化

固定 $(\rho,c)$ 后："层可行"$=\exists\,\mathcal V$（$\dim=\rho+c$、$\operatorname{row}L_0\subseteq\mathcal V$、类型 $(\rho,c)$、$(5a)$、$(5b)$）。
把 $\mathcal V$ 拆成 $(\mathcal U=\pi(\mathcal V),\ \mathcal H=\mathcal V\cap\mathcal J,\ \text{提升})$：
$\mathcal U$ 是 $X$ 的 $\rho$ 维子空间，$\mathcal H$ 是 $\mathcal J$ 的 $c$ 维子空间，提升 = 选截面。

**我的理解**：给定 $(\mathcal U,\mathcal H)$ 与截面 $s$，$\mathcal V=s(\mathcal U)\oplus\mathcal H$。
所以一个"格子"= $(\mathcal U,\mathcal H)$（+ 隐含的截面），而"层"= 全部格子。
**"格子被覆盖"= 对**该格子的所有**提升（即所有 $\mathcal V$）都使 $(5b)$ 失败**——注意这是**闭**条件。

### 2.3 三分

| 类 | 我的归纳 |
|---|---|
| 站得住 | $P\in\mathbf P$、下界 A.3、顶层 $\rho=d$ 的可观测判据、$\rho=0$ 层、$(3,1)$ 的**格子级** C.1–C.5、T11（$\tau$ 量词消除）、$d=4$ 的结构分类 |
| 已推翻 | 四个闭式 R1–R4、拟阵/TAP、$(5b)\iff$ 可控（Q5）、S1 充要判据、专家二分猜想（R12）|
| 开放 | $q1$；层的 $\exists(\mathcal U,\mathcal H)$（Grassmannian）判定；$d=4$ 的谱步（$\dim\Phi\ge2$）；EDCI；域与复杂度类的对齐 |

### 2.4 我认为的"结"在哪里

$q1$ 现在被精确成：**"$\mathrm{Bad}$（被覆盖的格子集）是投影时，$\mathcal A\subseteq\mathrm{Bad}$ 能否多项式判定"**。
$k=2$ 时坏集是仿射的（$W_0$ 唯一）⟹ 线性代数；$k\ge3$ 时是投影 ⟹ $\forall\exists$ 型。

## 3. **实质问题：§82 的证书脚本是坏的（结论仍对）**

### 3.1 现象

`python proof/layer_program/verify_counterexample_certificate.py` 打印
`非零的 6 阶子式个数 = 0 / 28`，并据此宣布"全部子式恒为零 ⟹ 对所有提升、所有 λ 秩降 ⟹ 层不可行"。
STATUS §12.1b、HANDOVER §3、proof/refuted R12 都引用了它。

### 3.2 根因（两处）

1. **第 61 行的 `% 1`**：
   ```python
   return [sum(a[i] * Lmat[i][t] for i in range(n)) % 1 for t in range(n)]
   ```
   `lift(e_1)` 的坐标是 $(1,0,0,0,0,0)$；`1 % 1 = 0`。于是 `lift` 把**每个** $e_i$ 都打到**零向量**。
   脚本里的 "V" 实际是 $\operatorname{span}\{a_i\tau_0\}$，**秩 1**，28 个 6 阶子式当然全为零。
2. **第 103 行的 `r0`** 是 `rank(J+K) and n`，打印出来永远是 `n`（=6），**不是**真的算
   $\operatorname{rank}[V;C_0A;C_0]$。所以"r0 = 6（应 = 6）"这一行也不构成检查。

### 3.3 实证

`verify_handover2_checks.py` 的 (B)(C) 段：

```
buggy lift(e_1) = 0            => rank(V) = 1  => 28 个子式平凡为零
fixed lift(e_1) = (1,0,0,0,0,0) => rank(V) = 4  => λ=1 处 rank = 6 = r0
                                => 至少一个子式非零 => "全部子式恒为零" 不成立
```

### 3.4 但结论是对的，而且**不需要** 28 个子式

$$\operatorname{rank}(A)=2\ \Longrightarrow\ \dim\pi(\mathbb C^nA)=1\le\rho-1=2 .$$
对**任意** 4 行的 $\mathcal L$（不需要类型假设），
$$\operatorname{rank}[-\mathcal LA;\ CA;\ C]\ \le\ \dim\mathcal J+\dim\pi(\mathbb C^nA)\ =\ 3+1\ =\ 4\ <\ 6 ,$$
而类型 $(3,1)$ 给 $\operatorname{rank}[\mathcal L;CA;C]=\dim(\mathcal V+\mathcal J)=4+3-1=6$。
故 $(\mathrm{5b})$ 在 $\lambda=0$ 处失败 ⟹ **整个层不可行** ✓（200/200 随机格子复核一致）。

**这就是 §80 的机制**（$\operatorname{rank}f\le\rho-1$ ⟹ $w\in\operatorname{row}T$ ⟹ 在 $\lambda=0$ 处秩降），
只是套在 $A$ 整体低秩上，与 $\mathcal U$、截面、$\tau$ **全都无关**。

$$\boxed{\ \text{建议：把 §82 的证书改成上面 3 行证明；28 个子式的符号计算可以整个删掉}\ }$$

### 3.5 顺带：§82.2 的"全部提升"参数化也值得复核

$\mathcal V$ 的行写成分 $s(u_i)+a_i\tau_0$ 时（只要某个 $a_i\ne0$），
$$\operatorname{span}\{s(u_i)+a_i\tau_0\}=\operatorname{span}\{s(u_i)\}+\langle\tau_0\rangle$$
**与 $a_i$ 无关**——$a_i$ 只改变 $\mathcal L$ 的**行基**，不改变 $\mathcal V$。
而 $(5b)$ 在行基变换下不变 ⟹ 这 4 个参数**不产生新的 $\mathcal V$**。
真正的自由度是**截面** $s$（$\mathcal V=s(\mathcal U)\oplus\mathcal H$，$s$ 遍历所有截面）。
§82.2 的"$\ker\beta$ 方向"论证覆盖的是**直线的变化**，不是截面的变化。
（不过因为 §3.4 的一行证明与 $\mathcal V$ 无关，这一点不影响结论。）
