## 1. 本轮完成：D-5 的第一块

### 1.1 新增定理

`tools/lean/MyProof/A3sem.lean` 末尾：

```lean
theorem finrank_map_mkQ_add (A : W →ₗ[K] W) (S G : Submodule K W) :
    Module.finrank K ↥(Submodule.map (Submodule.mkQ G) (Submodule.map A S))
        + Module.finrank K ↥G
      = Module.finrank K ↥(Submodule.map A S ⊔ G)
```

### 1.2 它是什么

$$\dim\phi(S)=\dim\operatorname{map}(\mathrm{mkQ}\,G)\big(A(S)\big)=\dim\big(A(S)+G\big)-\dim G$$

即 **$\ell$ 的语义形式**：把纸面上"$\phi(S)$ 是 $(A(S)+G)/G$"这一步，落成**维数恒等式**。

### 1.3 为什么重要

- 纸面证明里 $\ell$ 的定义依赖"第二同构" $(A(S)+G)/G$；
- 之前试图构造 `LinearEquiv` 卡在 Mathlib 的 API（`quotQuotEquivQuotOfLe` 不存在）；
- 本定理**绕开等价构造**，只用秩-零化度 + 维数公式 `Submodule.finrank_sup_add_finrank_inf_eq` ✓

### 1.4 证明要点

```
h1 := finrank_map_mkQ (A(S)) G        -- dim(map) = dim A(S) - dim(A(S) ⊓ G)
h3 := finrank_sup_add_finrank_inf_eq  -- dim(A(S)⊔G) + dim(⊓) = dim A(S) + dim G
hle, hle2                             -- dim(⊓) ≤ 两边
omega
```

随后我的批量修补脚本**把文件弄坏了**，只能 `git checkout` 回滚 —— 所以本轮只保留了已验证的那一条引理。
