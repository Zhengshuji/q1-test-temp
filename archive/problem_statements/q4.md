## ① 命题本身的详细准确描述

### 设定

LTI 系统 $(A,C,L_0)$ 满足 H1–H4。记

| 记号 | 含义 |
|---|---|
| $q_0=\sum_j\eta_j$ | **最小 (A)-增广行数**（P1 Theorem 2）——即"只看 (5a)"时的最小值 |
| $\nu_{\min}$ | 使 **(5a) 与 (5b) 同时**满足的最小行数 |
| $d_C=n-p$，$s=d_C-r$，$k=q_0-r$ | 基本维度 |
| $\boldsymbol{d_{CA}=n-\operatorname{rank}[C;CA]=\dim\ker[C;CA]}$ | **本命题的核心分水岭量** |

### 判定问题

q4:   给定 (A,C,L_0) (满足 H1–H4), 判定 ν_min =q_0 是否成立?

（注意：这是**判定**，不是求最小行数；求最小行数可由逐阶判定得到。）

### 原始阈值分解（**含一处已被推翻的断言**）

精确阈值： k+dim (E+row(B_A,T))  ≥  d_C
   实用充分条件： 2p+q_0  ≥  n

| 支 | 条件 | **原陈述** |
|---|---|---|
| **支 A** | $2p+q_0\ge n$ | ⟹ $\Sigma_{q_0}$ **满测度或空** ⟹ 单点随机检验可判 ⟹ **BPP** ⟹ q1 在此范围内为假 |
| **支 B** | $2p+q_0<n$ | ⟹ 可行集是**有限个孤立点**（零测，采样命中率恒 0）⟹ 须精确求出全部候选点 ⟹ **未决** |

> ⚠️ **支 A 的原陈述已被推翻**，理由见 §3.2。正确形式见 §3.3。

q4 是把 q1 **按阈值劈成两支**后的命题——它针对的**就是原始命题的复杂度问题**。

q1 xrightarrow 按阈值分解  q4  支 A (2p+q_0 ≥  n)[2pt]支 B (2p+q_0<n)

把目标实例造成哪一支/哪一情形：

若情形 II 难  ⟹  q1 难   (反之不成立)

## ③ 已完成的工作

### 3.1 已严格证明的（**与 $\Theta$ 无关，是最干净的部分**）

| 结论 | 陈述 |
|---|---|
| **精确阈值** | $\{\operatorname{rank}[W_J;B_{A,T}]=d_C\}\ne\emptyset\iff k+\dim(E+\operatorname{row}B_{A,T})\ge d_C$（引理 1 泛位置 + 推论 1.1） |
| **秩满 $\Rightarrow$ (A)** | 且秩满集是**开集** ⟹ $\Omega^\star$ **满测度**（不需要 $\Omega^\star$ 闭——旧引理 4 是假的） |
| **(S) 的谱刻画** | $(\text{S})\iff\operatorname{im}H$ 不含 $\Lambda$ 的特征向量；且 $F=\Lambda H$ |

### 3.2 ⚠️ 支 A 的原陈述**为什么被推翻**

原陈述依赖三条，**三条都假**：

| 依赖 | 错在哪 |
|---|---|
| **引理 4**：$(\text{A})$ 的可行集是 Zariski-**闭**集 | **假**。反例 $M=(a),N=(b)$；错因：$(Z,M)\mapsto(M,ZM)$ 是**双线性**而非线性 |
| **引理 5**：$(\text{S})$ 的可行集是 Zariski-**开**集 | **假**（$d_{CA}\ge q_0$ 时） |
| **定理 6**："$\Sigma_{q_0}$ **满测度或空**" | **假**——存在**第三种情况：非空且零测** |

**显式反例**（决定性）：

n=5, p=1, r=2, q_0=3   ⟹   d_CA=3=q_0,   2p+q_0=5 ≥ 5=n (在支 A 内)

| 观察 | 数据 |
|---|---|
| 一般点：$(\text{A})$ | **40/40** |
| 一般点：$(\text{A})∧(\text{S})$ | **0/40** ⟹ $(\text{S})$ 零测 |
| 退化点（$\operatorname{rank}H<q_0$）：$(\text{A})∧(\text{S})$ | **成立**（6/6 实例找到见证） |

⟹   Σ_q_0 非空且零测   ⟹   "满测度或空"的二分被直接证伪

**后果**：支 A 的"单点随机检验 ⟹ BPP"论证在 $d_{CA}\ge q_0$ 时**必然失效** ✗；
"q1 在支 A 内不是 NP-hard"是**过度断言** ✗。

### 3.3 ✅ 正确形式：按 $d_{CA}$ 与 $q_0$ 分三情形

| 情形 | 条件 | 结论 | 状态 |
|---|---|---|---|
| **I₁** | $d_{CA}=1$ | 判定 ∈ **BPP** | ✅ **完全证明**（两种独立证明） |
| **I₂** | $2\le d_{CA}<q_0$ | **无条件二分**：(a) $\Sigma_{q_0}$ 含非空开集 ⟹ BPP；或 (b) $\Sigma_{q_0}\subseteq\{\operatorname{rank}H<\beta_{\max}\}$（真闭代数集，零测）⟹ 采样失败 | ✅ **二分本身已证**；⚠️ **落哪一支未定**（$(\star''')$） |
| **II** | $d_{CA}\ge q_0$ | $\Sigma^{(S)}\subseteq\{\operatorname{rank}H<q_0\}$（真闭，**零测**）⟹ 采样必失败 | ✅ **已证**；❌ **但这不是复杂度结论**（不排除别的 BPP 算法） |

**三情形的直观**：$\dim\operatorname{im}H\le\min(q_0,d_{CA})$。
$d_{CA}<q_0$ 时 $\operatorname{im}H$ 是**真子空间**，一般避开有限条特征方向 ⟹ (S) 易成立；
$d_{CA}\ge q_0$ 时一般 $\operatorname{im}H=\mathbb C^{q_0}$，含**全部**特征向量 ⟹ (S) 必失败。

### 3.4 支 B 的已知结构

| 结果 | 内容 |
|---|---|
| 解集形状 | **有限个孤立点**（零测，随机采样命中率恒 0） |
| **精确解数** | $(1,3)$：**恰好 2**（与已知结果校准 **4/4** 一致）；$(1,4)$：**2–3**，≪ Bézout 界 8 |
| 推论 | 解数**不随规模增长** ⟹ **不像硬度来源** |
| 未证 | 一般 $(k,s)$ 的**多项式上界** |

### 3.5 情形 II 的答案**可以为 YES**（重要）

情形 II 的判定是 $\exists\Theta:(\text{A})\wedge(\text{S})\wedge\operatorname{rank}H<q_0$。
它**不是**平凡的"恒 NO"——实测 **6/6 例**找到了见证（在退化点上 $(\text{S})$ 可以成立）。

⟹   情形 II 的判定 = 一个量词自由的实代数存在性问题 (ETR 型)

（ETR 本身是 NP-hard ⟹ 此处**不能排除** NP-hard。）

### 3.6 🔴 范围限定（必须与 §3.3 一并引用）

rank(R N_C K)=k,   K=ker (L_0N_C) 的基

P1 的 $W_J$ 底部块 $[I_k|\Theta]$ 恒为秩 $k$，**只能表示"商空间中 $k$ 行独立"的增广**。
存在图卡外的实例（$L_0=CA^m$ 造出，$n{=}5,p{=}1,r{=}1,\eta=[3],q_0=3,k=2$，$\operatorname{rank}(RN_CK)=1$）。

⟹   §3.3 的三情形结论仅在图卡内成立

## ⑤ 验证方法（其他 agent 如何独立复核）

### 5.1 一键复现三情形

```bash
python scripts/core/reliable_S_test.py
```

**期望输出**（每行形如）：

```
 n  p  r  q0 | d_CA d_CA>=q0 |   (A)命中  (A)∧(S) |  扰动保持 | rankH=[…] full=… | A2: …
 6  2  2   3 |    2    False |  40/40    40/40   |  12/12   | rankH=[2] full=40/40 | A2: 40/40 rawT=40 redT=40
 5  1  2   3 |    3     True |  40/40     0/40   |   0/0    | rankH=[3] full=40/40 | A2: 40/40 rawT=40 redT=40
```

**判读**：
- `d_CA>=q0 = False` ⟹ $(A)∧(S)$ 应 **100%**；`True` ⟹ 应 **0/40**
- `A2: n/n` 中 `rawT` 与 `redT` 必须**相等**（三块约化 ≡ 原始 4 块 (A)）
- `rankH=[d_CA] full=cnt_A` ⟹ 所有 $(A)$-点的 rank H 都等于 $d_{CA}$

### 5.2 复现"支 A 原陈述被推翻"的反例

用 `reliable_S_test.py` 输出中 `d_CA>=q0 = True` 的行：
一般点 $(A)∧(S)$ = **0/40** ⟹ (S) 零测；再用
`python scripts/core/test_caseII_YES.py` 复现"退化点上 (S) 成立"（YES 6/6）。

### 5.3 复现支 B 解数

```bash
python scripts/core/exact_count_14_elim.py
```
期望：$(1,3)$ 列全为 **2**（校准通过与已知结果一致）；$(1,4)$ 列在 **{2,3}**。

### 5.4 验证铁律（血的教训）

1. **等价性检验必含至少一个 True 点**（否则"一致"可能只是"两边都 False"）；
2. **不可用"优化器没找到"当"不存在"**；
3. **拼接矩阵前先查维度**（曾因 ragged list 让秩计算"成功"于错误的列）；
4. **不要用旧 `condS` 判据**——已证明不可靠；(S) 必须用 $\rho$ 阶子式 gcd 判据。
