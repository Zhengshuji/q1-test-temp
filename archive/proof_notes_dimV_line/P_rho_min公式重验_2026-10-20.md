# P — $\rho_{\min}$ 公式的独立重验（2026-10-20）

> 项目在 `history/52` §7.114.0 给出公式
> $$\rho_{\min}=\min_{0\ne r\in\operatorname{row}(R_0)}\dim\Phi^\infty\big(\operatorname{span}\{\alpha_0,r\}\big)
> \quad\text{s.t. } \Lambda_{\mathcal A}\ \text{不良定义},$$
> 但 `c136` 的实现给出 **0/560**，被判为"可能构造 bug（第 68 处）"，**此后一直未重验**。
>
> 本文用**独立实现**（本轮的 `try_A` + 原始 (5a)/(5b) 复核）重做，结论：**公式通过**。

---

## 1. 做法

[`../scripts/core/c154_verify_rho_min_formula.py`](../scripts/core/c154_verify_rho_min_formula.py)：

1. 枚举 $r$（$\operatorname{row}(R_0)$ 的基的小系数组合，$\{-2,\dots,2\}$）；
2. $\mathcal A_r=\Phi^\infty(\operatorname{span}\{\alpha_0,r\})$（对 $A'$ 取闭包）；
3. 判 $\Lambda_{\mathcal A}$ 是否不良定义：$N_{\mathcal A}=\{\ell:\ell N=0,\ \ell AN\in\mathcal A\}\ne0$；
4. 对合格者，用 $q=\dim\mathcal A_r+1$ 做 lift（线性约束 + 取样 + **原始 (5a)/(5b)** 复核）。

## 3. 结论

$$\boxed{\ \textbf{公式本身未受损害};\quad \texttt{c136}\ \text{的 }0/560\ \text{确认为\textbf{实现 bug}（与项目第 68 处的猜测一致）}}$$

* 公式能命中 $\rho=2$ 的原因：取 $r=L_0R_0\in S$ 时，
  $$\beta_0=\alpha_0A'+L_0R_0\ \in\ \overline{\operatorname{span}\{\alpha_0,r\}}_{A'}=\mathcal A_r$$
  故 $\mathcal A_r\supseteq\operatorname{span}\{\alpha_0,\beta_0\}$——**不会被"平面被强制"的情形漏掉**。
* 因此项目把 `c136` 的 0/560 判为 bug 是**对的**；本轮的独立实现补上了那次缺失的验证。

## 6. 证明尝试（$d=2$）：一条已确认的**必要条件**

设 $v$ 张成 $\ker(M^{\mathsf T})$（$M$ 为 $q\times d$、$\mathrm{rank}=\rho$，故 $\dim\ker(M^{\mathsf T})=q-\rho$）。
对 $\lambda M-F$ 有

$$v(\lambda M-F)=\lambda\,vM-vF=-vG\qquad(\text{因 }vM=0,\ F=MA'+G,\ vMA'=0).$$

$$\Longrightarrow\ vG\ne0\ \text{时，}v\ \text{不再是铅笔的左零向量}$$

**数值真值表**（$d=2$，$q=3$，全部通过 (5a) 的样本 883 个）：

| $vG\ne0$ | $(b)$ | 计数 |
|---|---|---|
| ✗ | ✗ | 142 |
| ✓ | ✗ | 147 |
| ✓ | ✓ | **594** |
| ✗ | ✓ | **0** |

$$\boxed{\ (b)\ \Longrightarrow\ vG\ne0\qquad(\textbf{必要}，883\ \text{例 0 反例})}$$

$$\textbf{但不充分}：147\ \text{例 }vG\ne0\ \text{而}\ (b)\ \text{假}\ ✗$$

> **为什么只是必要**：$vG\ne0$ 只排除了"$v$ 在整个铅笔上都是左零向量"，而 $(b)$ 要的是
> $\operatorname{rank}(\lambda M-F)=\rho$ **在每个 $\lambda$**，这比"没有多余的左零向量"更强
> （还需要 $\rho\times\rho$ 子式无公共零点）。我最初把两者当成等价，是**错的**——已在 [proof/H](H_卡点定位_2026-10-20.md)
> 的教训清单里记着同一类错误（$\operatorname{rank}(XM)$ 不能随意化简）。

$$\textbf{状态}：\rho_{\min}\ \text{公式的证明仍缺};\quad \text{本条只是证明路上的一块（必要条件）}$$
