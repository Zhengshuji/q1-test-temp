## 写作原则（来自专家答复与项目规范）

1. **不自称功能可观测性/设计秩条件**——那是文献的；本 note 只写阶选择的两个机制；
2. 每个编号结论必须带**证明 + 证书**；`⟨TODO⟩` 标出未写完处；
3. **不能说"$q+r_1=n$ 就推出 $h=n$"**——正确形式是 Corollary A2（含 $V'\cap S=0$ 假设），
   在 §3 里要显式写这条更正；
4. 边界统计只作 exploratory evidence；
5. 复杂度**不作声称**（现状：无受限类困难结果；相邻但不同的问题已知 NP-hard）。
