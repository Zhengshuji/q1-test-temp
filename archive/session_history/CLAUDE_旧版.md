## 0.1 用户提出的关键观察（当前最重要的方向）

> **论文的方法不保证 q0 阶满足要求。在 q0 下搜索不一定能找到可行的 R；
> 需要进行"扩维"。这主要是 P2《Complete Characterization of Minimum-Order
> Functional Observers from Darouach to Luenberger》的内容。**

**含义**：

1. q0 = Σ_j η_j 只是 **(5a) 的最小行数**，它**不保证** (5b) 也成立；
2. 因此正确的问题不是"在 q0 处找 R"，而是
   **"在阶谱 [q0, n0−p] 中找最小的谱可行阶"**；
3. 这正是 P2 的主题（`data/p2.txt` 约 59–62 行）：
   > "if every algebraically admissible realization at order q0 fails the spectral
   > condition, at which subsequent orders can a functional observer exist?"

**证据**：
- P2 算例：r=2 < q0=3 < ν_min=5 < n0−p=6（必须扩到 5 阶）；
- 本项目小规模复现：n=3 的 5 个实例，q0=1 处 (A)∧(S) 命中 0/10，d=2 处 10/10。

**因此命题 q 的完整形式应为**：

> 给定满足 H1–H4 的 (A, C, L0)，判定各阶 q ∈ [q0, n0−p] 的谱可行性，
> **求最小的谱可行阶 ν_min**。问此问题是否 NP-hard？

（`problems/q_simp.md` 给出了单阶版本 MFOSP 的精确形式化。）

## 2. 问题的精确数学形式

系统：(1a) ẋ = Ax + Bu，(1b) y = Cx，(1c) z₀ = L₀x。
观测器 (2a)(2b)：ẇ = Nw + Jy + Hu，ẑ = w + Ey，阶数 = rows(L)。

### 原始形式（P3 Theorem 2）

> ⚠️ **重要更正**：最初把 (5a) 写成 3 行块。经 `pdftotext -bbox` 坐标级重建确认，
> **Condition 1 左端是 4 块 `[LA; L; CA; C]`**，右端 3 块 `[L; CA; C]`。
> 这与 P1 Corollary 1（`data/p1.txt:1147`）逐字一致，P1 称其
> "precisely the Darouach observer-existence conditions"。
> 解析脚本：`scripts/core/bbox_parse2.py`。

```
(5a)  rank[LA; L; CA; C] = rank[L; CA; C]

(5b)  rank[sL − LA; CA; C] = rank[CA; C; L],   ∀s ∈ ℂ  (或 ℜ(s) ≥ 0)
```

### 现代形式（P1 的 (A)(S)）—— 证明用它

```
(A)  rank[LA; L; CA; C] = rank[L; CA; C]   ⟺   row(LA) ⊆ row(L, C, CA)

(S)  rank[λL − LA; CA; C] = rank[L; CA; C],  ∀λ ∈ ℂ
```

**关键观察**：
- (5a) ⇔ (A)：4 块版本下二者**严格等价**（引理 1，已证 + 600/600 数值确认）。
- (5b) ⇔ (S)：λ 版本，只是符号重参数化。
- **(S) 与 (A) 互不蕴含**（已更正；1200 例中仅 (S) 成立 433、仅 (A) 成立 85）。
  ⇒ "ν_min ≥ q0" 的依据是 P1 的**阶谱** ν_min ∈ [q0, n0−p]，不是 (S)⇒(A)。

### 优化问题

> **Q**：给定 (A, C, L₀)，求行数最小的 R，使 L := [L₀; R] 满足 (A) 与 (S)。
> 约束 row(L₀) ⊆ row(L) 保证 L₀ 的每一行都必须保留。

## 3. 已掌握的结构定理（武器库）

| 结论 | 内容 | 用途 |
|---|---|---|
| 有序秩保留构造 (P1 §III) | 生成元 g1..g_{p+r} = C 的行 ∪ L0 的行；按"幂次优先、同幂按序号"逐行秩保留，得 M | 构造候选行 |
| 功能可观性指数 | α_i = 1 + max{k : g_i A^k ∈ rows(M)}；η_j := α_{p+j} | **核心不变量** |
| Lemma 1（依赖性持续） | 若 g_i A^q 被拒，则 g_i A^{q+ℓ} 全被拒 | 使构造有限（≤ n 步） |
| Theorem 1 | 构造出的 L 满足 (A) | 上界构造 |
| **Theorem 2（最小增广维数）** | **q0 = Σ_j η_j**，最少需补 Σ(η_j − 1) 行 | **最小行数的解析公式** |
| 非唯一性 | 达到 q0 的增广**不唯一**；一个可能 fail (S)，另一个满足 | ⚠️ 困难的来源 |
| Theorem 3 / 参数化 | 所有最小 (A)-增广由 (J, Θ, K) 参数化：J ⊆ {1..s}, \|J\| = k; L = [L; X_J(Θ)M_C + KC] | 搜索空间 = C(s,k) × Θ |
| Theorem 4（(S) 约化形式） | (S) ⇔ rank P_L(λ) = rank H ∀λ | 化为多项式矩阵的 gcd 判据 |
| Theorem 5（最小阶存在性） | 存在 q0 阶观测器 ⇔ ∃(J,Θ,K) 使 gcd_λ(Δ_i) = 1 | 判定准则 |
| Corollary 1/2 | q0 = r 退化为 Darouach；L 张满未测方向退化为 Luenberger/PBH | 与经典对齐 |
| **P2 的阶谱** | 允许阶数在 [q0, n0−p]；n0 = rank O_C | **扩维的依据** |

**组合量（NP-hard 归约的天然落点）**：
- C(s, k) 个子集 J（s = n−p−r，k = q0−r）
- P3 中的 C(n−a, j)、C(rows(U), β1) 等

## 4. NP-hard 证明的候选路线

### 路线 α：从 Set Cover / Hitting Set 归约
- 直觉：Σ(η_j−1) 的最小性天然是"覆盖"结构。
- **陷阱**：(5a) 只要求**线性张成**，不是**集合并集**。
  因此"仅 (5a)"是多项式的（见 README §2），硬度必须来自 (5b)。

### 路线 β：从最小生成集 / Sparse 恢复归约
- 同上，需先确认 (5a) 不是硬度的来源。

### 路线 γ：(S) 侧的 gcd 判定
- (S) ⇔ gcd_λ(Δ1..Δ_{N_h}) = 1，是**符号/代数**条件。
- 若可行性只由连续参数 Θ 决定，复杂度会落到 **∃ℝ**，而**不是** NP-hard。
  **这是本命题最容易被审稿人击穿的地方。**

**倾向**：主线是 (5b)/(S) 侧的联合搜索（离散 J + 连续 Θ），
必须显式消去 Θ 或给出离散化构造。

### 归约必须写清的要素
1. 方向：Set Cover 实例 ↦ 系统数据 + 预算 k。
2. ⇐ 方向：给定覆盖，构造 R，验证 (A) 与 (S)。
3. ⇒ 方向：给定 R，抽取覆盖。
4. 多项式时间：0/1 + 块对角，避免大数。
5. 决策版 ∈ NP 的证书（R 本身）。
6. 验证 (S) **必须双向**（见 §5 末）。

## 5. 陷阱清单

- [x] **(S) 是否蕴含 (A)？** 已判定：**互不蕴含**。
- [ ] **s ∈ ℂ 还是 ℜ(s) ≥ 0？** 影响难度；取 ℂ 更强（任意极点）。
- [ ] **C(s,k) 的具体含义**：s = n−p−r，k = q0−r（已在 P1 `data/p1.txt:802` 核对）。
- [ ] **row(L0) ⊆ row(L)** 约束是否满足。
- [ ] **rank[L0; C] = r+p**（H3）必须显式满足。
- [ ] **功能可观性（H4）** 是 P1/P2 的 standing assumption，必须满足。
- [x] **η_j 是否多项式可算？** 是（P1 §III 的秩保留构造）。
      ⇒ NP-hard 不能来自"算 η_j"，只能来自"从候选族里挑最小子集"。
- [ ] 归约中的矩阵元素要是多项式长度的整数/有理数。
- [ ] "最小行数"的良定义：若不存在可行 R 则无解。
- [ ] **(S) 的验证必须双向**：所有 (h+1) 阶子式恒零 **且** h 阶子式 gcd 为常数。
      只做后者会漏判（1500 例中 13 例 generic rank > h）。

## 8. 审查结论

### 8.1 被纠正的错误（8 类，摘要）

| # | 原以为 | 实际 |
|---|---|---|
| 1 | (5a) 左端 3 块 | **4 块** `[LA; L; CA; C]` |
| 2 | (5b) 不改变最小行数 | 可能把最小值从 q0 抬高 |
| 3 | (S) ⇒ (A) | **互不蕴含** |
| 4 | 定理 2 公式无条件成立 | 必须加前提 rank[L0;C] = r+p |
| 5 | (5b) 判据为"存在子式非零" | **错**；正确是 gcd = 1（精确算术发现 31/387 反例） |
| 6 | 下界证明用 VA ⊆ V | **错**；只需 (V+W)A ⊆ V+W |
| 7 | 构造反例时 $L_0 = C$ | **违反 H3**，例子无效 |
| 8 | "加候选族约束就 NP-hard" | **错**；(5a) 只要求线性张成 |

### 8.2 分层结论

| 问题 | 复杂度 |
|---|---|
| 仅 (5a) | **多项式**（闭式 dim Z − dim V，已证） |
| 仅 (5a) + 候选族约束 | **仍是多项式** |
| **rank[C;CA] = n 时的 (5a)∧(5b)** | **多项式**（ν_min = q0，已证 → `problems/q3.txt`） |
| **(5a)∧(5b)，rank[C;CA] < n** | **未知**（= q.txt 的开放部分） |
| **扩维：在 [q0, n0−p] 中求最小谱可行阶** | **未知**（= P2 的主题，用户指出） |
