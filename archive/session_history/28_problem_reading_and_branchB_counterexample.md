## 1. 🔴→✅ 支 B 的"有限孤立点"：我的反例**作废**

### 1.1 我一度宣称的反例（**错误**）

`probe_B_final.py` 报：支 B 实例（$n{=}5,p{=}1,r{=}1,q_0{=}2,k{=}1,s{=}3$，$\Theta$ 维数 $m=2$）
在 $\Theta_0$ 附近以步长 $1/32$ 随机扰动 400 次，**命中 37 次（9.2%）**。

$$\text{我据此断言：}\ \Omega^\star\ \text{是正维数集合，FINAL 的"有限孤立点"错了}\ ✗$$

### 1.2 🐛 真正的 bug（`randint(-1,1)` 会取 0）

扰动写成 `base[i] + Fraction(rng.randint(-1,1), 32)` ——
**当两个坐标的 `randint(-1,1)` 都取 0 时，扰动向量是 `(0,0)`，即"没有扰动"**，
于是"命中"的都是 $\Theta_0$ **本身**。

`b1_resolve.py` 直接把命中点打印出来，**全部是 `['0','0']`**：

```
[测试2] ±1/32 扰动（400 次）：  命中 50 —— 全部是 ['0','0']
[测试2'] 排除零扰动后：          非零扰动命中 0（零扰动出现 400 次）
[测试4]  步长 1/1024，非零扰动： 命中 0 / 1000
```

$$\boxed{\ \text{"9.2\% 命中率"是\textbf{测量 bug}（采样到了基点自身），不是 \Omega^\star\ 正维数的证据}\ ✗}$$

### 1.3 ✅ 修正后的正确测量（`b1_dim_scan.py`）

对 **6 个** $\Omega^\star$ 非空的支 B 实例（$n{=}5,p{=}1,r{=}1,q_0{=}2,k{=}1,s{=}3$，$m=2$）做**三重交叉**：

| 判据 | 结果（6 个实例全同）|
|---|---|
| ① **切空间维数**（定义子式的梯度矩阵秩）| $\dim T_{\Theta_0}\Omega^\star=0$ |
| ② **精细网格**（步长 $1/16$，$\pm1/4$，81 点）| 命中 **1**（仅 $\Theta_0$）|
| ③ **非零随机扰动**（步长 $1/1024$，约 1780 次/实例）| 命中 **0**（共约 10700 次）|

$$\Longrightarrow\ \textbf{这些实例上}\ \Omega^\star=\{\Theta_0\}\ \text{（孤立点）}\ \Longrightarrow\ \textbf{FINAL §8 的"有限孤立点"得到支持}\ ✓$$

**我的反例撤回。** 本轮净结论：**FINAL §8 无需修改**。

### 1.4 ⚠️ 但仍有一点保留

6 个实例**形状全同**（$k{=}1,p{=}1,s{=}3$）。以下未测：

- $k\ge2$（$\Theta$ 维数更大）；

- $q_0\ge3$。

**⟹ "$\Omega^\star$ 在支 B 上恒为孤立点"仍只有小样本支持，不是定理。**

## 2. ⭐ 仍然成立的一点：**"解数"这个指标需要精确化**

虽然"正维数"的说法错了，但 **$\#\Omega^\star$ 数的是什么**这个问题**是真的**。
`scripts/core/exact_count_14_elim.py` 数的是：

> 消元后**单变量多项式 $g(s)$ 的不同根数**（$s$ = 谱变量 $\lambda$），并对每个根反解 $\Theta(s)$。

**这不是 $\#\Omega^\star$**。至少混了三件事：

| # | 混淆 | 说明 |
|---|---|---|
| a | **$\Theta$ 的解数** vs **谱变量 $\lambda$ 的根数** | 代码数的是后者的根数 |
| b | **"消元法解出的解"** vs **"全部解"** | 用 Cramer 法则**隐含假设 $\det A\ne0$** ⟹ 漏掉 $\det A=0$ 的分支 |
| c | **$\Omega^\star$ 的势** vs **它的维数** | 每层 $J$ 的 $\Omega^\star_J$ 维数可不同 |

**⚠️ 注意（本轮教训）**：上表第 c 行我在**错误版本**里写成"$\Omega^\star$ 可能是正维数所以势无意义"——
那个理由已被 §1 推翻；但"要弄清数的是什么"这个**要求本身**仍然成立 ✓

**修正建议**（措辞）：把 FINAL §8 / c4 的

> ~~$\#\Omega^\star$ 有多项式上界~~

改为**可良定义**的陈述，例如

1. **每层 $J$ 的 $\Omega^\star_J$ 的维数**（若 §1 的孤立点结论普遍成立，则维数 $=0$，势有限）；
2. **$\Omega^\star$ 的不可约分支数 / 消元后 $s$ 的根数**的上界；
3. 或**明确声明数的是哪个集合**（$\Theta$？谱变量？增广矩阵的同构类？）。

## 3. 本轮我犯的三个**读法错误**（由用户指出，均成立）

### 3.1 错误一：以为判据是"行列式"（**我原答复正确，但需一直说清**）

$$(\text{5a}):\ \operatorname{rank}\begin{bmatrix}LA\\CA\\C\end{bmatrix}=\operatorname{rank}\begin{bmatrix}CA\\C\\L\end{bmatrix},\qquad
(\text{5b}):\ \operatorname{rank}\begin{bmatrix}\lambda L-LA\\CA\\C\end{bmatrix}=\operatorname{rank}\begin{bmatrix}CA\\C\\L\end{bmatrix}$$

**判据是秩等式**；行列式只出现在项目的**实现**里（子式 gcd、Cramer），**不是判据** ✓

### 3.2 错误二（**重要**）：把"三元组功能可观"与"$L$ 自身满足 $(5a)(5b)$"混为一谈

我一度断言："只要 $(A,C,L_0)$ 功能可观，$R=0$ 就够 ⟹ 最小 $R$ 恒为 0" ✗

用户指出：「$(5a)(5b)$ 不就是用于刻画功能可观测的吗？」

**核实（用户对）** P3 **Definition 1** 原文字面（[02_文献摘录](../docs/02_文献摘录_证明相关.md):970–972）：

> $(A,C,L_0)$ Functional Observable **iff** $\exists L$, $\mathcal R(L)\supseteq\mathcal R(L_0)$ **and $L$ satisfies conditions 1 and 2**（即 $(5a)(5b)$）

$$\Longrightarrow\ (5a)(5b)\ \textbf{确实刻画功能可观测性}\ \text{——只是刻画\textbf{增广后}的}\ \begin{bmatrix}L_0\\R\end{bmatrix}$$

**我的真实错误**：① 混淆"$\exists R$（功能可观）"与"$R=0$（$L_0$ 自身可行）"；
② **反读**了 [01_概念总结](../docs/01_概念总结.md) §6.1（那节说 $R=0$ **不行**时才需增广）。

**正确理解**（与 [01](../docs/01_概念总结.md) §6.3 的 P3 原话一致）：

$$\textbf{原命题} = \min|R|\ \text{s.t.}\ \begin{bmatrix}L_0\\R\end{bmatrix}\ \text{满足}\ (5a)\wedge(5b)\ \Longleftrightarrow\ \textbf{最小阶功能观测器}$$

### 3.3 错误三：**行数 vs 秩**

$q_0$ 用**行数** $r+k$ 计，而 $\text{观测器阶数}=\operatorname{rank}\begin{bmatrix}L_0\\R\end{bmatrix}\le$ 行数。
H2/H3 只约束 $L_0$，**没约束 $R$ 与 $L_0$ 的相关性**。

**建议**：在 [problems/q1.md](../problems/q1.md) 加"$\operatorname{rank}[L_0;R]=\operatorname{rank}L_0+\operatorname{rows}(R)$"或改为按秩计。
