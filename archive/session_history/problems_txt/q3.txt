========================================================================
一、命题
========================================================================

【命题 q3】

  给定满足以下条件的 LTI 系统 (A, C, L0)：

   (H1) rank(C) = p
   (H2) rank(L0) = r
   (H3) rank[L0; C] = r + p        （联合满秩；排除 L0 中落在 row(C) 的成分）
   (H4) 功能可观：row(O_L0) ⊆ row(O_C)  （P1 §II 的 standing assumption）
   (H5) **首次可观性充分**：
            rank[C ; CA] = n          ← 本条件
        等价地 ker[C;CA] = {0}，即 N_CA 为空矩阵（0 列）。

  求最小的 k，使存在 R ∈ R^{k×n}，令 L = [L0; R] 同时满足
       (5a) rank[LA; L; CA; C] = rank[L; CA; C]
       (5b) rank[sL − LA; CA; C] = rank[CA; C; L],  ∀s ∈ C

  问：计算该最小 k（记 nu_min）是否为 NP-hard？


========================================================================
二、结果（已严格证明）
========================================================================

【定理 q3】

  在 (H1)–(H5) 下：

     nu_min = q0 = Σ_{j=1}^{r} η_j

  其中 η_j 是功能可观性指数（P1 §III 的全局有序秩保留构造读出）。
  且 q0 可在**多项式时间**内计算。

  因此命题 q3 的答案是：**不是 NP-hard；该问题在 P 中。**

【证明】

  步骤 1（条件 (H5) 的直接后果）.
    由 (H5)，rank[C;CA] = n，故
        ker[C;CA] = {0}，
    于是 N_CA（ker[C;CA] 的基矩阵）是 n×0 的空矩阵。

  步骤 2（(5b) 的核形式退化）.
    由引理 L3：
        (5b) ⟺ rank[(sL−LA)N_CA] = rank[L·N_CA]   ∀s
    代入 N_CA = 0（空矩阵）：
        (sL−LA)N_CA = 0（n×0 空矩阵），L·N_CA = 0。
    两者秩均为 0，故等式**恒成立**。

    ⇒ **(5b) 对任意 L 自动成立。**

  步骤 3（只需考虑 (5a)）.
    由步骤 2，满足 (5a)∧(5b) 的最小行数
        = 满足 (5a) 的最小行数
        = q0                    （P1 Theorem 2 / 本文定理 2）

  步骤 4（多项式性）.
    q0 = Σ_j η_j 由 P1 §III 的有序秩保留构造确定，
    该构造为 O(n) 次秩计算，多项式时间。∎

【附注】步骤 2 的另一种表述：
    (5b) 的两端分别是
        rank[C;CA] + rank[(sL−LA)N_CA]  与  rank[C;CA] + rank[L·N_CA]
    当 N_CA 为空时，后两项均为 0，两端都等于 rank[C;CA] = n。

========================================================================
四、q3 的意义与局限
========================================================================

【意义】

  (H5) 是一个**自然的、常见的**条件：它要求 (A,C) 的首次可观性已充分，
  即单次求导（y 与 ẏ）就能定出全部状态。

  在此条件下：
    * (5b) 消失（不再构成约束）；
    * 问题塌缩为"求 (5a) 的最小行数"，即 P1 Theorem 2 的 q0；
    * 一切是多项式的。

  这解释了为什么 P1/P2 在实践中很少遇到"谱阻塞"：
  只要 rank[C;CA] = n，谱条件就自动满足。

【局限】

  (H5) 是**充分条件**，不是必要条件。当 rank[C;CA] < n 时：
    * N_CA 非空，(5b) 成为实质约束；
    * 此时 nu_min ≥ q0，可能出现"谱阻塞"（P2 的例子：
      r=2 < q0=3 < nu_min=5 < n0−p=6）；
    * 该情形的复杂度**仍未解决**（对应 q.txt 的开放部分）。

五、相关的已证明结构（来自主证明链）
========================================================================

  L1  (5a) ⟺ row(LA) ⊆ row(L,C,CA)
  L2  (5b) 只依赖 row(L)
  L3  (5b) ⟺ rank[(sL−LA)N_CA] = rank[L·N_CA] ∀s
  L4  P_L(s) = (sI − T_R)H_L            （由 LA = T_R L + GC 右乘 N_CA）
  L5  im(H_L) ≅ R/(R ∩ row(C))
  L6  (S) ⟺ im(H_R) 不含 T_R 的任何特征向量
  L7  (S) 是 Zariski-开条件
  L8  Z 是包含 row(L0)+row(C) 的最小 A-不变子空间；可行 R ⊆ Z
  L9  q0 = Σ η_j 多项式可算
  L10 rank[C;CA] = n ⟹ (S) 自动成立             ← 本文件的核心
  L11 P1 §VII 算例校准逐条一致
