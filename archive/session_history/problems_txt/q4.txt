二、支 B 的已知结构（本轮推进到的位置）
========================================================================

1. 铅笔既约形式（已推导 + 严格验证 31/31 × 8 实例，含非平凡 True 点）：

       (A)  <=>  对所有 i = 1..r+k:   q_i(Theta) ∈ row P(Theta)

   其中  P(Theta) = B2^(1) Theta − B2^(2)      (p × (s−k))
         q_i(Theta) = gamma_i^(1) Theta − gamma_i^(2)

2. 统一性：  2p + q0 < n   <=>   p < s − k
   ⟹ P(Theta) 行数恒不足，row P 恒为真子空间 —— 这就是「不可能满测度」的计数原因。

3. 强必要条件：  (A) 成立  ⟹  rank Q(Theta) <= p
   （行列式簇，余维 (r+k−p)(s−k−p)）

4. 次数下降：P 与 q_i 都是 Theta 的仿射函数
   ⟹ 每个包含条件由 (p+1) 阶子式给出，次数 <= p+1
   ⟹ Bezout:  #Omega* <= (p+1)^{ k(s−k) }     ← 仍**指数**，这就是缺口

5. 最小情形 (r,p,k) = (1,1,1) 已完全解决：
   精确判别式计算证明恒有**恰好 2 个解**（10/10 实例），
   可由「一个一次方程 + 一个二次方程」显式求出 ⟹ 多项式 ⟹ 该情形命题为假。

━━━ 本轮新增的**结构性纠正**（真实、已核对）━━━

  之前我写「P 与 q_i 都是仿射，故次数 <= p+1」—— **这是错的**。
  q_i = gamma_i^(1)(Theta)·Theta − gamma_i^(2)(Theta)，而 gamma_i^(1) **本身依赖 Theta**。

  正确的次数结构：

    N 的行           gamma_i        q_i 的次数
    ────────────────────────────────────────────
    i <= r   (W_J 的常数行 e_i)     **常数**      **一次**
    i >  r   (W_J 的 Theta 行)      仿射          **二次**

  ⟹ 条件 q_i ∈ row P（P 仿射，p×(s−k)）由 [P; q_i] 的 (p+1) 阶子式给出，次数：
        i <= r :  <= p+1
        i >  r :  <= p+2

  **这正好解释了 (1,3) 情形为何恰是「一个一次 + 一个二次」**（r=1, k=1）——
  见 proof/12 的 6.1–6.4。

  **同时纠正**：我曾设想的「Z-图」（把 (A) 化为双线性方程 Z(BΘ+C)=DΘ+E 且 D,E 常数）
  **不成立**，因为 gamma^(1) 不是常数 ⟹ q_i 不是 Theta 的仿射函数。
  （原式只有第一项 ZBΘ 与 DΘ 是双线性，第二、三项 ZC 与 E 依赖 Θ 的高次项。）
