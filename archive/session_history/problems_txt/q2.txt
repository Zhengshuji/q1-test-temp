========================================================================
q2.txt —— 增加候选族约束后的命题（记录）
========================================================================

【为什么建这个文件】

q.txt 的命题是：
  "找到行数最小的 R，使得将矩阵 L 变成矩阵 [L;R] 时，方程 (5a) 和 (5b)
   得到满足，这个问题是 NP-hard"

经审查（详见 04_NP-hard证明.md）发现：
  * 仅 (5a) 的最小行数 = dim Z - dim V，是**多项式可解**的；
  * 但 q.txt 要的是 (5a) 与 (5b) **同时**满足的最小行数 nu_min，
    它与上述值**不相等**（实测 16/317 实例中前者=0、后者=1）；
  * nu_min 满足 q0 <= nu_min <= n0 - p，两个端点都可算，但它本身
    既未证多项式、也未证 NP-hard。

因此需要一个"带候选族约束"的命题来承载 hardness —— 这就是本文件。


========================================================================
一、命题的正式表述
========================================================================

【命题 P'（增广侧最小基数问题）】

输入：
  * 系统数据 (A, C, L0)：A ∈ R^{n×n}, C ∈ R^{p×n}, L0 ∈ R^{r×n}
    满足 P1 §II 的前提：rank(C) = p, rank(L0) = r, rank[L0;C] = r + p
  * 一个**候选函数族**：C = {c_1, ..., c_m} ⊆ R^{1×n}
  * 预算 K

问：是否存在 R ∈ R^{k×n}，满足
      (i)  R 的每一行都属于候选族 C（即 rows(R) ⊆ C，逐行取）
      (ii) k ≤ K
      (iii) L := [L0; R] 同时满足
              (5a)  rank[LA; L; CA; C] = rank[L; CA; C]
              (5b)  rank[sL - LA; CA; C] = rank[L; CA; C],  ∀s ∈ C
    ？

判定版记作 P'_D；优化版（求最小 k）记作 P'_O。


========================================================================
二、我曾经的猜测：命题 P' 是 NP-hard
========================================================================

【当时的（错误的）推理链】

1. 令 Z := row(O_{L0}) + row(O_C)（L0 与 C 在 A 下生成的最小 A-不变子空间），
       V := row(L0) + row(C) + row(CA)。
   条件 (5a) 等价于 Z ⊆ V + row(R)。

2. 于是"找最小的 R 使 (5a) 成立"看起来就是：
       "从候选族里挑最少的行，使得它们的张成覆盖 Z/V"
   —— 而这与**最小集合覆盖**（Minimum Set Cover，Karp 1972，NP-complete）
      形式相同。

3. 最小集合覆盖是 NP-complete 的经典问题，所以直觉上 P' 也是 NP-hard。

4. 文献旁证：同一研究方向的 S20（Zhang–Fernando–Darouach,
   arXiv:2307.08923 / IEEE TAC 70(3):1592-1607, 2025）在**传感器侧**
   证明了同型命题是 NP-hard。这加强了"它应该是 NP-hard"的预期。


========================================================================
三、为什么这个推理是【错的】
========================================================================

关键漏洞在第 2 步：**"覆盖"的性质不同。**

* **集合覆盖**：候选集合只能**取并集**。选集合 S 就贡献 S 里的元素，
  不能"用一个候选覆盖别人没有的方向"。所以"是否覆盖 U"是纯组合的。

* **本问题**：row(R) 是 R 各行的**线性张成**（线性组合，不是并集！）。
  因此一个候选行只要它的**支撑**横跨多个方向，它的**线性组合**
  就能张成这些方向，从而覆盖它们。

具体的反例（04 §3.0，已数值验证）：

  设 m = 4，候选族
     C = { y_0, y_1, y_2, y_3,  y_{0,1}, y_{1,2}, y_{2,3}, y_{0,3} },
     其中 y_S := sum_{e ∈ S} y_e
  若 Z/V = span{y_0, y_1, y_2, y_3}，则
  **一行** y_{0,1,2,3}（若在候选族中）就张成整个 Z/V ——
  与"至少需要多少个集合覆盖 {0,1,2,3}"完全无关。

因此：
  **仅 (5a) + 候选族约束，仍然是多项式可解的。**
  判据是对 Z/V 取一组基，然后逐候选做消元（线性代数，非组合）。


========================================================================
四、修正后的命题与我的猜测
========================================================================

【修正后的命题 P'（保留 (5b) 的版本）】

  同上"一、"，但强调 (5b) 不可省：
  硬度（若存在）**只能**来自 (5b)，因为 (5a) 无论如何都是多项式的。

【已知的复杂度分层（详见 04 §0）】

  | 设定                    | 仅 (5a)        | (5a) ∧ (5b)          |
  |-------------------------|----------------|----------------------|
  | R 无约束                | 多项式（已证）  | 未知（= q.txt 的问题）|
  | R 取自候选族 C          | 仍是多项式（已证）| 未知（= 命题 P'）    |

【我的猜测】

  对 "R 无约束" 的 (5a)∧(5b)（即 q.txt 原命题）：
      猜测 **多项式可算**（信心约 65%）
      理由：(5b) 是"矩阵束是否常秩"的判定，等价于
            gcd_lambda(所有 h 阶子式) = 1，可用子结式/Smith 标准形
            在多项式时间内判定，不需要搜索。

  对 "R 取自候选族" 的 (5a)∧(5b)（即命题 P'）：
      猜测 **可能是 NP-hard**（信心约 55%，比之前低）
      理由：候选族把解空间**离散化**，而 (5b) 依赖 L 的**具体行**
            （不只是行空间），所以"挑哪些候选"可能真的产生组合结构。
      但：我**没有**构造出归约；这一猜测目前只是直觉。


========================================================================
四之二、【2026-xx 更新】检索结果对上述猜测的修正
========================================================================

（依据 06_相关工作检索.md，22 条来源 R01–R22）

【修正 1】"R 无约束"版的猜测**上调**：文献确认
  * **(V1) 验证版**（L 数值给定后判 (A)/(S)）：**多项式可解**。
      依据：Storjohann–Villard 2005 把多项式矩阵秩归约到矩阵乘法
      （O~(n^ω d)，Las Vegas 带认证）；Varga 2020 给出 pencil 的
      Kronecker 结构算法；Schwartz–Zippel 给出多项式恒等判定。
  * **(V2) 存在版**（L 含未知 R / Θ）：**文献零结果** ——
      既无多项式算法，也无 NP-hard / ∃ℝ-hard 下界。
  * 分层两端 q0 与 n0-p 都可算（Fernando arXiv:2609.37992）。
  => 我原先"多项式"的猜测有 V1 作旁证，但 **V1 的多项式性不能
     自动推给 V2**。这是必须避免的误读。

【修正 2】(5b) 版的正确复杂度类**可能是 ∃ℝ，而不是 NP**
  * 把 (5b) 展开成"多项式等式（子式恒零）+ 多项式不等式
    （存在非恒零子式、子式无公共根）"，其自然归属是 **∃ℝ**。
  * ∃ℝ 的最佳已知算法是**单指数**，上界 PSPACE。
  => 若要主张 NP-hard，**必须消去连续参数 Θ** 或给出离散化构造；
     否则正确结论是 **∃ℝ-hard**（这比 NP-hard 更强，但不能写成
     "NP-complete"）。这是目前最大的技术风险点。

【修正 3】⚠️ **对偶路线被文献明确否定**（我原先的首选方案作废）
  * 来源：arXiv:2309.14263（Target Controllability and Target
    Observability of Structured Network Systems, IEEE L-CSS,
    DOI 10.1109/LCSYS.2023.3289827）逐字陈述：
      "functional observability and output controllability are not
       dual properties in general when rank(F) < n."
  * 因此**不能**把 S20（Zhang–Fernando–Darouach，传感器侧 NP-hard）
    经对偶搬到增广侧。两个具体障碍：
      (a) 转置后得到的是"最小输入/驱动器选择"型问题，不是 nu_min；
      (b) 决策变量的语义不因转置而改变（S20 选 C 的行，我们要选 R）。
  * 替代桥梁（尚无人做）：该文的 Theorem 3 给出结构功能可观性的
    **纯图论判据**（每个目标节点有路径到传感器，且目标集与所有
    **极小收缩集**不交）。若能导出增广侧的类似刻画，硬度与近似
    算法都可能搬过来。

【修正 4】明确的**负面结论**（有价值）
  * 文献中**不存在**任何"最小阶（功能）观测器 NP-hard"的结果。
  * 所有已知硬度结果的决策变量都是 **C 的行** 或 **B 的列**，
    **没有一个是 R**。=> 本命题（无论哪个版本）都是**新的**。

【修正 5】Grassmann 方向不能用作归约来源
  * Lai–Lim–Ye（arXiv:2406.19377）证明 Gr(k,n) 上无约束二次优化
    是 NP-hard（含 k=1，无 FPTAS）。
  * 但其硬度在**目标函数**上，而 nu_min 的目标是**整数维数**、
    约束是**秩恒等式**，且那是**无约束**优化。
  => 只能引作**背景动机**，不能当归约来源。

【更新后的猜测】

  | 命题                            | 猜测              | 信心 |
  |---------------------------------|-------------------|------|
  | q.txt 原命题（R 无约束，(5a)∧(5b)）| 多项式可算        | ~65% |
  | 命题 P'（R 取自候选族，(5a)∧(5b)） | NP-hard 或 ∃ℝ-hard | ~55% |
  | 命题 P' 若是硬的，其类别          | 更可能是 ∃ℝ-hard   | ~60% |

  注：由于修正 3，我原先"由 S20 经对偶推出硬度"的首选路径**已作废**，
  必须自建归约（或走修正 3 的图论桥梁）。


========================================================================
四之三、【2026-xx 决定性更新】两个实验否证了我猜测所依赖的假设
========================================================================

我原先猜测"候选族约束 -> NP-hard"依赖一个隐含假设：

    **(H) (5b) 依赖 L 的具体矩阵表示，而不只是 row(L)。**

（若 (H) 成立，则"从离散候选族挑子集"会因 L 的具体行不同而产生
  组合结构，hardness 才有来源。）

【实验 1（_extract/verify_spectral_rigidity.py）】

  构造 R 与 R' = T·R（T 可逆，故 row(R') = row(R)），检查
  (5a)∧(5b) 是否会在两者之间翻转。

  结果：找到 0 个反例。
        （"同一行空间、(5a) 都成立、(5b) 一真一假"的实例不存在）

【实验 2（_extract/verify_S_rowspace.py）— 更严格】

  3 维系统，1500 轮随机实例：
    * 满足 (5a)∧(5b) 的 L                    : 11,021 个
    * 检验的"同一行空间不同表示"对数          : 132,252 对
    * **反例个数（(5b) 被翻转）**             : **0**

  => **假设 (H) 被否证**：(5b) 在该规模下**只依赖 row(L)**。

【实验 3（同文件实验 B）】

  候选族受限（只用标准基 + 全一向量）与无约束（穷举 ±1 网格）比较
  最小 k：
    候选族受限的 k 严格更大 : **0**
    相同                     : 188
  => 候选族约束在该实验中**完全没有起作用**。

【对猜测的影响】

  若 (5b) 只依赖 row(L)，则整个问题可以完全用**子空间语言**重述：

      求最小的子空间 R ⊆ R^n，使
          row(L0) ⊆ R  （L0 的行不能被丢掉）
          R 满足 (A) 与 (S)     [两者都是"子空间的性质"]

  这在**子空间格**（或 Grassmann 流形 Gr(k,n)）上是一个
  "求最小维数可行子空间"的问题。

  而 (A) 与 (S) 都是**代数**条件（子式恒零/多项式 gcd），
  最小维数可行子空间问题一般有**多项式算法**
  （格上的贪心 / 消元 + 维数下界）。

  => **(H) 被否证 + 候选族不起作用**，两点合起来使 hardness
     失去了可能的来源。**我的猜测"P' 是 NP-hard"应当下调。**

【更新后的猜测（第三次）】

  | 命题                              | 猜测        | 信心 |
  |-----------------------------------|-------------|------|
  | q.txt 原命题（R 无约束，(5a)∧(5b)） | 多项式可算  | ~78% |
  | 命题 P'（R 取自候选族，(5a)∧(5b)） | **也是多项式** | ~62% |

  理由：既然 (5b) 只依赖 row(L)，候选族的"离散性"就不构成
        组合障碍 —— 因为我们仍可在候选的张成空间里做线性组合
        （(5a) 允许），而 (5b) 又只看张成空间本身。

【但仍然必须承认的保留】

  * 实验规模只有 n = 3，样本来自整数矩阵；(H) 在更高维、
    更病态、或有重根/不可对角化等退化情形下**仍可能**成立。
    要否证或确认 (H)，需要更大的实验或一个定理。
  * (5b) 依赖 row(L) 这一点若能**证明**，则是本问题
    走向"多项式算法"的关键一步 —— 这是目前**最有价值的
    可攻目标**（见 §七）。


========================================================================
五、当前的开放问题（真正要证的）
========================================================================

【首要 · 已升级为最有希望的方向】
    证明或否证：**(S) 只依赖 row(L)**（假设 (H) 的逆）。
    若能证明，则问题可用子空间语言重述，很可能落在 P；
    进而可望给出 nu_min 的多项式算法。

【其次】判定 nu_min（(5a)∧(5b)，R 无约束）是否多项式可算。
        证出多项式 => q.txt 命题为**假**；
        证出 NP-hard => q.txt 命题为**真**。
        (V1) 验证版（L 数值给定后判 (A)/(S)）已知**多项式**
        （Storjohann–Villard 2005: O~(n^ω d)；Varga 2020: pencil
        Kronecker 结构；Schwartz–Zippel: 多项式恒等判定）；
        (V2) 存在版（L 含未知 R/Θ）文献**零结果**。

【再次】命题 P' 的归约（若仍想证硬度）：
        全部难点在 (5b) 的**显式满足构造**；且**必须消去连续 Θ**，
        否则结论只能是 ∃ℝ-hard（见"四之二 修正 2"）。

【防守】判定版 ∈ NP 的证书与验证算法：
        验证 (5b) **必须双向**（所有 (h+1) 阶子式恒零
        **且** h 阶子式 gcd 为常数）——只做后者会漏判
        （实测 1500 例中 13 例误判）。

【作废】"由 S20 经对偶直接推出硬度" —— 文献已明确否定朴素对偶
        （arXiv:2309.14263："functional observability and output
        controllability are not dual properties in general"）。
        替代：该文的图论判据（极小收缩集）桥接，尚无人做。

六、附：相关事实清单（可核查）
========================================================================

* (5a) 的正确形式是 **4 行块**：
      rank[LA; L; CA; C] = rank[L; CA; C]
  等价于 row(LA) ⊆ row(L, C, CA)。（坐标级 PDF 重建确认）
* (S) 与 (A) **互不蕴含**（1200 例：(S) 独真 433、(A) 独真 85）。
* 仅 (5a) 的最小行数闭式：
      k_min = dim Z - dim V,   Z = row(O_{L0}) + row(O_C),
                               V = row(L0) + row(C) + row(CA)
  前提 rank[L0;C] = r+p；独立穷举验证 347/347。
* nu_min 的范围：q0 <= nu_min <= n0 - p，
      q0 = sum_j eta_j（功能可观性指数之和），n0 = rank(O_C)。
* 相关论文：Fernando-Trinh-Jennings IEEE TAC 55(5):1268-1273 (2010)；
      Fernando arXiv:2609.33615；Fernando arXiv:2609.37992；
      Zhang-Fernando-Darouach arXiv:2307.08923 / IEEE TAC 70(3):1592-1607 (2025)。
