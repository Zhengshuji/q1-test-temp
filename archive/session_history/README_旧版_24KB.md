## 1. 问题的精确形式

设系统 $\dot x=Ax+Bu,\ y=Cx,\ z_0=L_0x$，增广 $L=[L_0;R]$（$\mathrm{rows}(L)=r+k$ = 观测器阶数）。

**两个条件**（P3 Theorem 2）：

$$(\text{5a})\ \mathrm{rank}\begin{bmatrix}LA\\L\\CA\\C\end{bmatrix}=\mathrm{rank}\begin{bmatrix}L\\CA\\C\end{bmatrix},
\qquad
(\text{5b})\ \mathrm{rank}\begin{bmatrix}sL-LA\\CA\\C\end{bmatrix}=\mathrm{rank}\begin{bmatrix}CA\\C\\L\end{bmatrix}\ \forall s\in\mathbb C$$

**前提假设**（三篇文献共有，详见 `proof/05_PDF前提假设清单.md`）：

| 编号 | 假设 |
|---|---|
| H1 | $\mathrm{rank}(C)=p$ |
| H2 | $\mathrm{rank}(L_0)=r$ |
| H3 | $\mathrm{rank}[L_0;C]=r+p$ |
| **H4** | **功能可观性** $\mathrm{row}(O_{L_0})\subseteq\mathrm{row}(O_C)$ |
| H5 | $s\in\mathbb C$（任意极点配置）或 $\Re(s)\ge0$（渐近收敛） |

**核心量**：

q_0=Σ_jη_j_(5a) 的最小行数，多项式可算  ≤  ν_min _(5a)∧(5b) 的最小行数  ≤  n_0-p_功能可观上界

### 2.2 一个完整的已证结论（`q3.txt`）

> **在 $\mathrm{rank}[C;CA]=n$ 下，$\nu_{\min}=q_0$，问题多项式可解，故不是 NP-hard。**

证明：$\ker[C;CA]=\{0\}\Rightarrow N_{CA}$ 为空矩阵 $\Rightarrow H_L=P_L(s)=0\Rightarrow$(S) 恒成立。

### 2.3 P1 算法的整理

P1 §III–IV 给出 $R$ 的**构造性算法**（不是搜索）：

1. **有序秩保留构造**：生成元 $g_1..g_{p+r}=C$ 的行 $\cup$ $L_0$ 的行；按"幂次优先、同幂按序号"的全局顺序逐行做秩保留，得 $M$；
2. **读指数**：$\alpha_i=1+\max\{k:g_iA^k\in\mathrm{rows}(M)\}$，$\eta_j:=\alpha_{p+j}$；
3. **解一阶依赖**：$L_jA^{\eta_j}=\phi_{p+j}M^-_{p+j}$（线性方程组，多项式）；
4. **闭式生成额外行**：
   $$\ell_{j,t}=L_jA^{t}-\sum_{q=1}^{t}\phi^{(q)}_{p+j}G^{(q)}_{p+j}A^{\,t-q},\qquad t=1,\dots,\eta_j-1$$
5. $R=[\ell_{j,t}]$，$\mathrm{rows}(R)=\sum_j(\eta_j-1)=q_0-r$。

**要点**：该算法给出的是 **(5a) 的最小解**；它**不保证** (S)。

  **这是本项目最重要的未决点。**

- **对命题 q_now 的回答**：
  - $d_{CA}<q_0$ 且 $2p+q_0\ge n$：判定 ∈ BPP ⟹ 该范围内命题**假**（两情形完全证明；$d_{CA}\ge2$ 附 $(\star''')$）；
  - $d_{CA}\ge q_0$：随机检验无信息，须代数判定；
  - $2p+q_0<n$ 最小情形（$r=p=k=1$）：恰 2 个候选 ⟹ 命题**假**（严格推导 + 10/10 精确计数）；
  - $2p+q_0<n$ 一般情形：**未定**。

- **残余空白**：把"Kronecker 型铅笔（$\Theta$ 仅左乘出现）"与"必要条件 $\mathrm{rank}Q\le p$"结合，
  把 $(p+1)^{k(s-k)}$ 降到多项式界。

- **采样/求解教训**：
  - **#18**：涉及代数坏集的随机实验必须用**一般有理数**。
  - **#19**：**图卡坐标依赖 $T$**；须先把 $T$ 规范化。

- **对命题 q_now 的回答**：
  - $2p+q_0\ge n$：判定 ∈ BPP ⟹ 命题**假**（已证）；
  - $2p+q_0<n$ 最小情形：恰 2 个候选 ⟹ 命题**假**（已证）；
  - $2p+q_0<n$ 一般情形：**未定**。

- **残余空白（唯一）**：一般情形下 $(\text{A})$ 解集的**多项式界**。
  Bézout 只给 $(q_0+p+1)^{k(s-k)}$（指数）；需要额外结构（候选：P1 有序秩保留构造的谱系饱和性）。

- **采样/求解教训**：
