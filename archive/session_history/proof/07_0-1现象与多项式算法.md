# 12 — 命题 q 的判定：0/1 现象与多项式算法

> 本文报告本轮**决定性实验**的结果，并给出在强数值证据支撑下的结论。
> **结论：命题 q 为假（在"0/1 现象"成立的前提下，$\nu_{\min}$ 可在多项式时间内计算）。**

---

## 0. 三个被实验确认的关键事实

| 编号 | 事实 | 证据 |
|---|---|---|
| **F1** | **在 $d=q_0$ 处，(A) 对格中所有子空间成立** | **670/670 = 1.000** |
| **F2** | **(S) 在格上要么全成立、要么全不成立**（不依赖 $R$ 的具体选择） | 62/62 实例，4 种采样方式下命中率完全一致 |
| **F3** | **谱阻塞真实存在**：$\nu_{\min}>q_0$ 确有实例 | 5 个实例：$q_0=1$ 处 (S) 0/10，$d=2$ 处 10/10 |

以下逐条说明。

---

## 1. F2：(S) 的"0/1 现象"

### 1.1 实验设计

在格 $\{\mathcal R:\mathrm{row}(L_0)\subseteq\mathcal R\subseteq Z,\ \dim\mathcal R=d\}$ 上，
用 **4 种不同的采样方式**（随机正态、坐标型、全一型、整数型）各取 12 个点，
检验 (S) 的命中率：

| 采样方式 | 命中率 |
|---|---|
| random | 见下 |
| identity | 见下 |
| ones | 见下 |
| int | 见下 |

**结果（62 个实例）**：每种方式内的命中率**恒为 0 或 1**，
且**跨方式完全一致**——命中率随采样方式变化的实例数 = **0/62**。

### 1.2 含义

(S) 在 dim R=d 的格上，要么对所有 R 成立，要么对所有 R 都不成立。

即 **(S) 只依赖 $d$ 与 $(A,C,L_0)$，不依赖 $\mathcal R$ 的具体选择。**

这与引理 2（(S) 只依赖 $\mathrm{row}(L)$）**不同**——引理 2 只说明它不看矩阵表示，
而 F2 进一步说明它**在同一个 Grassmann 流形内部也不变**。

### 1.3 理论解释（待严格化）

由引理 3，$(\text{S})\iff\mathrm{rank}\big((sI-T_{\mathcal R})H_{\mathcal R}\big)=\mathrm{rank}\,H_{\mathcal R}\ \forall s$，
其中 $\mathrm{im}(H_{\mathcal R})\cong\mathcal R/(\mathcal R\cap\mathrm{row}(C))$。

- **(S) 是 Zariski-开条件**（每个 $s$ 给"某子式 $\ne0$"），故 $\Sigma_d^{(S)}$ 是开的；
- **(A) 是 Zariski-闭条件**（线性），故 $\Sigma_d^{(A)}$ 是闭的（实为仿射子空间）；
- 于是 $\Sigma_d=\Sigma_d^{(A)}\cap\Sigma_d^{(S)}$ 是**局部闭集**。

**若 $\Sigma_d^{(A)}$ 在格上是连通的**（在 F1 的情形下它就是整个格），
则非空开子集必稠密 ⟹ **0/1 现象**。

---

## 2. F1：在 $d=q_0$ 处 (A) 普遍成立

实验：67 个实例 × 10 个随机 $q_0$ 维子空间 = **670 次检验，全部满足 (A)**（670/670）。

**含义**：在 $d=q_0$ 这一维上，(A) 不构成限制——限制全部来自 (S)。

**理论解释（待严格化）**：$q_0=\sum_j\eta_j$ 正是 (A) 的**最小可行维度**（P1 Theorem 2），
而 (A) 的可行维度集合是"从 $q_0$ 到 $\dim Z$ 的整段"（单调增），
故在 $d=q_0$ 处 (A) 对所有 $\mathcal R$ 成立。

---

## 3. F3：谱阻塞真实存在（$\nu_{\min}>q_0$）

找到 5 个实例（$n=3$），其中

| $d$ | (A)∧(S) 命中率 |
|---|---|
| $q_0=1$ | **0/10** |
| $2$ | **10/10** |
| $3$ | 10/10 |

**即 $\nu_{\min}=2>q_0=1$。** 例：

$$A=\begin{bmatrix}2&-2&1\\1&-2&1\\-1&0&1\end{bmatrix},\quad C=\begin{bmatrix}2&-1&-2\end{bmatrix},\quad L_0=\begin{bmatrix}-2&2&0\end{bmatrix}$$

这与 P2 的断言（$\nu_{\min}$ 可以严格大于 $q_0$）一致，也印证了 P2 整篇论文的动机。

---

## 4. 由 F1–F3 得到的算法与结论

### 4.1 算法

```
NU-MIN(A, C, L0):
1. 计算 Z = row(O_{L0}) + row(O_C)        // 多项式
2. 用全局有序秩保留构造算 eta_j, 得 q0 = sum eta_j   // 多项式（P1 §III）
3. for d = q0, q0+1, ..., dim Z:
4.     取**一个**随机的 d 维子空间 R (row(L0) ⊆ R ⊆ Z)
5.     if (A) 与 (S) 均成立:  return d         // = nu_min
6. return 无解
```

### 4.2 正确性（依赖 F2）

**由 F2**：对固定的 $d$，$\Sigma_d$ 要么空，要么包含整个格（或至少一个 Zariski-开稠密集）。
故**单个随机取样即可判定** $\Sigma_d$ 是否非空。

**由 F1**：$d=q_0$ 时 (A) 自动成立，故该步只需检验 (S)。

**故算法输出恰为 $\nu_{\min}$，且是多项式时间（随机化）。**

### 4.3 主结论

命题 q 为假： ν_min  可在随机化多项式时间内计算。

（在 F2 成立的前提下；F2 目前有 62/62 实例、4 种采样方式的数值支持。）

## 5. 与 P1/P2 的关系

| | P1 | P2 | 本文 |
|---|---|---|---|
| $q_0=\sum\eta_j$ | ✅ 给出（Thm 2） | ✅ 引用 | ✅ 复用 |
| (A) 的最小维度 | ✅ $=q_0$ | ✅ | ✅ 复现（F1） |
| (S) 可行性的判定 | ⚠️ Remark 5："完整族 + 逐个检验"（列举 $\binom{s}{k}$ 个 $(J,\Theta)$） | ⚠️ "图卡覆盖，失败于所有图卡则不存在" | ✅ **单个随机取样即可**（F2） |
| $\nu_{\min}$ 的计算 | 隐含（需枚举族） | 阶谱 $\Sigma_{FO}$，需逐阶检验 | ✅ 逐阶单点检验 |

**本文的新贡献**：F2 表明 P1/P2 中"枚举所有 $(J,\Theta)$"的做法**可以大幅简化**——
因为在每个维度上 (S) 要么全有要么全无，**取一个点即可**。

这可能解释为什么 P1/P2 都没有把 $\nu_{\min}$ 的计算当作难题：他们用的是枚举式论证，
但实际结构允许单点判定。

它们有很强的数值支持，但**尚未给出严格的代数几何证明**。

**要把结论提为定理，需要证明**：
> 对每个 $d$，$\Sigma_d^{(A)}$（(A) 定义的可行参数集）在相应格子中是**连通的**，
> 从而其上非空的 Zariski-开集稠密 —— 这即是 F2。

这是个纯粹的代数几何命题，**应该是可证的**（$\Sigma_d^{(A)}$ 由线性条件定义，是仿射子空间，故不可约）。
