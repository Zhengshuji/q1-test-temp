## 2. 证明思路总览（**一条主链 + 两个输入**）

```
        +---------------------------+
        |  输入的几何结构            |
        |  (i)  K 是 A-不变的        |
        |  (ii) A' := A|_K 幂零      |
        +-------------+-------------+
                      |
                      v
        +---------------------------+
        |  构造一行 l（对偶零化）    |  <-- 本策略的核心
        |  pi(l) 平行于 u ≠ 0        |
        |  且 pi(lA) = 0             |
        +-------------+-------------+
                      |
                      v
        +---------------------------+
        |  补行（row[C;CA] 中的行）  |  <-- (A) 保持（核形式）
        |  得到 L，满足 (A) + T5a    |
        +-------------+-------------+
                      |
                      v
        +---------------------------+
        |  (A)  ==>  F = Λ H         |
        |  F = L A N = (L N) A' = 0  |  <-- 关键恒等式
        |  ==>  Λ H = 0              |
        +-------------+-------------+
                      |
                      v
        +---------------------------+

        +---------------------------+
```

**只需两件事输入**：$K$ 的 $A$-不变性、以及诱导映射 $A'$ 有非零核 ✓。
**其余全是线性代数恒等式** ✓ —— 这正是 Lean 已机器验证的部分 ✓。

## 3. 逐步策略

### 步 1（不变性）—— $CA^2=0$ 的情形

$$\boxed{\ CA^2=0\ \Longrightarrow\ K=\ker[C;CA]\ \text{是}\ A\text{-不变的}\ }$$

**证**：$v\in K$ ⟹ $Cv=0$ 且 $CAv=0$ ✓。于是
$$C(Av)=CAv=0,\qquad CA(Av)=CA^2v=0$$
⟹ $Av\in K$ ✓ $\square$

**Lean**：`ker_inter_ker_comp_is_invariant` ✓ · `range_le_of_invariant` ✓

> **一般 $A$**：$K$ 未必 $A$-不变 ✗ —— 这是推广的真正障碍 ⚠️（见 §5）。

---

### 步 2（诱导映射幂零 ⟹ 核非零）

$$\boxed{\ K\ne0\ \wedge\ A'^2=0\ \Longrightarrow\ \ker A'\ne0\ }$$

**证**：$A'^2=0$ ⟹ $\operatorname{im}A'\subseteq\ker A'$ ✓。
秩-零化度：$\dim\operatorname{im}A'+\dim\ker A'=\dim K$ ✓ ⟹ $2\dim\ker A'\ge\dim K>0$ ✓ $\square$

**Lean**：`ker_ne_bot_of_comp_self_eq_zero` ✓

---

### 步 2′（对偶形式，**构造性**）

$$\boxed{\ A'\ne0\ \wedge\ A'^2=0\ \Longrightarrow\ \exists f:D\to K,\ f\ne0\ \wedge\ f\circ A'=0\ }$$

**证**：
1. $A'$ **不满射** ✓ —— 若满射，则 $\forall y,\ y=A'x\Rightarrow A'y=A'^2x=0$ ✓ ⟹ $\top\le\ker A'$ ⟹ $A'=0$ ✗ 矛盾 ✓
2. $\operatorname{im}A'\ne\top$ ⟹ 对偶零化子 $(\operatorname{im}A')^\circ\ne\bot$ ✓
3. 取 $0\ne f\in(\operatorname{im}A')^\circ$ ✓ ⟹ $f$ 在 $\operatorname{im}A'$ 上为 0 ✓ ⟹ $f\circ A'=0$ ✓ $\square$

**Lean**：`exists_dual_comp_eq_zero` ✓

> **此步把"$u$ 的存在"从假设变成构造** ✓ —— 这是保留 ③ 的消除 ✓。

---

### 步 3（行提升）

$$\boxed{\ \ker N\le\ker f\ \Longrightarrow\ \exists l:V\to W,\ l\circ N=f\ }$$

**证**（三步，全是线性代数）：
1. $\ker N\le\ker f$ ✓ ⟹ $f$ 过商 $D/\ker N$ 分解 ✓
2. $D/\ker N\cong\operatorname{im}N$ ✓ （`quotKerEquivRange`）
3. **域上每个子空间是直和项** ✓ ⟹ 把 $\operatorname{im}N$ 上的映射**扩张**到 $V$（补空间上取 0）✓ $\square$

> **第 3 步不平凡** ✓ —— 它需要"$\operatorname{im}N$ 是直和项" ✓（域上成立 ✓，一般环上不成立 ✗）

**Lean**：`exists_comp_eq_of_ker_le_ker` ✓
**推论**：$N$ 单射 ⟹ 存在左逆 $\pi$ ✓ —— `exists_leftInverse` ✓

---

### 步 4（$\pi(lA)=0$ —— 机制的关键）

$$\boxed{\ A\circ N=N\circ A'\ \wedge\ (l\circ N)\circ A'=0\ \Longrightarrow\ l\circ A\circ N=0\ }$$

**证**：
$$l\circ A\circ N=l\circ(A\circ N)=l\circ(N\circ A')=(l\circ N)\circ A'=0\qquad\square$$

**Lean**：`comp_A_comp_N_eq_zero` ✓ · `exists_row_with_comp_A_eq_zero` ✓

> **这一步是 §20 数值验证过的机制** ✓：$u\in\ker A'$ ⟹ $\pi(lA)=0$ ✓。

---

### 步 5（补行保持 (A)）—— **必须用核形式**

$$\boxed{\ L'=L+P_0C+P_1CA\ \wedge\ CA^2=0\ \Longrightarrow\ (\text{A})\ \text{的核形式被保持}\ }$$

**证**：设 $v$ 被 $L',C,CA$ 同时杀掉 ✓。则
$$Lv=L'v-P_0(Cv)-P_1(CAv)=0$$
由 (A) 的核形式 ⟹ $L(Av)=0$ ✓。于是
$$L'(Av)=L(Av)+P_0(CAv)+\underbrace{P_1(CA^2v)}_{=0}=0\qquad\square$$

**Lean**：`condA_of_add_row_mem` ✓

---

### ⚠️ 步 5 的一个重要澄清（**编译器抓出的错误**）

我原先以为**任意**行组合 $L'=\Phi L+P_0C+P_1CA$ 都保持 (A) 的**显式分解** ✗ —— **这是错的** ✗：

$$\text{计算得}\ \Phi\Lambda L\ \text{vs}\ \Lambda'\Phi L\ \Longrightarrow\ \text{需}\ \Phi\Lambda=\Lambda\Phi\ \text{—— 一般不成立}\ ✗$$

**推论**：
- **(A) 的显式 $(\Lambda,G_0,G_1)$ 分解**：**不**被行组合保持 ✗
- **(A) 的核形式（= 秩条件）**：**被**保持 ✓ ✓

**⟹ 形式化时必须用核形式** ✓ —— 这正是"用 Lean 验证"直接避免的一个实质错误 ✓。

---

### 步 6–7（(A) ⟹ $F=\Lambda H$，及 (S) 失败）

**步 6**：由 (A) 得分解 $LA=\Lambda L+G_0C+G_1CA$ ✓。右乘 $N$：
$$F=\underbrace{LA\,N}_{F}=\Lambda\,L\,N+\underbrace{G_0\underbrace{CN}_{=0}}_{\text{因 }N\hookrightarrow K}+\underbrace{G_1\underbrace{CAN}_{=0}}_{\text{因 }N\hookrightarrow K}=\Lambda H$$

**Lean**：`F_eq_Lam_comp_H` ✓

**步 7**：由上面的构造 $\pi(lA)=0$ ⟹ 对构造出的 $L$ 有 $F=0$ ✓；于是 $0=F=\Lambda H$ ✓ ⟹ $\operatorname{im}H\subseteq\ker\Lambda$ ✓ —— 且 $\operatorname{im}H\ne0$ ✓。
由 **T5**（已机器验证 ✓）：若 $\operatorname{im}H\cap\ker(\lambda I-\Lambda)\ne0$ 对某个 $\lambda$ ✓，则 (S) 失败 ✓。取 $\lambda=0$ ✓：
$$\Lambda H=0\ \Longrightarrow\ \operatorname{im}H\subseteq\ker\Lambda=\ker(0\cdot I-\Lambda)\ \Longrightarrow\ \textbf{(S) 失败}\qquad\square$$

**Lean**：`S_fails_of_ker_meets_range` ✓ · `S_fails_of_comp_eq_zero` ✓ · `range_le_ker_of_comp_eq_zero` ✓

## 4. 组装：最终定理

把步 1–7 合起来 ✓：

$$\boxed{\ \textbf{c6'}:\ \underbrace{(\text{A})}_{}\ \wedge\ \underbrace{N\hookrightarrow K}_{}\ \wedge\ \underbrace{A\circ N=N\circ A'}_{\textbf{步 1}}\ \wedge\ \underbrace{(L\circ N)\circ A'=0}_{\textbf{步 2′–4}}\ \wedge\ \underbrace{H\ne0}_{}\ \Longrightarrow\ \textbf{(S) 失败}\ }$$

**Lean 定理名**：`c6'_final` ✓ · **辅助**：`c6'_conditional` ✓ · `c6'_conditional'` ✓ · `c6'_CA2_zero` ✓ · `c6'_contrapositive` ✓

**⟹ 若 c6′ 成立**，则结合 **T12**（不平行 ⟹ NO ✓ 已证）：
