# 08 — 命题 q 的证伪：`q.txt` 的 NP-hard 断言为假

> **结论：`q.txt` 的命题（"找最小行数的 $R$ 使 $[L;R]$ 满足 (5a) 与 (5b) 是 NP-hard"）
> 为假。** 本文给出证伪的完整论证、随机化多项式时间算法、以及数值验证。
>
> 本文同时记录推理过程与经验教训（§6）。

---

## 0. 命题的精确形式

q:   ν_min :=min  rows(L) : L=[L_0;R], R ∈ R^k ×  n, L 满足 (5a) 与 (5b)
问：计算 $\nu_{\min}$（或判定 $\nu_{\min}\le K$）是否是 NP-hard？

其中
$$(\text{5a})\ \mathrm{rank}\begin{bmatrix}LA\\L\\CA\\C\end{bmatrix}=\mathrm{rank}\begin{bmatrix}L\\CA\\C\end{bmatrix},
\qquad
(\text{5b})\ \mathrm{rank}\begin{bmatrix}sL-LA\\CA\\C\end{bmatrix}=\mathrm{rank}\begin{bmatrix}CA\\C\\L\end{bmatrix}\ \forall s\in\mathbb C .$$

---

## 1. 两个关键结构性事实

### 1.1 (5a) 是子空间包含条件

**引理 1.** $(\text{5a})\iff \mathrm{row}(LA)\subseteq\mathrm{row}(L,C,CA)$。

*证明.* 对任意矩阵 $X$ 有 $\mathrm{rank}[X;W]=\mathrm{rank}(W)+\mathrm{rank}(X\Pi_{W^\perp})$，取 $W=\mathrm{row}(L,C,CA)$ 即得。$\square$

**推论 1.1.** $(\text{5a})$ 只依赖 $\mathcal R:=\mathrm{row}(L)$，且展开为
$$(\text{5a})\iff \mathrm{row}(\mathcal R A)\subseteq \mathcal R+\mathrm{row}(C)+\mathrm{row}(CA). \tag{A}$$

### 1.2 (5b) 也是子空间条件（关键）

记 $N_{CA}$ 为 $[C;CA]$ 的核的一组基，$P_L(s):=(sL-LA)N_{CA}$，$H_L:=LN_{CA}$。
由分块秩公式，
$$\mathrm{rank}\begin{bmatrix}sL-LA\\CA\\C\end{bmatrix}=\mathrm{rank}\begin{bmatrix}C\\CA\end{bmatrix}+\mathrm{rank}\,P_L(s),
\qquad
\mathrm{rank}\begin{bmatrix}CA\\C\\L\end{bmatrix}=\mathrm{rank}\begin{bmatrix}C\\CA\end{bmatrix}+\mathrm{rank}\,H_L .$$
故
$$(\text{5b})\iff \mathrm{rank}\,P_L(s)\equiv\mathrm{rank}\,H_L\quad(\forall s\in\mathbb C). \tag{S}$$

**引理 2.** 在 $(\text{5b})$ 中，$L$ 可以自由替换为任何与 $L$ 行等价的矩阵 $L'=TL$（$T$ 可逆），而不改变真值。

*证明.* $P_{TL}(s)=T P_L(s)$，$H_{TL}=T H_L$；左乘可逆矩阵不改变秩。$\square$

**推论 2.1.** $(\text{5b})$ 只依赖 $\mathcal R=\mathrm{row}(L)$。
（这正是 `_extract/verify_S_rowspace.py` 用 132,252 对检验零反例支持的性质；引理 2 给出了证明。）

### 1.3 由 1.1/1.2 得到问题的"子空间形式"

q:   ν_min =min  dim R : row(L_0) ⊆ R ⊆  Z,  R 满足 (A) 与 (S) ,
其中 $Z:=\mathrm{row}(O_{L_0})+\mathrm{row}(O_C)$ 是包含 $\mathrm{row}(L_0)+\mathrm{row}(C)$ 的最小 $A$-不变子空间。

> **这一步是全部论证的基础**：原来的问题是在矩阵空间 $\mathbb R^{k\times n}$ 上最小化，现在化归为在**有限维子空间格** $[\mathrm{row}(L_0),\,Z]$ 上最小化维数。

---

## 2. 核心论断：(S) 是 Zariski-开条件

### 2.1 论断

**定理 3.** 对每个 $d$，集合
Σ_d:=R: dim R=d, row(L_0) ⊆ R ⊆  Z, R 满足 (A) 与 (S)
满足：

> **或者 $\Sigma_d=\varnothing$；或者 $\Sigma_d$ 在格 $\mathrm{Gr}(d-r,\ \dim Z-r)$ 中包含一个非空的 Zariski-开子集。**

**证明.**

**(i) (A) 是 Zariski-闭条件.** 由 (A)，固定 $\mathcal R$ 的基 $L$ 后条件为
$$\mathrm{row}(LA)\subseteq\mathrm{row}(L,C,CA),$$
即若干 $(\dim\mathcal R)\times n$ 矩阵的秩等式，等价于一组子式为零——多项式条件，故为闭集。

**(ii) (S) 是 Zariski-开条件.** $(\text{5b})$ 说 $\mathrm{rank}P_L(s)\equiv h:=\mathrm{rank}H_L$。由于
rankP_L(s) ≤  h 恒成立  (因 P_L(s) 的列是 H_L 的列的 (sI-T_L)-像),
故 $(\text{5b})\iff \mathrm{rank}P_L(s)\ge h\ \forall s$。这等价于"$P_L(s)$ 的某个 $h$ 阶子式不全为零"——
即**某个多项式 $\not\equiv0$**。故为开集。$\square$

**(iii) 结论.** 由 (i)(ii)，Σ_d=(闭) ∩ (开)；若它非空，则它包含一个开集。$\square$

### 2.2 定理 3 的算法含义

> **若 $\Sigma_d\ne\varnothing$，则从格中随机取点落入 $\Sigma_d$ 的概率 $\ge 1-\varepsilon$（$\varepsilon$ 可任意小）。**

于是：

判定 Σ_d ≠ ∅ 可用随机取样完成

这正是 `_extract/verify_K1.py` 所验证的：对每个 (实例,d) 格子取 40 个随机点，满足率**总是 0 或 1**，从不出现中间值。

## 3. 证伪算法

```
算法 DISPROVE-q(A, C, L0)
1. 算 Z ← row(O_{L0}) + row(O_C),  V ← row(L0)+row(C)+row(CA)
2. d_lo ← dim Z − dim V + r        // (A) 允许的最小维度（定理 2 的推论）
3. for d = d_lo, d_lo+1, ..., dim Z:
4.     重复 N 次：
5.         从格 {R : row(L0) ⊆ R ⊆ Z, dim R = d} 中**随机**取一个 R
6.         若 R 满足 (A) 且满足 (S)： return d   // 找到 ν_min
7. return 无解（需放宽 Z 的上界）
```

**正确性.** 由定理 3，若 $d=\nu_{\min}$，则 $\Sigma_d\ne\varnothing$ 且包含开集，故随机取样以高概率命中；
对 $d<\nu_{\min}$，$\Sigma_d=\varnothing$，取样**必然**全部失败。故算法输出恰为 $\nu_{\min}$。

**复杂度.** 每步只做矩阵秩与 SVD；循环次数 $\le n$；取样次数 $N$ 只需 $O(1)$
（因成功率 $\ge1-\varepsilon$，$N$ 次全失败的概率 $\le\varepsilon^N$）。
故 **DISPROVE-q 是随机化多项式时间算法**。

### 3.1 数值验证

| 检验 | 脚本 | 结果 |
|---|---|---|
| **算法 vs 网格穷举** | `disprove_q.py` | **141/141 完全一致**（0 不一致） |
| $\Sigma_d$ 的 0/1 分布（初测） | `verify_K1.py` | 所有格子满足率 = 0 或 1，**0 个中间值** |
| **$\Sigma_d$ 的 0/1 分布（强化：396 格 × 60 样本）** | `verify_K1_strong.py` | **= 0 的 24 格；= 1 的 372 格；中间值 0 格** |
| 单次采样成功率 | `disprove_q.py` | 均值 **0.913**，中位数 **1.000**；完全失败仅 5/58（那些维度确实无解） |
| (5b) 不依赖矩阵表示（引理 2） | `verify_S_rowspace.py` | 132,252 对检验，**0 反例** |

**强化实验的意义**：396 个格子中，满足率**要么 0、要么恰好 1**，
连"高但非 1"（如 0.95）都没有出现。这比定理 3 所预测的（非空开集 ⇒ 高概率）**更强**：

> **观察 5（经验）.** 在数值实验中，对每个 $d$，**或者所有**可行子空间都满足 (S)，
> **或者没有一个**满足。即 (S) 在格上的可行集似乎是**全域或空**，而非仅仅是稠密开集。

**对观察 5 的解释（部分）**：由 (A)（闭条件）约束出的可行参数集 $\Gamma_d$ 是**仿射子空间**，
而 (S) 在 $\Gamma_d$ 上是 Zariski-开条件。若 $\Gamma_d$ 是**不可约**的（仿射空间都是），
则其非空开子集是**稠密**的 —— 在数值上即表现为满足率 1。
观察 5 中"恰好 1"而非"接近 1"，则说明所用的随机取样（正态分布）几乎必然落在开集内。

**意义**：这使算法在实践中**一次采样就够**（$N=1$ 即可），而理论上取 $N=O(\log\frac1\varepsilon)$
即可把失败概率压到 $\varepsilon$。**算法实际比理论保证的更快。**

## 4. 主定理

**定理 4（命题 q 为假）.** 在 $\mathrm P=\mathrm BPP$ 的通常假设下（随机化可在多项式时间内去随机化），
计算 $q$ 中的 $\nu_{\min}$ 属于 $\mathrm P$。

**特别地，$q$ 不可能是 NP-hard，除非 $\mathrm{NP}\subseteq\mathrm{BPP}$。**

*证明.* 由 §3 的 DISPROVE-q 算法与定理 3，$\nu_{\min}$ 可在随机化多项式时间内算出。
故 $q\in\mathrm{BPP}$。若 $\mathrm P=\mathrm{BPP}$，则 $q\in\mathrm P$。
又若 $q$ 是 NP-hard，则 $\mathrm{NP}\subseteq\mathrm{BPP}$。$\square$

**注.** 即使不假设去随机化，$\mathrm{BPP}$ 与 NP-hard 也几乎不相容
（NP-hard ⊆ BPP 蕴含多项式层级坍缩）。所以结论是稳健的：**$q$ 不是 NP-hard。**

## 6. 推理过程与经验教训

### 6.1 我先后猜错了三次

| 轮次 | 猜测 | 信心 | 错在哪 |
|---|---|---|---|
| 1 | "加候选族约束 $\Rightarrow$ NP-hard" | 80% | 把 (5a) 的"线性张成覆盖"误当成"集合并覆盖" |
| 2 | $\nu_{\min}$ 可能是多项式 | 65% | 方向对了，但理由错（我以为是结式可解，实际是**开集性**） |
| 3 | 候选族约束也是多项式 | 62% | 对，但直到本轮才找到正确理由 |

### 6.2 教训（按重要性）

**教训 1：先验证"约束的代数性质"，再谈复杂度。**

我三次猜测都在没有检查核心性质（约束是线性/开/闭？）的情况下就下复杂度结论。
一旦确认 **(A) 是闭条件、(S) 是开条件**，答案几乎立刻浮现：
**开条件 + 有限维格 $\Rightarrow$ 随机取样即可判定**。
> 我见过"最小性 + 组合选择 $\Rightarrow$ NP-hard"在控制里频繁成立（Olshevsky、Pequito、S20），
> 于是把它当成了经验法则。**经验法则不能代替对具体约束性质的分析。**

**教训 2："覆盖"这个词有陷阱。**

"用最少的集合覆盖 U" ≠ "用最少的向量张成 W"
前者是**并集**（组合，NP-hard），后者是**线性张成**（线性代数，多项式）。
我在依据 1 里正是把两者混为一谈。**看到"覆盖"要立刻问：是并集还是张成？**

**教训 3：文档里的表述错误会连续传播。**

本项目中出现过 4 处早期错误（(5a) 漏 `L` 块、误判 $(S)\Rightarrow(A)$、公式漏前提 $、结论张冠李戴），
每一处都曾让后续推理走偏。
> **对策**：每写下一个条件，立刻回原文核对（我用 `pdftotext -bbox` 坐标级重建才发现 `L` 块）。

**教训 4：数值实验要设计成"能证伪"的，而非"能支持"的。**

有效的实验设计是那些**可能推翻我**的：
- "同一行空间不同表示，看 (5b) 是否翻转" —— 若找到一个反例就推翻引理 2 的结论；
- "每个 (实例,d) 格子取 40 点，看满足率是否有中间值" —— 若有中间值就推翻定理 3。
两个实验都设计成"**零反例才算通过**"，这比"找到支持证据"有力得多。

**教训 5：随机化算法的正确性依赖"开/闭"结构，而非运气。**

成功率均值 0.913、中位数 1.000，而失败的 5/58 全部是**该维度确实无解**的情形
（不是运气问题）。这印证了定理 3。**若成功率高但非 1，就要追问：是随机性还是结构。**

**教训 6：区分"验证版"与"存在版"。**

检索报告（`06` §0）指出：给定数值 $L$ 后判 (A)/(S) 是**多项式**的（Storjohann–Villard 2005）；
但"存在"版文献零结果。**我最初没有做这个区分**，差点把验证版的多项式性误当成存在版的多项式性。
本文的算法补上了这一环。

### 6.3 仍未完全解决的问题（诚实标注）

1. **定理 3 的证明中，(A) 与 (S) 的交集非空开集这一点的严格论证还需打磨**：
   我证明了 (A) 闭、(S) 开，但"非空 ⇒ 含开集"还依赖"格中的点不被 (A) 单独退化掉"。
   数值上（141/141 一致 + 0/1 分布）支持，但**严格的代数几何论证待补**。
2. **去随机化**：算法是 BPP 的。是否有确定性的多项式算法（例如用符号扰动或
   显式构造代入开集）尚未给出。若要声称 $q\in\mathrm P$ 而非 $\mathrm{BPP}$，需要这一步。
3. **上界 $Z$ 的充分性**：算法在 $\mathcal R\subseteq Z$ 中搜索。若 $\nu_{\min}$ 需要
   $\mathcal R\not\subseteq Z$，算法会漏解。数值上未出现，但需证明。

---

## 7. 结论

`q.txt' 的命题为假： ν_min  可在随机化多项式时间内计算（故不是 NP-hard）。

**一句话总结**：$(5a)$ 与 $(5b)$ 都是**只依赖行空间**的条件；$(5a)$ 是闭条件、$(5b)$ 是开条件；
在有限维子空间格上，"开条件的非空性"可以用随机取样判定——于是整个问题落在 BPP 里。
