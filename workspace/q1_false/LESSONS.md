# q1_false · 经验记录

> 给下一个做算法的人/子 agent：这些是已经踩过的坑，别再重复。

## 死路 / 已撤回

1. **$q_{\min}=\dim V+1$**：$n=5$ 反例。
2. **闭包 +1 / 闭包**：$q_{\min}\in\{\mathrm{cl},\mathrm{cl}+1\}$ 被 40 个反例推翻；公开例子间隔 2。
3. **层公式 / 维数捷径**：可行性不由 $(\rho,c,\mu,\nu)$ 决定。
4. **$\rho>p+1\Rightarrow$ 生成好**：反例（多实例证书）。
5. **“采样没找到 $\Rightarrow$ 不可行”**：薄集必错过；必须精确枚举或构造。

## 有效做法

1. **gcd / 结式判据**：$(5b)\iff$ 全部最大子式的 $\gcd$ 为常数；在 $\mathbb Q(\theta)[\lambda]$ 上做 Euclid。
2. **可容许 $v$ 是特征向量**：层 = 有限个纤维（$\mathbb P^r$），不是连续族；有理采样会系统错过代数数特征向量。
3. **重特征值要分方向**：同一特征空间里不同方向给出不同结果，不能只按特征值分类。
4. **一个坏点 $\Rightarrow$ 整层坏？** 不：坏集闭，但层可约；要按不可约分量判，必要时要有限不可约覆盖。
5. **交叉验证**：点值判据 + 结式判据 + Bézout 证书三路互校；本项目的两次假阳性都是靠互校抓到的。
6. **实 vs 复**：$(5b)$ 是复 $\lambda$；实 $\lambda$ 采样会误判（P2 例子 432/486 假通过）。

## 判定“是不是定理”的底线

- 实验只筛假，不确认公式；
- 一般 $\theta$ 的结论不能自动推到特殊 $\theta$（gcd 次数会掉）；
- 写“层可行”前先写清：哪个域、哪个分量、是否闭、是否包含实点。
