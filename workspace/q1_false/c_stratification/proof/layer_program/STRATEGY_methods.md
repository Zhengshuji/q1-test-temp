# 证明/证伪 $q1$ 的方法清单（2026-10-30）

> 这不是进展汇报，是把"哪条路可能走得通"按**机制**整理一遍。每条都标：需要什么、已知的障碍、目前有没有雏形。

---

## 0. 先把问题的形状钉住

$$q_{\min}=\min\{\rho+c:\ \text{层 }(\rho,c)\text{ 可行}\},\qquad
\text{层可行}\iff\exists\mathcal V\ (\text{类型条件}+(5a)+(5b))$$

已建立的三个关键性质：

| 编号 | 性质 | 状态 |
|---|---|---|
| K1 | 固定 $(\mathcal U,\mathcal H)$：$(5b)\iff$ 铅笔的极大子式 $\gcd=1$；等价于**有限**代数判据（某极大子式在 $\mathcal A$ 上不恒零）| 已证 ✓ |
| K2 | $(5a)\iff\pi(\mathcal VA)\subseteq\pi(\mathcal V)$，且**依赖提升**（$\pi(xA)$ 在 $X$ 上不良定义，偏差 = $B$）| 已证 ✓（曾两次写错，现回正）|
| K3 | $(5b)$ 是**开条件**（$(\mathcal U,\mathcal H)$ 的型层上"泛型成立"）| 实测（200 例中仅 2% 覆盖）|

**K1 + K3 合起来给出一个尖锐的推论**：

> 在固定 $(\mathcal U,\mathcal H)$ 上，$(5b)$ **几乎自动成立**。所以层的难度**不在 $\tau$**，而在于
> $$\exists(\mathcal U,\mathcal H)\ \text{满足"类型 + }(5a)\text{"}\quad\text{且}\quad \text{型层}\not\subseteq\mathrm{Bad}.$$

于是**全部难度集中在一个问题**上（记作 **CQ**，Covering Question）：

> **CQ**：给定实例与 $(\rho,c)$，判定"$(\text{类型}+(5a))$ 型层是否**完全**被 $\mathrm{Bad}$ 覆盖"。

- $\rho=2$：型层在 $\mathrm{Bad}$ 之外 ✓（容器唯一 ⟹ $\mathrm{Bad}$ 仿射 ⟹ 维数比较）⟹ 已解 ✓；
- $\rho\ge3$：$\mathrm{Bad}$ 是投影 ✗ ⟹ **CQ 开放** ✗（$\mathbb F_3$ 上已见"完全覆盖"的真实例子 ✓）。

## 1. 若要证 **$q1$ = 真（hard）**：可用的方法

### H1. gadget：把"覆盖"做成条件性的

**思路**：设计 $(A,C,L_0)$，使
$$\text{组合问题可满足}\iff \text{型层}\not\subseteq\mathrm{Bad}\ (\text{即层可行}).$$

**需要的东西**：
1. 能把组合数据编码进**类型 + $(5a)$ 的型层** ✓；
2. 能把"不可满足"翻译成"$\mathrm{Bad}$ 覆盖整个型层" ✓（即每个 $(\mathcal U,\mathcal H)$ 都让某个 $\lambda$ 秩降）✗。

**已有雏形**：$\mathbb F_3$ 上那个实例（18 个型层候选、0 个可行 ✓）—— 它证明"完全覆盖"**可以发生** ✓，
但它是**无条件**的（不依赖组合数据）✗。

**已知障碍**：$\mathrm{Bad}$ 由 $A$ 与 $\mathcal V$ 决定 ✗，不能逐条设计 ✗（Löfberg 的 gadget 能逐条设计多项式 ✗）。

### H2. 从"常秩铅笔"的已知难问题归约

**思路**：若文献里有"给定仿射族，判定是否含常秩 $\rho$ 成员"的 hardness ✓，直接归约 ✓。

**现状**：专家明确说**没有找到**这样的结果 ✗（Rubei / de Seguins Pazzis 只做结构与最大维数 ✗）。

**含义**：若走这条，我们得到的会是一个**新的 hardness 定理** ✗（价值更高，但更难）。

### H3. 从 $\exists\mathbb R$-完全问题归约（经"根的存在性"）

**思路**：$(5b)$ 失败 $\iff$ 一族多项式有公共根 ✓ —— 而"多项式的根结构"可以编码不等式吗 ✗？

**障碍**：我们的条件是 **"$\ne 0$"**（无公根/判别式非零）✗，不是 **"> 0"** ✗。
Löfberg 用的是 Routh 行列式的**符号** ✗，我们这边的自然量是**判别式/结式**，它只有"零/非零"两态 ✗，
所以经典的"符号编码"（Betweenness）**不能直接用** ✗。

**可能的变通**（未验证）：先固定 $\lambda$ 的实部符号？——但 $(5b)$ 是**所有** $\lambda$ ✗（复的）✗。

### H4. 用 $\mathbb F_p$ 上的穷尽结论"搬运"到 $\mathbb Q$

**思路**：$\mathbb F_3$ 上已找到"完全覆盖"的实例 ✓，能否**提升**到 $\mathbb Q$ ✓？

**障碍**：$\mathbb F_p$ 无解 ⟹ $\mathbb Q$ 无解 ✗不成立（反方向才成立 ✓）。且 $\mathbb C$ 上型层是正维数的 ✗。
**所以 H4 只能给出启发，不能给 hardness** ✗。

## 2. 若要证 **$q1$ = 假（polynomial）**：可用的方法

### P1. Kronecker 型 + 铅笔完成理论（目前最有希望）

**思路**：$(5b)$ 等价于"铅笔的 Kronecker 型**不含正则初等因子**"✓（等价地：无有限初等因子，且 $\operatorname{rank}Q_1=\rho$ 排除无穷初等因子；左右奇异块都允许 —— 2026-10-30 按专家意见更正 ✗）。
于是层判定 = "$\exists\mathcal V$（类型 + $(5a)$）使其铅笔的 Kronecker 型属于给定集合" ✓。

**需要**：$\exists\mathcal V$ **达到指定 Kronecker 型**的判据 —— 这正是**铅笔完成问题** ✓。
Dodig (LAA 2008) 对"行/列补全"给出了**有限条不等式** ✓；我们要的是"**子空间**补全"✗（未解决 ✗）。

**为什么这条值得试**：Kronecker 型是离散的 ✓，型条件是不等式 ✓ ⟹ 若"子空间补全"也有有限条不等式，
则层判定是**有限检验** ✓ ⟹ 多项式（在固定 $\rho$ 下）✓。

### P2. 证明"$\mathrm{Bad}$ 在型层上是真子集"（构造一个坏集之外的点）

**思路**：若能在型层里**显式构造**一个使 $(5b)$ 成立的 $\mathcal V$ ✓，则层可行 ✓（并顺便证明 $\mathrm{Bad}\ne$ 型层 ✓）。

**现状**：$\mathbb F_3$ 实例说明**做不到**（型层全被覆盖 ✗）⟹ P2 作为**普遍**策略是**假的** ✗。
但可能是"除少数实例外成立" ✓ —— 那样需要**分类**"完全覆盖"的实例 ✗（未见雏形 ✗）。

### P3. 格结构 + 通用扰动

**思路**：$\{V:\ \pi(VA)\subseteq\pi(V)\}$ 对**和**封闭 ✓（已核对：$\pi((V_1+V_2)A)=\pi(V_1A)+\pi(V_2A)\subseteq\pi(V_1)+\pi(V_2)$ ✓），
所以有唯一极大元 ✓；再配合"类型条件"的等式约束 ✗。

**障碍**：类型条件是**等式**（$\dim\pi(V)=\rho$、$\dim(V\cap J)=c$）✗，格结构帮不上 ✗。

### P4. 直接对 CQ 做代数几何（消除投影）

**思路**：CQ 是"$\mathcal A\subseteq\pi_\tau(V(I))$"✓。若能把投影**消掉**（例如用 $\lambda$ 的结式/判别式 ✓），
则 CQ 变成"某些多项式是否在 $\mathcal A$ 上恒零" ✓ ⟹ 系数比较 ✓ ⟹ 有限判据（$\rho$ 固定时多项式 ✓）。

**现状**：消元后的方程次数**无界** ✗（结式的次数 = $\deg\cdot\deg$ ✗，且 $\lambda$ 的次数是 $\rho$ ✓ 但小式的个数是 $N$ ✗）⟹
子式族本身指数级 ✗（见 SCALE 文档）⟹ 只能"逐实例"，不能给算法 ✗。

## 4. 结论与下一步

$$\\boxed{\\ \\text{难度全部集中在 CQ（型层是否被 }\\mathrm{Bad}\\text{ 覆盖）；}\\textbf{P1 是唯一有明确技术路线的方向}\\ }$$

**下一步（P1 的具体化）**：
1. 把 $(5b)$ 翻成 **Kronecker 型条件**（只含零块 + 右最小指标）✓；
2. 问：给定 $\mathcal V$ 的"类型 + $(5a)$"约束，铅笔的 Kronecker 型能取哪些值 ✓ —— 这是"**子空间补全**"问题
   （Dodig 的行/列补全版本的子空间类比 ✗）；
3. 若能用**有限条不等式**刻画出这些型 ✓ ⟹ 层判定是有限检验 ✓ ⟹ 在固定 $\rho$ 下多项式 ✓ ⟹ $q1$ = 假（至少对固定 $\rho$）。
