# $(\rho,c)=(3,1)$：固定 $U,\mathcal H$ 时 $\mathrm{Bad}$ 是否覆盖 $\mathcal A$（测量）

> 2026-10-29。回应专家"目标 2"：**先固定 $\mathcal U$**，看坏集是否覆盖 $\mathcal A$。
> 脚本：[probe_31_bad.py](../../proof/rho1_layer/probe_31_bad.py)（精确有理算术）。

## 1. 设定

模型对层是忠实的：$X=\mathbb Q^d$、$\dim\mathcal U=3$、$T(\mathcal U)\subseteq\mathcal U$（即 $(5a)$ 自动成立）、
$\dim B=m$、$\beta:\mathbb Q^m\to B$ 取同构、$w=\beta(h)\in B\cap\mathcal U$ 一维（$c=1$）。
$\mathcal A=\{\tau:\beta(\tau_i)\in B\cap\mathcal U\}$（线性子空间）。
铅笔 4 行 $\times$ $d$ 列；$(5b)\iff$ 全部 $3\times3$ 子式的 $\gcd$ 为非零常数（$4\times4$ 子式自动为零，因行都在 $\mathcal U$ 里）。

对每个实例，在 $\mathcal A$ 上抽 12 个 $\tau$，判定 $(5b)$ 是否成立。

## 2. 结果

| $(d,\ m,\ \mu=\dim(B\cap\mathcal U))$ | $\mathrm{Bad}=\mathcal A$（全失败）| 有成功的 $\tau$ | 实例数 |
|---|---|---|---|
| $(3,3,3)$ | 0 | 78 | 78 |
| $(4,1,1)$ | **2** | 11 | 13 |
| $(4,2,2)$ | **1** | 31 | 32 |
| $(4,3,3)$ | 0 | 27 | 27 |
| $(4,4,2)$ | 0 | 1 | 1 |
| $(4,4,3)$ | 0 | 35 | 35 |
| $(5,2,1)$ | **1** | 1 | 2 |
| $(5,2,2)$ | 0 | 2 | 2 |
| $(5,3,1)$ | 0 | 1 | 1 |
| $(5,3,2)$ | 0 | 1 | 1 |
| $(5,3,3)$ | 0 | 28 | 28 |
| $(5,5,3)$ | 0 | 35 | 35 |

**合计**：约 200 个实例中，**"$\mathrm{Bad}=\mathcal A$" 只有 4 个**（约 2%），其余都存在成功的 $\tau$。
且同一签名 $(d,m,\mu)$ 下两种情形**都出现**（5 个签名有分歧）⟹ 该签名不决定 $\mathrm{Bad}$ 是否覆盖 $\mathcal A$。

## 3. 解读（谨慎）

1. **$(5b)$ 是"泛型成立"的**（它是个开条件）⟹ 对固定的 $(\mathcal U,\mathcal H)$，**失败是例外** ✓；
2. 于是层级别的主要门槛**不是** $(5b)$，而是"$\exists(\mathcal U,\mathcal H)$ 满足类型条件 + $(5a)$" ✓ ——
   这与 $\rho=2$ 的情形不同：那里 $(5b)$ 会真正杀死层（$w=0$ 时恒不可行）；
3. 但"例外"确实存在（4/200）⟹ **不能**把"$(5b)$ 泛型成立"当成判据 ✗；
4. 该测量只覆盖 $d\le5$、$c=1$、$\dim\mathcal U=3$ 的小样本 ✓，**不能**据此断言一般情形 ✗。

## 4. 诚实标注

- 这是**测量**，不是证明 ✗；
- 它回答的是"固定 $(\mathcal U,\mathcal H)$ 时 $\mathrm{Bad}$ 覆盖 $\mathcal A$ 有多常见"（答：**少见**），
  **没有**回答"层级别是否存在 $(\mathcal U,\mathcal H)$" ✗（那需要 $\exists(\mathcal U,\mathcal H)$ 的搜索，仍未解决）；
- 它给出一个可检验的**猜想**：$c=1,\rho\ge3$ 时"$\mathrm{Bad}=\mathcal A$"的 $(\mathcal U,\mathcal H)$ 是低维子簇 ⟹
  层判定可能主要由"类型条件 + $(5a)$"决定。此猜想**未证**，且与 §R7 的负结果不冲突（那里否定的是"秩型不变量判据"）。
