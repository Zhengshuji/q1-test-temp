# 371 判定器的可靠性修补：特征方向不能"跳过"

> 承接 357（双向判定器）与 370（复杂度）。本轮修一个**可靠性隐患**，并确认 4246 的不可行结论不受影响。

## 目标

让判定器在"$v$ 同时是 $A$ 的特征向量"（特征方向）时**不会错误地下 NO 结论**。

## 设想与理由

原实现遇到 $\operatorname{rank}\{v,Av\}=1$（特征方向）就直接 `跳过`，若其余因子全坏，
就会输出"不可行"——但被跳过的那个方向根本没检查，结论不成立。

正确做法：
- 特征方向上，纤维 = $\{V\subseteq v^\perp:\dim(V\cap K_0)=\omega\}$，参数个数 $r=\rho$；
- 现有实现只取 $\mathrm{NV}=3$ 个方向（为 $\rho-1=3$ 的非特征情形设计），
  所以对特征方向只算到纤维的一个**切片**；
- **切片上找到好点 ⟹ 可行（可靠）**；切片全坏 ⟹ **不能**推出纤维全坏 ⟹ 标"不完备"。

## 做法

把跳过改成"照算 + 打标"：
- `is_eigen = (rank{v,Av} == 1)`；
- 若 $\gcd$ 次数 0 ⟹ `生成好`（任何方向都可靠）；
- 若 $>0$ 且 `is_eigen` ⟹ `切片全坏（不完备）`；
- 汇总时：任一块生成好 ⟹ **可行**；否则若有不完备块 ⟹ **未判定**；否则 ⟹ **不可行**。

## 进展

重跑 357 的三个实例：

| seed | 结果 |
|---|---|
| 4242 | **可行**（两纤维都生成好） |
| 4245 | **可行**（$x^2-8$ 生成好） |
| 4246 | **不可行**（两因子全坏，且**都不是**特征方向）✓ |

**4246 的结论不变**——它的两个因子都是非特征方向（$r=3$ 的完整纤维），所以"全坏"是完备的。

## 最终结论

1. 判定器现在**只在完备时才下 NO**；特征方向改为"切片 + 不完备标记"。
2. 4246 不可行的结论**不受影响**（已确认两个因子都非特征）。
3. 特征方向的**完整**纤维需要 $\mathrm{NV}=\rho$（比现在多一维），未实现。

## 放弃原因

- 没有把 $\mathrm{NV}$ 参数化成 $\rho$，因此特征方向的完整纤维仍未覆盖；
- 没有构造一个"特征方向存在"的实例来测试新分支。

## 残留价值

- 一处**可靠性修补**（避免不健全的 NO）；
- 明确了"切片 ⟹ 只能证 YES"这条规则，并写进实现；
- 确认了 4246 结论的完备性。
