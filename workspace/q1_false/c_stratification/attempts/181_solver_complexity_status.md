# 求解器的复杂性定位：随机性 ≠ P/NP，工具属于“带见证验证的搜索”

> 2026-11-08。回答“算法有随机性，是否不能简单用 P/NP 衡量”。本文件把 180 的工具放进
> 复杂性框架：问题 vs 算法、随机类的前提、$\exists\mathbb R$ 上界、以及工具的正确性轮廓。
> 状态：**M2（记录）**。

## 目标

澄清三件事：
1. P/NP 分类的是判定问题，不是算法；
2. 180 的求解器不是多项式时间随机算法，不能归入 RP/BPP/ZPP；
3. $\mathrm{DEC}(q)$ / $\mathrm{MIN}(k)$ 的已知复杂性地位。

## 设想与理由

工具的随机性（$V$ 枚举、自由参数采样）容易被误读为“随机算法 ⟹ RP/BPP”或“随机 ⟹ NP”。
两者都不对：随机类要求**多项式时间**与**错误类型**；NP 要求**多项式证书 + 确定性验证**。

## 做法：逐条定位

### 1. 问题 vs 算法

- $\mathrm{DEC}(q)$：给定 $(A,C,L_0,q)$，问是否存在 $L$ 满足 $(5a)(5b)$；$\mathrm{MIN}(k)=\bigvee_{q\le k}\mathrm{DEC}(q)$。
- 180 的 `solve` 是**算法/搜索过程**，不是判定问题；它输出见证或“没找到”。

### 2. 随机类的前提

| 随机算法性质 | 类 |
|---|---|
| 零错误、期望多项式 | ZPP |
| 单边错误、多项式时间 | RP / coRP |
| 双边有界错误、多项式时间 | BPP |

180 的工具**不在**这些类：$\operatorname{Gr}(c,W_L)$ 的枚举与子式 gcd 在最坏情况下非多项式；
且 `none` 不是“高概率拒绝”，只是“有限采样没找到”。

### 3. 正确性轮廓

| 输出 | 依据 | 是否证明 |
|---|---|---|
| `FOUND`（$L$）| 七条检查（精确有理）| **是** |
| `infeasible: True`（$\dim W_L=c$，$\alpha$）| 行空间判据（165/178）| **是** |
| `none` | 有限采样 | **否** |

### 4. 复杂性地位

- $\mathrm{DEC}(q)\in\exists\mathbb R$：162（直接原铅笔证书）；
- $\mathrm{MIN}(k)\in\exists\mathbb R$：有限析取；
- **NP**：不能直接说——$\exists\mathbb R$ 的见证是实/复代数数，NP 需要有限串 + 确定性多项式验证；
- **硬度**：未知；不能由“求解器随机”推出 NP-hard 或 NP。

### 5. 工具该怎么衡量

- 正确性：见证/证书精确；
- 完备性：仅 $\dim W_L=c$ 的 forced-plane 有证明；其余是搜索；
- 复杂度：无多项式界，在 $\exists\mathbb R$ 上界之内；
- 随机性：`seed` 可复现，不是 RP/BPP。

## 进展

* 明确了“随机性 ≠ P/NP”在本项目中的具体含义；
* 工具的 FOUND/infeasible/none 三态与证明强度对应；
* 复杂性地位：$\exists\mathbb R$ 上界，硬度未定。

## 最终结论

* 180 是“带精确见证验证的搜索”，不是随机判定算法；
* 不能以“有随机过程”判定 P/NP；正确的说法是 $\mathrm{MIN\text{-}ROWS}\in\exists\mathbb R$；
* 若要得到随机多项式算法，需要逐层的多项式判定 + 单边错误 + 可去随机化，当前不具备。

## 放弃原因

* 未给工具的最坏情况复杂度上界（枚举/采样没有多项式界）；
* 未讨论 $\exists\mathbb R$ 的下界/硬度（开放）；
* 未把“见证是代数数”与 NP 证书的差距形式化。

## 残留价值

* 防止把随机搜索误标为 RP/BPP 或 NP；
* 为论文的复杂性一节提供措辞。
