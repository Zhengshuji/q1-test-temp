# 322 超平面情形：确定化不需要"掉落轨迹"，需要"全空间分量"

> 承接 93 号裁决（Q1 最高优先、走 generic gcd）与 121（底空间分量 $\le\delta+1$）、
> 123（逐分量随机点 + gcd）、44/45（掉落轨迹候选不完备）。
> 本文件提出一个**分工上的更正**：把"递归分解例外轨迹"换成"枚举全空间的不可约分量"。
> 验证：[c332](../../../../tools/verification/c332_104_component_split.py)。

## 目标

把超平面情形（$k=\omega+1$）的判定从"一侧随机算法"推进到**确定性判据**，并说清它到底还缺什么。

## 设想与理由

123 的算法是：每个分量取**一个随机点**算 gcd，永不假阳性、假阴性 $\le2^{-T}$。
44/45 认为要变确定性，必须把"gcd 掉落轨迹"枚举完（并把候选集补全）。

本文的观察是：**在不可约分量上，坏集闭（113），所以 generic point 就够**——
- generic 点好 $\Rightarrow$ 好集非空（开且稠密），分量可行；
- generic 点坏 $\Rightarrow$ 坏集含 generic 点，而坏集闭 $\Rightarrow$ 坏集 = 整个分量，分量不可行。

于是"逐分量算 generic gcd"就是一个**无假阴性、无假阳性**的判定；**掉落轨迹不需要枚举**。
123 的一侧性来自"用特化点代替 generic point"，不是问题的本质。

那 44/45 看到的"一般 $\theta$ 全失败、例外 $\theta$ 好"是什么？——**是底空间/图表的 generic，
不是分量的 generic**。全空间（lifted incidence）会分裂成分量，一支全坏、一支（可能退化成一点）好。
104 就是标准例子，本文件把它显式分解。

## 做法

**1. 判据（闭性见附录：射影入射簇 + 紧合）。** 设 $Y$ 是 lifted incidence 的一个不可约分量、法秩为 $\omega$，
$\mathcal B_Y=\{y\in Y:\exists\lambda,\operatorname{rank}P_y(\lambda)<\omega\}$ 闭。则
$$\boxed{Y\ \text{含好点}\iff \gcd\{m_I(y;\lambda)\}=1\ \text{在}\ \mathbb C(Y)[\lambda]\ \text{中}}$$
即：在 $Y$ 的**函数域**上算 generic gcd。这就是确定性的（符号计算），不需要递归。

**2. 为什么 104 的"混合"不矛盾。** 104 的可容许底空间是 $\mathbb P^1=\{\sigma=(a,-4b,b)\}$，
约束是 $y\in\ker\sigma$、$y_1=0$，于是
$$a y_1-4b y_2+b y_3=0,\ y_1=0\ \Longrightarrow\ b\,(-4y_2+y_3)=0 .$$
**乘积式**给出分解
$$Z=\{b=0\}\ \cup\ \{y\propto V_0\}=:Z_1\cup Z_2 .$$
- $Z_2$（$y$ 被压到 $\langle V_0\rangle$，底空间是整个 $\mathbb P^1$）：$\gcd=\lambda$ ⟹ **整支全坏**；
- $Z_1$（$\sigma=(1,0,0)$，$y$ 在 $S$ 中二维自由）：一般点 $\gcd=1$ ⟹ **好**；
- $Z_1\not\subseteq Z_2$（$y=(0,1,0)$ 就是反例），故 $Z$ 至少两支。

逐支看，每支内部完全一致（全坏 / 好）；"混合"只是把两支并在一起看的假象。
c332 对 194 个随机实例验证了乘积式与"$b\ne0\Rightarrow y\propto V_0$"，并在两支上各取精确有理实例：
$Z_2$ 的 6 个实例 gcd 全为 $\lambda$，$Z_1$ 的 5 个一般实例 gcd 全为 $1$。

**3. 与 93 号配方的关系（分工，不是对错）。** 93 号给的路线是
"逐分量算 generic gcd → 找次数上升的轨迹 → 递归分解"。
若分量分解**完整**，第 2 步之后全是空的（闭性把"一般坏但例外好"排除）；
若只在**图表**上做 generic，则第 2 步必须做。所以这是**分工**：
> 要么按纤维型做全空间分量分解（本文主张），要么在图表上递归追例外轨迹（93 号的配方）。
> 前者给确定判据、后者给工作面更小的局部算法——但前者不需要"候选集完备"这种脆弱假设。

## 附录：闭性的证明（**已更正**）

> **更正（专家 94 号，2026-11-16 收到）**：本节初版写的是"$\operatorname{rank}L_D<\operatorname{rank}[L_D\mid e_0]$
> 是秩条件 ⟹ 闭"，**这是错的**。专家反例：$L(x,y)=\binom{x}{y}$、$e_0=(1,0)$ 时
> "$e_0\notin\operatorname{im}L$" 等于 $\{y\ne0\}\cup\{(0,0)\}$，**不闭**；矩阵**非**包含不是闭条件
> （$L$ 的秩本身在变）。正确路线是**射影入射簇 + 紧合**，如下。

**命题（坏集闭）.** 设 $Y$ 不可约、$Y$ 上处处 $\operatorname{rank}H(y)=\omega$。则
$$\mathcal B=\{y\in Y:\ \exists\lambda\in\mathbb C,\ m_I(y;\lambda)=0\ \forall I\}$$
是 $Y$ 中的 Zariski 闭集。

*证明.* 齐次化：$M_I(y;s,t)=\det\bigl((sH(y)-tH_A(y))_{I}\bigr)$ 关于 $(s,t)$ 齐次、次数 $\omega$、
在 $(y,s,t)$ 上正则。令
$$\mathcal D=\bigl\{(y,[s:t])\in Y\times\mathbb P^1:\ M_I(y;s,t)=0\ \forall I\bigr\},$$
是闭集。在 $t=0$ 处 $M_I(y;1,0)=\det H_I(y)$，而 $\operatorname{rank}H(y)=\omega$ 保证某个 $\det H_I(y)\ne0$，
故 $\mathcal D\cap\{t=0\}=\varnothing$，于是 $\mathcal D=\{(y,[\lambda:1]):m_I(y;\lambda)=0\ \forall I\}$。
投影 $\pi:Y\times\mathbb P^1\to Y$ 是 $\mathbb P^1\to\mathrm{pt}$ 的基变换，故**紧合**；紧合映射把闭集映成闭集，
于是 $\pi(\mathcal D)=\mathcal B$ 闭。$\square$

两个要点：
- "满列秩 $\operatorname{rank}H=\omega$"是关键假设——它排除了**无穷远处的公共根**；
- Bézout 矩阵仍有用，但只作**代数判据/证书**，**不**用于证明闭性（这正是初版出错的地方）。

**域的问题（专家 94 号 §3、§6）.** 上述等价是在**代数闭域**（$\overline{\mathbb Q(Y)}$）上说的。
非空 Zariski 开集不一定含 $\mathbb Q$ 点、也不一定含 $\mathbb R$ 点（$x^2+y^2=0$ 只有原点）。
所以判据给出的是**复几何可行性**；有理/实可行性要另加论证（例如分量有有理参数化且含一个 $\mathbb Q$ 点
$\Rightarrow$ 有理点 Zariski 稠密）。

## 4. 更正：123 的按层抽样**没有**缺口（324）

> **更正（[324](324_hyperplane_component_theorem.md)）**：本节初版说"按层抽样不保证命中每个分量，104 只是运气好"。
> **该说法不成立**：324 证明每一层恰好贡献**一个**不可约分量——$\sigma\in E_\lambda$ 上的**满纤维** $F_\lambda$——
> 外加 $Z^\circ$（一般闭包）；123 对每个特征 $\lambda$ 取一个点、对开层取一个一般点，**正好命中每个分量**。
> 我担心的"同层里好分量维数更低、随机点漏掉"不会发生：同层只有一个分量。
> 保留本节的理由：它记录了这条推理弯路，且"按层抽样"的**正确性依赖** 324 的分量结构（不是无条件成立）。

## 最终结论

1. **确定性判据存在**：逐分量 generic gcd = 1 ⟺ 该分量可行。**在完整分量分解可用的前提下**，
   例外轨迹递归不是必需的中间对象（这是专家 94 号建议的精确措辞，比初版的"红鲱鱼"准确）。
   域的限制：判据是**代数闭域**上的；$\mathbb Q$ / $\mathbb R$ 点要另论（见附录）。
2. **104 的"混合"是底空间层面的**：分量层面是"一支全坏 + 一支好"（$Z=Z_1\cup Z_2$）。
   这解释了 44/45 的观察，也解释了为什么"候选集不完备"总也补不完——它补的是**跨分量**的东西。
3. **剩下的是两件，都不是几何**：
   - **全空间分量枚举**：等价于按纤维维数 / 兼容秩 / 离散剖面分层（113 的 determinantal stratification；
     93 号叫"离散 Kronecker 剖面"）。121 只做了**底空间**，全空间会再分裂（104 即例）。
   - **generic gcd 的代价**：它是对 Bézout 矩阵 $\Phi_{D_0}$ 的极大子式做 PIT
     （27.2 给 $D_0\le2d(m-1)$ 的界）。网格去随机化要对每个参数方向取 $>$ 次数个点，
     参数个数 $k-1$ 会让代价指数增长。**确定性的多项式时间 = 这个结构化 PIT 的确定性算法**（未解决）。
4. 实点问题（实输入 vs 复判定）仍未处理。

## 放弃原因

- 没有给出**全空间**分量分解的一般算法；只在 104 上做了显式分解。
- 没有证明依赖的闭性（113 的 M3），也没有独立核验它对本文件用到的"分量 ⊂ lifted incidence"是否都成立。
- PIT 的确定性代价未触及。
- $c>1$（一般余维）完全不覆盖。

## 残留价值

- 一个**判据层面的更正**：把"掉落轨迹递归"从必要步骤里去掉，换成"全空间分量枚举 + generic gcd"。
- 104 的显式两支分解（$Z=Z_1\cup Z_2$）与 c332 的验证，可作论文里的"混合 ≠ 不可判"例子。
- 给 93 号的回信准备了一个具体分歧点：**递归配方的必要性取决于分量分解的完整性**。
