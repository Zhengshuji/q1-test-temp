> **已按专家审阅修正（485 回合）**：
> ① **命题 1** 应写成**条件性良基**：对当前 $Z_k$ 的每个不可约分支 $Y$，切分多项式须满足 $D_k|_Y\not\equiv0$；
> 否则 $Y\cap\{D_k=0\}=Y$ 不下降 ✗。Noether 性只保证严格下降链有限，**不**保证每一步自动下降；
> 且过程是**递归树**（分支会分裂），不是单一集合链。
> ② **命题 3** 须把点域写成 $\mathbb R$、并把"相交"精确为
> $V(Y)(\mathbb R)\cap\mathcal P_{\mathrm{legal}}(\mathbb R)\ne\varnothing$，沿递归树 $\mathscr T$ 取并：
> $\text{层可行}\iff\exists Y\in\mathscr T:\ V(Y)(\mathbb R)\cap\mathcal P_{\mathrm{legal}}(\mathbb R)\ne\varnothing$。
> ③ 每层的实点存在性**不是黑箱**：可用 [485](485_existsR_encoding.md) 的 $\exists\mathbb R$ 编码处理（可判定、复杂度未控）。

# 484 例外集递归：泛型不可行 $\ne$ 整分支不可行；正确的判定结构是**分层证书搜索**

> 承接 [481](481_pencil_gcd_and_specialization.md)（开集级）与 [483](483_realpoint_certificate.md)（实点证书）。
> 本轮做专家指出的 484：$D=0$ 的例外集上公共因子可能降次，故必须递归。

## 目标

1. 定义例外集递归 $Z_0\supseteq Z_1\supseteq\cdots$；
2. 证明"泛型不可行 $\ne$ 整分支不可行"（并给出最小模型的实例）；
3. 写出正确的判定结构（分层证书搜索），并说明它**不是**复杂度结论。

## 设想与理由

481 引理 B(2)（更正后）只说：在 $V_-$ 上**每点**不可行。而
$$Z_1:=\mathcal B_R\cap\{D=0\}$$
上，$\tilde g$ 的首项可能退化、公共因子可能降为常数 ⟹ **例外点上反而可能可行** ✓。

这正是最小模型里发生的事：$D_I(X)=\begin{pmatrix}-X&1\\-X&2\end{pmatrix}$、$\det D_I=-X$，
泛型点 $X\ne0$ **不可行**（$\mathcal T_W=0$），而**例外点 $X=0$ 可行** ✓（[468](../../decision_algorithms/attempts/468_three_levels_and_minimal_example.md) 精确验证）。

## 做法：递归与判定结构

**递归定义.** 令 $Z_0=\mathcal B$。对 $Z_k$ 的每个不可约分支，取其函数域上最大子式的 gcd $g_k$ 与清分母多项式 $D_k$，令
$$Z_{k+1}=Z_k\cap\{D_k=0\}.$$

> **命题 1（良基）.** $Z_k$ 严格下降（当 $D_k\ne0$ 时），故递归在有限步后稳定（Noether 性）✓。

**但**——这只说明过程**会停**，不给位复杂度界 ✗（专家已明确警告）。

> **命题 2（泛型 $\ne$ 整分支）.** 若 $\deg g>0$ 于 $\mathcal B$，则 $V_-$ 上处处不可行，但 $Z_1$ 上的点**可能可行**；
> 因此"$\mathcal B$ 上泛型不可行"**不能**推出"$Z_1$ 上也不可行" ✓。

> **命题 3（正确的判定结构）.** 固定 $W$、固定 $t$ 时：
> $$\text{层可行}\iff\exists k\ \exists\text{不可约分支 } Y\subseteq Z_k:\ V_k(Y)\cap\text{(合法参数)}\ne\varnothing,$$
> 其中 $V_k(Y)$ 是 $Y$ 上引理 B(1) 给出的开集；也就是**沿递归树做证书搜索**，而不是一次 gcd 判定 ✓。

## 进展与边界

| 项目 | 结论 |
|---|---|
| 递归良基 | ✓ 命题 1 |
| 泛型 $\ne$ 整分支 | ✓ 命题 2（最小模型为实例） |
| 判定结构 | ✓ 命题 3（分层证书搜索） |
| **位复杂度** | ✗ **未给**：$Z_k$ 的分支数、每个 $D_k$ 的位长、gcd 成本均未估 |
| **实点** | ✗ 每一层的 $V_k$ 是否有实点，仍是 [483](483_realpoint_certificate.md) 的开放问题 |
| 终止性 $\Rightarrow$ 算法 | ✗ **不成立**（Noether 性不给有效界） |

## 最终结论

1. **"泛型不可行 ≠ 整分支不可行"成立**，且有最小模型这个干净实例 ✓；
2. **正确判定结构**是沿例外集递归的**分层证书搜索**（命题 3），不是一次 gcd 判定 ✓；
3. 但这一结构**还不是算法**：终止性有、复杂度没有、实点存在性也没有 ✗；
4. 因此中间层路线目前的**准确表述**仍是：
   $$\text{精确的有限维子空间刻画}+\text{逐层可检验的充分性证书},\quad\text{完整判定未闭合}\ \✗$$

## 放弃原因

- 没有估 $Z_k$ 递归的深度/分支数与位长（复杂度）；
- 没有在例外集上处理实点（把 483 的开放问题带到了每一层）；
- 没有给出"递归在几步内稳定"的界。

## 残留价值

- **例外集递归**的明确定义与良基性；
- **命题 2**（泛型 $\ne$ 整分支）及其最小模型实例——这是本项目"单点测试不够"的第三次独立确认；
- **命题 3** 给出正确的判定结构（分层证书搜索），把"泛型 gcd"放在它该在的位置。
