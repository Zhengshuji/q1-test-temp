# 462 实证：每卡一个泛型点 = 网格枚举（4/4）——461 的整卡判据可用

> 承接 461（移植 Paper III 的整卡判据）。本轮实现"按卡枚举"，并与网格枚举对照。

## 目标

验证"每卡一个泛型点"能否取代"枚举所有 $W$"。

## 设想与理由

461 的整卡判据：卡上函数域条件成立 $\iff$ 该卡每点可行。
故**每卡取一个泛型点**即可判定该卡；于是 $\exists W$ 只需查 $k$ 个卡 ✓。

对照实验：
- (a) **网格**：$q\in\{-1,0,1\}^3\setminus0$ 全枚举；
- (b) **每卡一个泛型点**：$q=(1,2,3),(2,1,3),(2,3,1)$（三个坐标卡各一个）。

## 做法

$n=5$、$p=1$、$k=3$、$\omega=2$；判定用 (R)(E$'$)（[452](452_E_simplified.md)）。

## 进展（结果）

| trial | 网格 | 每卡一个泛型点 |
|---|---|---|
| 0 | False | False |
| 1 | **True** | **True** |
| 2 | False | False |
| 3 | False | False |

**一致 4/4** ✓ —— 包括一个"可行"的实例（trial 1），两边都对 ✓。

## 最终结论

1. **461 的整卡判据得到实证支持**：每卡一个泛型点 = 网格枚举 ✓；
2. 于是中间层的判定 = **$k$ 个卡各测一次**（$O(k)$ 次线性代数），而不是枚举 Grassmannian ✓；
3. 456 的"泛型点失败"彻底解释并修复：**问题在卡，不在泛型性**；
4. 对 $q1$：中间层判定现在有**明确、可算**的算法，且代价与 $k$（$\le\ell$）相关 ⟹
   $\ell$-参数化，与 Paper I 的 FPT 框架一致 ✓。

## 放弃原因

- 只做了 4 个实例（其中 1 个可行）；
- 没有做**符号**版本的整卡验证（这里用"每卡一个泛型点"代替，理论上等价但未形式上证）；
- 没有算复杂度（卡数 $k$ × 单卡代价）。

## 残留价值

- **一次正面验证**（4/4）：整卡判据可用，中间层判定 = $k$ 次线性代数；
- 修复了 454/456 的错误结论链；
- 与 Paper I 的 $\ell$-FPT 框架对接。

## 下一步

把"每卡一个泛型点"升级为"每卡**符号**判定"（函数域），得到**无随机性**的算法；
再估 $k$ 与 $\ell$ 的关系（$\omega\le\ell$ ⟹ $k$ 相关于 $\ell$）。
