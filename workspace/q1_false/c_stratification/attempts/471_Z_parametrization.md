# 471 $Z(X)$ 的显式参数化；以及 A2 可能**不需要**的理由（决定性层是线性原像）

> 承接 470（(R)(E) 的显式秩条件）。本轮补 $Z(X)$ 的公式，并提出一个可能消掉特殊层实可行的观察。

## 目标

1. 写出 $\ker D_I(X)$ 在常秩层上的**显式有理参数化**；
2. 处理 468 留下的 A2（特殊层的实可行性）。

## 做法

在常秩层上取主元子式写出核基公式；再把秩层写成线性映射对经典确定性簇的原像，借此判断实点稠密性。

## 进展

（见下文"结果与保留意见"。）

## 设想与理由

### $Z(X)$ 的公式（选主元子式）

在 $\operatorname{rank}D_I(X)=r$ 的层上，取一个非零 $r$-子式 $\Delta$，主元列集 $P$、补集 $P^c$。则
$$\ker D_I(X)=\operatorname{col}\begin{pmatrix}-D_I^{[P]}(X)^{-1}D_I^{[P^c]}(X)\\ I\end{pmatrix},$$
其中 $D_I^{[P]}$ 是主元列组成的方阵（在层上可逆 ✓）。于是 $Z(X)$ 在层上是**$X$ 的有理函数** ✓，
与 470 的两条秩条件（$\operatorname{rank}[\bar V_0;Z_1]=a$、$\operatorname{rank}Z_2=a$）配合即得显式判定 ✓。

### A2：为什么它可能**不需要**

468 说：特殊层（$\operatorname{rank}D_I<r_{\max}$）是闭的，需做半代数实可行性。
但注意一个结构事实：$D_I(X)=C(X)B_0$ 的每一项**对 $X$ 是线性的**，且
$$\{\operatorname{rank}D_I(X)\le r\}=\Phi^{-1}\bigl(\{M:\operatorname{rank}M\le r\}\bigr),
\qquad \Phi:X\mapsto D_I(X)\ \text{线性}.$$
右端是**经典的确定性（determinantal）簇**，而它在 $\mathbb R$ 上的实点是**Zariski 稠密**的
（$\mathbb R$ 上秩恰为 $r$ 的矩阵稠密于秩 $\le r$ 的簇）✓。

于是：**秩层 = 确定性簇的线性原像** ⟹ 实点在每个秩层里**稠密** ✓ ⟹
**A1（实点稠密 + 泛型秩）可以逐层使用**，不必对特殊层另做 A2 ✓。

$$\boxed{\text{若"确定性簇实点稠密 + 线性原像保稠密"成立，则 A2 消失，A1 逐层适用}}$$

## 结果与保留意见

1. **$Z(X)$ 有显式公式**（主元子式求逆），于是两个秩条件完全可算 ✓；
2. **A2 可能不需要**：因为我们的层是**线性原像**，而实点稠密性在确定性簇上成立、并被线性原像保持 ✓；
3. **保留意见（必须核）**：
   - "线性原像保持实点 Zariski 稠密"需要证明（$\Phi$ 不必满射，但它是实数域上的线性映射，稠密集的原像稠密 —— 需要严谨写法）；
   - **有理点**版本更强（DEC 是 $\exists R\in\mathbb R$，故只需实点 ✓，但有理由版本更便于实现时用有理点）；
   - 与 467 的 $x^2+y^2$ 反例不矛盾：那个簇**不是**确定性簇的线性原像 ✓。

## 最终结论

1. $Z(X)$ 显式化 ✓（471 给出公式）；
2. **A2 很可能可以绕过**：层是确定性簇的线性原像 ⟹ 实点稠密 ⟹ A1 逐层适用；
3. 这把 468 的三层区分**简化成两层**：每个秩层都用 A1（泛型秩 + 稠密实点），**不再需要半代数可行性判定** ✓；
4. 若这一步证实，则中间层算法的逻辑链闭合，剩下的是**复杂度**。

## 放弃原因

- 没有证明"线性原像保持实点 Zariski 稠密"（只给了理由与直觉）；
- 没有验证"每个秩层实点稠密"在具体实例上的后果（例如特殊层里是否有实点避开 (R)(E)）；
- 没有重做最小模型上的 A1 判定以对照 A2 的结论。

## 残留价值

- **$Z(X)$ 的显式公式**（可直接实现）；
- **A2 可能消失**的论证路线（线性原像 + 确定性簇实点稠密），把三层简化成两层；
- 与 467 反例的相容性说明（反例不是线性原像）。
