# 376 重特征值确实要命：同一特征空间里不同方向给出不同结论

> 承接 374/375（参数化 + 单谱多项式）。按计划试"降维"（思路 1），**失败了**，并得到一个具体的反例；
> 同时验证了 372 加的守卫确实避免了错误结论。

## 目标

检验思路 1：能否把重特征值时 $\mathbb P(E_\mu)$ 的方向参数**吸收**进纤维（从而救回固定 $p$ 多项式）。

## 设想与理由

若同一 $E_\mu$ 里所有方向给出**相同**结论，方向参数就是冗余的，可以固定一个代表。反之则不能。

## 做法

构造一个重特征值实例：取 4242 的 $A$，把 $K_0$ 上的块换成 $B=\operatorname{diag}(1,1,2,3)$，
于是压缩 $M=\operatorname{diag}(1,1,2,3)$、特征多项式 $(x-3)(x-2)(x-1)^2$，$E_1$ 是 **2 维**。

在该特征空间里取 6 个方向 $v=N(c_1,c_2,0,0)$，对每个算纤维的 generic gcd。

## 进展

| 方向 $(c_1,c_2)$ | 纤维 gcd 次数 | 结论 |
|---|---|---|
| $(1,0)$ | 2 | 全坏 |
| $(0,1)$ | 2 | 全坏 |
| **$(1,1)$** | **0** | **生成好** |
| $(1,2)$ | 2 | 全坏 |
| $(2,-1)$ | 2 | 全坏 |
| $(3,1)$ | 2 | 全坏 |

**同一特征空间里，有的方向好、有的方向坏** ⟹ 方向参数**不能**丢掉。

**守卫验证**：对同一实例跑判定器，输出

```
x - 3 : 全坏（次数 2）        [完备]
x - 2 : 全坏（次数 1）        [完备]
x - 1 : 全坏（次数 2）        [不完备]   ← multi_dir 守卫触发
```

于是整体判为**未判定**（而不是错误的"不可行"）✓——而该实例**其实可行**（方向 $(1,1)$）。
若没有 372 的守卫，这里就会给出一个**错误的 NO**。

## 最终结论

1. **思路 1（降维）失败**：方向参数是真实的，不能吸收。
2. **思路 2（递归）也不解决问题**：底上的问题是"$\exists v\in\mathbb P(E_\mu)$ 使纤维生成好"，
   仍是一个含方向参数的 PIT，不能降到更小的同类实例。
3. 所以 Prop G 的多项式结论**只能停留在单谱**（375）；重特征值需要**新的想法**。
4. 但守卫是有效的：不完备时会拒绝下结论，而不是误报。

## 放弃原因

- 降维：被上述反例否定；
- 递归：底问题与原问题同型（都含"$\exists$ 方向"），没有降维；
- 没有尝试其它路线（如"用 $\mathbb P(E_\mu)$ 上的开条件做随机化 YES + 符号化 NO"）。

## 残留价值

- **一个具体的反例**，说明"每特征值取一个特征向量"会给出错误答案（这正是 101 号 §3.3 警告的）；
- **守卫有效的验证**：本实例若无守卫会误报不可行；
- 明确了固定 $p$ 多项式结论的边界（单谱）不是技术限制，而是**实质**的。
