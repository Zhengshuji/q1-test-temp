## 设想与理由

### 关键观察：分层不是逻辑必需

485 的编码
$$\exists\,(X,Y),\,a:\quad (X,Y)\in\mathcal P_{\mathrm{legal}}\ \wedge\ \operatorname{rank}X_1(X,Y)=\omega\ \wedge\ \textstyle\sum_j a_jf_j=1$$
是**逐点**条件——它在整个卡参数空间上直接成立，**无需**先分层、无需例外集、无需函数域。

$$\boxed{\text{可判定性}\ \Leftarrow\ \text{485 的单一公式；递归只用于}\textbf{避免量词消去}}$$

（递归/分层把"$(\lambda,X,Y)$ 三联的量词消去"换成"逐层的 $g$ 与 $D$"——是算法策略，不是逻辑条件。）

## 进展：六步的可计算性

| 步骤 | 数学内容 | 可计算？ | 代价 |
|---|---|---|---|
| 1 不可约分支分解 | 秩层 + 分母条件的 $\mathbb Q$-不可约分支（Galois 轨道，[465](465_Q_components.md)） | ✓ 原理上（准素分解/Gröbner） | ✗ 可能双指数 |
| 2 函数域 | $K_Y=\operatorname{Frac}(R/\mathfrak p_Y)$ | ✓ | ✗ 规模随分支涨 |
| 3 gcd | $g=\gcd_J f_J\in K_Y[\lambda]$（Euclid）或等价的消元理想生成元 | ✓ | ✗ 次数与系数位长 |
| 4 清分母 | $g=\tilde g/\delta$ ⟹ $D=$ 公分母（非零） | ✓ | ✓ 线性于项数 |
| 5 例外集 | $Z_{k+1}=Z_k\cap\{D=0\}$ | ✓ | ✓ 加一个方程 |
| 6 重参数化 | 主元子式退化 ⟹ 换卡/换主元（[480](480_grassmann_parameterization_of_FW.md) 的 $Z_{Q,P}$） | ✓ | ✗ 分支 × 卡 × 主元的簿记 |

**结论**：六步都是**可计算的代数操作**（Gröbner、一元 gcd、因式分解）⟹ 递归是**可终止、可执行的过程** ✓；
但**没有任何一步的代价有可接受的界** ✗。

## 最终结论

1. **有效性（可终止、可计算）成立** ✓：六步都有标准工具；
2. **可判定性更强且更简单**：485 的单一 $\exists\mathbb R$ 公式已经是判定程序（量词消去），**不需要**递归 ✓✓；
3. 递归/分层的价值在**效率**：它避免"$(\lambda,X,Y)$ 一起消去"，改为逐层一元 gcd；
   但其本身引入分支 × 卡 × 主元的簿记 ✗；
4. 因此 486 的诚实结论是：
   $$\text{可判定}\ \checkmark\qquad\text{可执行}\ \checkmark\qquad\text{高效}\ \times$$

## 放弃原因

- 没有实现六步中的任何一步（只做了可计算性判断）；
- 没有比较"单一公式消去"与"递归分层"两条路线的实际代价；
- 没有给出簿记规模的界（分支 × 卡 × 主元）。

## 残留价值

- **关键简化**：可判定性不需要分层，485 的公式已足够 ✓；
- 六步的可计算性清单（含代价位置）；
- "有效 $\ne$ 高效"的明确区分，避免把"递归终止"误当成算法。
