# 408 固定 $c=2$ 的复杂度定理（专家 108 号 Priority 3-10）：单谱 ⟹ $\mathrm{poly}(n,\tau)$

> 承接 393（单谱有限）、406（$W$-消去）、407（可实现图卡）、405（实一般点判据）。
> 本文件给 $c=2$ 补上与 $c=1$ 论文 §V 平行的复杂度定理。

## 目标

在**固定 $c=2$ + 实谱单谱**的许诺下，证明 $K_0$-split 层的判定是 $\mathrm{poly}(n,\tau)$
（$\tau$ = 输入 $A,C$ 的最大位长），并写清代价来源。

## 设想与理由

$c=1$ 论文的复杂度定理用的是"**几何单谱**"：底是有限个点 ⟹ 无需底图卡 ⟹ 每张图卡变量数固定
⟹ $\mathrm{poly}$。$c=2$ 的对应是：

- **底**：单谱 ⟹ $\mathcal I_2(M)$ 是**有限集**（393 推论 4），$\binom{k_{\mathbb R}}{2}+\#\{\text{共轭对}\}=O(k^2)$ 个点；
- **有效纤维**：406 ⟹ 只通过 $\Phi\subseteq D^\circ$（$\dim D^\circ=c=2$）起作用，
  故 $\Phi$ 只有 $\{0\}$、**一条直线（$\mathbb P^1$）**、$D^\circ$ 三种；$\mathbb P^1$ 用 2 张图卡；
- 所以总图卡数 $O(k^2)$，每张图卡**至多 1 个自由变量**。

这就是可算的代价。

## 做法

**模型与高度.** 输入 $A\in\mathbb{Z}^{n\times n}$、$C\in\mathbb{Z}^{p\times n}$，位长 $\le\tau$。
$N$（$K_0$ 的 $\mathbb{Q}$-基）与 $M$、$A_{21}$ 的条目是 $n\cdot\tau$ 位的有理数（Cramer/Gram 逆）；
$H$、$H_A$ 的条目同理。所有"高度"都是 $\mathrm{poly}(n,\tau)$——与 $c=1$ 论文 §V-A 的记账同型。

**引理 1（图卡数）.** 单谱时，$c=2$ 的判定算法需要至多
$$N_{\rm charts}\le 3\cdot 2\cdot\Bigl(\binom{k_{\mathbb R}}{2}+\#\{\text{共轭对}\}\Bigr)\le 3k^2$$
张总图卡（每个底点 × 3 个 $\Phi$-类 × $\mathbb P^1$ 的 2 张卡；$\Phi=\pm$ 的类只需 1 张）。

**引理 2（每张卡的变量数与次数）.** 每张图卡恰有 **1** 个自由变量 $s$，并且**参数化的是像直线**
$\Phi(s)=\operatorname{span}(\phi_0+s\phi_1)$（不是任意的 $W$ 提升）。此时 $\Phi(s)$ 只贡献**一行**，
且该行对 $s$ 仿射线性；$D^{\perp_{K_0}}$ 的行与 $s$ 无关。于是 $\lambda H-H_A$ 的每个
$\omega$ 阶子式对**行**多线性、而只有一行随 $s$ 变，故
$$\deg_\lambda\le\omega\le k,\qquad \deg_s\le 1,$$
高度 $\mathrm{poly}(n,\tau)$。

**专家 109 号 §5.1 的限定**：$\deg_s\le1$ 是**像约化定理给的**性质（只有一行变），
**不是**原 Grassmannian 纤维的通用性质——若直接参数化 $W$，可能多行同时随 $s$ 变，次数界不成立。
论文必须写明这一点。

*核对*（`c409`，$n=8,k=4$ 的一个具体图卡，$T_D$ 维 3）：
$H$ 与 $s$ 无关 ✓、$\max\deg_s H_A=1$ ✓；
六个非零 2 阶子式的 $(\deg_s,\deg_\lambda)$ 为 $(0,2)\times2$ 与 $(1,1)\times4$ ⟹ 界成立；
该卡上 gcd $=1$（可行，与 406 的 9/10 可行样本一致）。

**引理 3（每张卡的代价）.** 在 $\mathbb{Q}(s)[\lambda]$ 上算 $\omega$ 阶子式的 gcd：
- 子式个数 $\binom{q}{\omega}\binom{k}{\omega}$，每个由 $\omega!\cdot\omega^3$ 次 $\mathbb{Q}[s]$ 的乘法得到；
- 用分式自由的子结式链，单次 gcd 的代价 $\mathrm{poly}(\deg_\lambda,\deg_s,\text{高度})$；
- 总代价 $\mathrm{poly}(n,\tau)$（固定 $c=2$ 时 $\omega\le k$、维数 $\le 2$）。

**定理（$c=2$ 的复杂度）.** 在许诺
$$\text{(i) } c=2;\quad\text{(ii) } M\text{ 的实特征值互异且无重共轭对（单谱）};\quad\text{(iii) } K_0\text{-split}$$
下，层判定（三值语义）在 $\mathrm{poly}(n,\tau)$ 内完成；若输出"未定"，则算法在多项式预算内耗尽。

*证明.* 由引理 1–3：$O(k^2)$ 张卡 × 每卡 $\mathrm{poly}(n,\tau)$ = $\mathrm{poly}(n,\tau)$。
实数性由 405 的判据（$\mathbb P^1$ 的实点稠密、每点满秩）保证，不需要额外搜索。
"未定"的出现只可能来自预算上限（我们设它为 $\mathrm{poly}(n,\tau)$ 的显式函数）。$\square$

**对照（为什么去掉单谱就不行）.** 若 $M$ 有重特征值，底可以是 $\operatorname{Gr}(2,E_\lambda)$，
维数 $2(d_\lambda-2)=O(n)$；加上每张卡的 gcd 代价随变量数指数增长，就得不到 $\mathrm{poly}$。
更一般地，专家 108 号 §13.1 指出 $|\mathcal I_c(M)|=\binom{k}{c}$ 在 $c$ 变化时可指数——
所以"固定 $c=2$"这个限制是**本质的**，不是技术性的。

## 进展

- 定理的骨架、三条引理、与 $c=1$ 论文 §V 的对应关系已写出；
- 关键的新输入是 406（$W$-消去）：它把纤维从 $\operatorname{Gr}(t-w_0,T_D/W_0)$（维数可到 $O(n^2)$）
  压到**至多 1 个变量**——没有它，$c=2$ 的代价会是 $n^{O(n^2)}$ 量级；
- 诚实标注：引理 2 的"$\deg_s\le2$"是按 $W$ 的参数化估的，没逐项验算（下一轮可用 sympy 抽一个
  具体图卡验一次）。

## 最终结论

1. **$c=2$ 的复杂度定理成立**（固定 $c$、单谱、$K_0$-split）：$\mathrm{poly}(n,\tau)$；
2. 与 $c=1$ 论文的"几何单谱"完全平行：单谱 ⟹ 底有限 ⟹ 变量数固定；
3. 去掉单谱就不成立（底正维）；去掉"固定 $c$"也不成立（$\binom{k}{c}$）——
   这两条**边界**是 $q1$ 的真困难所在。

## 放弃原因

- 没做位复杂度的完整记账（高度传播只给了量级判断，未逐项给界）；
- 引理 2 的 $\deg_s\le1$ 有结构性论证（$H$ 的 $W$ 行全零），并在 `c409` 的具体图卡上核对过；
  但"清分母"的具体分母次数没算（只依赖 $W$ 的参数化是线性的）；
- 没处理"共轭对"在实数域上的可构造性（407 已标注同类问题）。

## 残留价值

- **$c=2$ 的复杂度定理**（陈述 + 三条引理 + 证明骨架），可直接进 $c=2$ 论文；
- **边界分析**：单谱与固定 $c$ 是两个本质限制，缺一不可——这比笼统的"$n^{O(c^2)}$"精确得多；
- 与 $c=1$ 论文 §V 的对应表，便于两篇互引。
