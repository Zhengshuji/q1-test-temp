# 356 修掉有理数转换 bug：结式判据与点值判据现在一致

> 承接 355（c354 报"4245 结式全零"与 c353 的点值 $\gcd=1$ 不一致）。本轮找到并修掉根因，
> 两个方法现在给出**一致**结论。

## 目标

解决 355 里那个未解的不一致（4245 的 $x^2-8$ 纤维）。

## 设想与理由

两个独立方法对同一实例给出相反结论，必有一处实现错。优先怀疑"域元素转换"这类底层代码。

## 做法

逐项核对从 sympy 有理矩阵到域元素的转换：

```python
# 错误（c353/c354 原来的写法）
Fq.elt(F(r.p), F(r.q))      # = p + q·mu  ← 把分母当成了 mu 的系数！
# 正确
Fq.elt(F(r.p, r.q))         # = p/q       ← 常数域元素
```

**这是致命的**：压缩矩阵 $M$ 的有理条目全部被读成 $p+q\mu$，于是 $M$ 整个错、特征向量错、
纤维错——c353/c354 之前的结果都不可靠。

## 进展

修掉后（其它不变）：

| seed | c354（结式，$x$ 符号） | c353（点值 gcd） |
|---|---|---|
| 4242 | **可行**（$x-1$） | **可行**（$x-1$，$x=(0,0,1)$） |
| 4245 | **可行**（$x^2-8$） | **可行**（$x^2-8$，$x=(0,0,1)$） |
| 4246 | 结式全零（未判定） | 12 样本全坏（未判定） |

**两个方法一致** ✓。4245 的"纤维生成好"现在有两条独立证据：点值 $\gcd=1$、结式非零。

## 最终结论

1. 355 的不一致**已解决**：根因是"有理数 → 域元素"的转换写错（$p+q\mu$ 而非 $p/q$）。
2. 4242 与 4245 **可行**（各有两条证据）；4246 **未判定**（两个方法都指向全坏，但没有证明）。
3. **教训**：域元素转换这种"一行底层代码"能悄悄污染整条计算链；**必须用点值/独立方法交叉验证**。
   这一轮已经是第二次靠交叉验证抓到 bug（上一次是 `p_mul` 的零系数）。

## 放弃原因

- 4246 仍未证"全坏"：需要 $K(x)[\lambda]$ 上的 gcd（有理函数域），本轮没做；
- 没有把两个方法的结论做成自动交叉检查（现在靠手工跑两次）；
- 没测更多实例。

## 残留价值

- **一处关键 bug 的修复**（有理数→域元素），使数域判定器真正可信；
- 两个方法的一致性验证；
- 再次强化"符号结果必须点值交叉验证"这条纪律。
