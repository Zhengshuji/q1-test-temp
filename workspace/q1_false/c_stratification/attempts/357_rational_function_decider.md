# 357 $K(x)[\lambda]$ 上的 gcd：判定器双向完成，4246 被证明**不可行**

> 承接 356（两个方法一致：4242/4245 可行，4246 未判定）。本轮补上**有理函数域**上的 gcd，
> 判定器变成 YES/NO 双向；4246 因此被**证明不可行**——富余档的第一个反例。

## 目标

把"纤维是否生成好"的判定从"点值样本 / 结式（只够 YES）"升级为**双向精确**：
$\deg_\lambda\gcd=0$ ⟹ 生成好；$>0$ ⟹ **全坏**。

## 设想与理由

点值与结式都只能给 YES；要证"全坏"必须在**整个** $x$ 空间上做 gcd。
把极大子式看成 $K(x)[\lambda]$（有理函数系数）里的多项式，做欧几里得即可——
$\gcd$ 的 $\lambda$-次数为 0 ⟺ 纤维生成好。

## 做法

[c355_rf_gcd.py](../../../../tools/verification/c355_rf_gcd.py)：在 c354 的多变量多项式层上加一层
有理函数（num/den 对），实现 $\lambda$-多项式的余式与欧几里得。

## 进展

| seed | 因子 | 结论 |
|---|---|---|
| 4242 | $x-1$ | **生成好** |
| 4242 | $x^3+2x^2+4x+6$ | **生成好** |
| 4245 | $x-1$ | 全坏（gcd 次数 1） |
| 4245 | $x$ | 全坏（gcd 次数 1） |
| 4245 | $x^2-8$ | **生成好** |
| 4246 | $x-1$ | **全坏（gcd 次数 3）** |
| 4246 | $x^3+4x^2+2x-5$ | **全坏（gcd 次数 3）** |

**4246 的所有可容许方向都全坏**（两个不可约因子各覆盖其共轭根，共轭不改变 $\gcd$ 的次数）⟹
**该实例的超平面层不可行**——这是富余档里第一个被**证明**不可行的实例。

**一致性**：4242 生成好（与 347 的 Bézout 证书一致）、4245 走 $x^2-8$（与 c353/c354 一致）✓。

## 最终结论

1. **判定器双向完成**：$\deg_\lambda\gcd$ 直接给出 YES/NO，不再只是"找到好点/没找到"。
2. **4246 不可行（已证）**：富余档（$n-2-p=4>3=\omega$）里存在不可行实例。
   这终于把 349/351 里反复摇摆的那个结论**正确地**立住了——机制不是"某个纤维全坏"，
   而是**全部可容许方向的纤维都全坏**。
3. 于是 $c=1$ 层（该模式）的判定链完整：
   $$\text{压缩 }M\to\text{特征多项式分解}\to K(x)[\lambda]\text{ 上的 gcd}\to\text{YES/NO}.$$

## 放弃原因

- 只测了 3 个 $n=8,p=2$ 实例；
- 只覆盖**非特征**可容许 $v$；特征方向（$v$ 也是 $A$ 的特征向量）走的是 $F_\lambda$ 分支，未在此链里；
- 复杂度未分析（有理函数 gcd 的规模增长未评估）。

## 残留价值

- **一个完整、双向、可复跑的判定器**（纯有理算术，无外部 CAS）；
- **富余档不可行的第一个实例**（4246），支撑"$\rho>p+1$ 不保证可行"；
- 三个实例的一致结论：4242 可行、4245 可行、4246 不可行。
