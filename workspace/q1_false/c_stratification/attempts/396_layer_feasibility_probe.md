# 396 层可行性的实验：$V=U_D^\perp$ 全部坏；但那些 $q$ 上纤维是单点

> 承接 395（层单调性是 $q1$ 的关键开关）。本轮想做经验检验，结果给出一个**结构性观察**：
> 在 $q=n-\dim(D+AD)$ 的那些阶上，设计被 $D$ **唯一确定**，因此"层是否可行"退化为单点检验。
> 本轮所有候选点都坏，但这**不能**推出层不可行（其它 $q$ 上还有纤维自由度）。

## 目标

检验"同一阶 $q$ 下不同层 $c$ 的可行性"，为层单调性收集数据。

## 设想与理由

最自然的构造是 $V=U_D^\perp$（$U_D=D+AD$）。若 $q=\dim U_D^\perp=n-\dim U_D$，则该 $q$ 上的设计被
$D$ 唯一确定（纤维是单点）；此时层判定 = 一次 gcd 检验，是**最便宜**的层可行性探针。

## 做法

`c396`：实例 4242（$K_0$ 块换成 $\operatorname{diag}(1,1,2,3)$，$n=8,k=4$）。对每个候选 $D$
（$c=1$ 的 4 个坐标轴、$c=2$ 的 6 个坐标对）取 $V=U_D^\perp$，核对：
(5a)、精确核 $K\cap V^\perp=D$、以及 $\omega$ 阶极大子式的 gcd。

## 进展

| $D$ | $q$ | 精确核 | (5a) | $\omega$ | gcd 次数 |
|---|---|---|---|---|---|
| $e_1$ | 6 | ✓ | ✓ | 3 | 2 |
| $e_2$ | 6 | ✓ | ✓ | 3 | 2 |
| $e_3$ | 6 | ✓ | ✓ | 3 | 1 |
| $e_4$ | 6 | ✓ | ✓ | 3 | 2 |
| $e_1,e_2$ | 5 | ✓ | ✓ | 2 | 1 |
| $e_1,e_3$ | 4 | ✓ | ✓ | 2 | 2 |
| $e_1,e_4$ | 5 | ✓ | ✓ | 2 | 1 |
| $e_2,e_3$ | 4 | ✓ | ✓ | 2 | 2 |
| $e_2,e_4$ | 5 | ✓ | ✓ | 2 | 1 |
| $e_3,e_4$ | 4 | ✓ | ✓ | 2 | 2 |

**全部不可行**（gcd 次数 ≥1）。

### 关键结构性观察

1. 在这些 $q$ 上 **$q=n-\dim(D+AD)$**，所以 $V\subseteq(D+AD)^\perp$ 且 $\dim V=q$ **强制** $V=(D+AD)^\perp$：
   纤维是**单点**。因此上表只是"这些被强制的点坏"，**不构成层不可行的证明**。
2. $c=1$ 与 $c=2$ 的候选落在**不同的 $q$**（6 与 4/5），所以它们本来就**不可比**：
   "同一 $q$ 下层的单调性"需要 $q$ 相同而 $c$ 不同，本实例的强制设计给不出这样的对。
3. 由此得到一个**便宜的层不可行探针**：对每个 $D$ 算 $q_0(D)=n-\dim(D+AD)$；在 $q=q_0(D)$ 上只需一次
   gcd 检验。若所有 $D$ 都坏，则在那些 $q$ 上层不可行（但**不影响**更小的 $q$）。

## 最终结论

1. 本轮实验**没有**回答层单调性；它只说明"强制设计"那一档全坏；
2. 真正的层可行性检验必须**在纤维上搜索**（即 394 的算法），而不是取 $U_D^\perp$；
3. 层单调性的经验检验需要一个**实现了层判定器**的环境（$c=1$ 有判定器、$c=2$ 只有算法、未实现）；
4. 记录一条可用的**便宜探针**（在 $q=n-\dim(D+AD)$ 上判不可行）。

## 放弃原因

- 没有实现 $c=2$ 的层判定器（394 的算法只写到纸面），所以无法在纤维上做层可行性的系统检验；
- 本实例的候选 $D$ 太少（只取坐标轴/坐标对），没有覆盖 $\operatorname{Gr}(2,E_\lambda)$ 的连续族；
- 没有找到同一 $q$ 下 $c=1$ 与 $c=2$ 都可比较的构造。

## 残留价值

- **"强制设计"档**（$q=n-\dim(D+AD)$）的显式检验表——这是每个 $D$ 必查的一个点；
- 便宜的**层不可行探针**；
- 明确了下一步必须先实现 394 的判定器，才能谈层单调性。
