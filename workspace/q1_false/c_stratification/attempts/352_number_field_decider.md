# 352 数域上的纤维判定器：YES 侧可用，三次域是性能墙

> 承接 350（可容许 $v$ = 压缩特征向量）与 351（纤维全坏 $\ne$ 实例不可行）。本轮把判定器写出来并试跑。

## 目标

实现 $c=1$ 层的判定：枚举压缩 $M$ 的特征值（代数数）→ 各纤维 generic gcd → 有一个 $=1$ 即**可行**。

## 设想与理由

350 之后，$v$ 不再连续，只需遍历 $M$ 的特征值。每个特征值 $\mu$ 给出特征向量 $v$，
纤维里取**有理**的 $x$-样本，在 $\mathbb Q(\mu)[\lambda]$ 上算 $\omega$-子式的 gcd。
$\gcd=1$ ⟹ 该纤维生成好（Theorem 2）⟹ 可行。

**只做 YES 侧**：找到一个好点即证可行；找不到**不**构成不可行（需要用 generic gcd 证整条纤维坏）。

## 做法

[c352](../../../../tools/verification/c352_number_field_decider.py)：
1. 构造实例 → $K_0,N$ → 压缩 $M=(N^{\mathsf T}N)^{-1}N^{\mathsf T}AN$；
2. `sp.factor_list(charpoly(M))` 分解；
3. 对每个因子求根（`sp.roots`，返回根式表达）、特征向量 $c$、$v=Nc$；
4. 跳过 $v$ 是 $A$ 的特征向量的情形；
5. 纤维里取 2–3 个有理 $x$-样本，算 pencil 的 $\omega$-子式 gcd。

## 进展

| seed | 特征多项式 | 结果 |
|---|---|---|
| 4245 | $x(x-1)(x^2-8)$ | **可行**，见证 $\mu=2\sqrt2$（$\mathbb Q(\sqrt2)$，计算快） |
| 4242 | $(x-1)(x^3+2x^2+4x+6)$ | 可行（$\mu=1$ 分支；与 347 的 Bézout 证书一致） |
| 4246 | $(x-1)(x^3+4x^2+2x-5)$ | **未判定**：三次域上的 gcd 计算**太慢**（>20 分钟未出结果） |

## 最终结论

1. **判定器在 YES 侧可用**：二次域（4245）秒级出结果；有理分支（4242）也快。
2. **三次域是性能墙**：sympy 的根式表达在 3 次代数数上做多元 gcd 不可行。
   要真正实现，需要专门的数域算术（或改用有限域/模 p 归约 + 提升）。
3. 因此 4246 仍**未判定**——不是"不可行"，是"没算完"。

## 放弃原因

- 三次域的计算没有跑完（尝试了两种路径：全量 `roots` 与逐因子，均 >20 分钟）；
- 没有实现专门的数域算术（工作量不小）；
- 没有做"整条纤维全坏"的符号判定（那需要数域上的 generic gcd，比单点更贵）。

## 残留价值

- 一个可复跑的判定器（YES 侧），并在两个实例上给出结论；
- 明确了性能墙的位置（三次域），以及绕开它的方向（模 p 归约 / 数域算术库）；
- 与 347 的证书、349 的纤维判据拼成完整流程：**枚举特征值 → 纤维 gcd → YES/未定**。
