> **更正（370 号轮）**：本文"层 1 $\iff t_2=0$"的结论**是采样假象**——该设计里 $(H_A)$ 的列 2 是 $t_2(0;w_2)$，
> 第一坐标恒 0，所以"列消失"可以靠 $w_2=0$ 实现而**不必** $t_2=0$（需要 $u_2=w_2=0$ 同时成立，随机整数几乎撞不上）。
> 真正的等式门要把锚定位置挪到 $L_0$ 的**第二项**（见 [370](../../../q1_true/multiplication_gate/attempts/408_equation_gate_layer_masking.md)）。

# 369 混合锚定：**等式可以表达**；但布尔性（两个等式的析取）还不行

> 按专家 100 号第 4 条开工（"双分支块、无秩零逃逸"）。
> 本文件有两个结果：**闭条件可表达**（正）；**布尔性构造失败**（负，附原因）。

## 目标

1. 找到"无秩零逃逸"的双分支块（专家指定的目标）。
2. 看能否由此得到布尔性条件 $t\in\{0,1\}$。

## 设想与理由

三条结构性观察（第 1、2 条来自核等式引理，第 3 条是本轮的）：

1. **每列都锚定**：核等式引理（$\ker H=\ker H_A$）迫使每个 $t_i\ne0$——$H$ 的列被锚定非零，故 $H_A$ 的对应列不能为零。
   于是**层号在纯锚定块里不产生任何分支差异**（所有层给同一个开条件）。
2. **完全不锚**：$R=0$ 给出 $H=H_A=0$、$\omega=0$，两条件平凡成立——**秩零逃逸**。
3. **只锚一列**：$\omega\ge1$（逃逸被堵死），而其余列**可以**为零 ⟹ **低层可以给出闭条件**。

第 3 条是关键：若 $\operatorname{rank}H=1$ 且有一列被锚定（该列第一坐标 $=1$），
则任何另一列 $H_{\bullet j}=(0;u_j)$ 与它成比例 ⟹ 比例系数必须为 $0$ ⟹ **$H_{\bullet j}=0$**。
再由核等式引理，$(H_A)_{\bullet j}=0$ ⟹ **$t_j=0$**——一个**等式**。

## 做法与结果

### 1. 混合锚定块（1 锚 + 1 不锚）：层 1 给等式 ✓

[c369](../../../../tools/verification/c369_mixed_anchor_branches.m)：

| $t_1$ | $t_2$ | 层 1 | 层 2 |
|---|---|---|---|
| 0 | 0 | 0 | 0 |
| 0 | 1 | 0 | 0 |
| 0 | 2 | 0 | 0 |
| **1** | **0** | **1** | 0 |
| 1 | 1 | 0 | **1** |
| 1 | 2 | 0 | **1** |
| **2** | **0** | **1** | 0 |
| 2 | 1 | 0 | **1** |
| 2 | 2 | 0 | **1** |

$$\text{层 }1\ \text{可行}\iff t_1\ne0\ \wedge\ t_2=0;\qquad
\text{层 }2\ \text{可行}\iff t_1t_2\ne0 .$$

**这就是"等式从哪来"的答案**：$t_2=0$ 是**闭条件**，由"最低层 + 部分锚定"产生。
（此前 367 里我断言"本架构只给开条件"——**这一条现在被自己的实验推翻了**。）

### 2. 布尔性构造：失败 ✗

想法：一个锚定列 + 两个不锚定列，参数取 $t$ 与 $t-1$；若"层 2 非空 $\iff$ 有一个不锚定列消失"，
就该得到 $(t=0)\vee(t=1)$。

[c370](../../../../tools/verification/c370_booleanity_gate.m) 实测：**所有 $t$ 都可行**（$-1,-\tfrac12,0,\tfrac14,\tfrac12,\tfrac34,1,\tfrac32,2$ 全为可行）。

**原因**：层 2 时 $\operatorname{rank}H=2$、三列、核 1 维，**没有哪一列必须为零**；
核等式引理只要求"$H$ 的列依赖关系与 $H_A$ 的相同"，而那个依赖关系**由对手选**
（挑 $u_i,v_i$ 就能让两边匹配）⟹ 层 2 不产生方程。

于是：**方程只在最低层出现**（那里秩不足迫使列消失）；而最低层的条件是**若干列同时消失**
——是**合取**，不是布尔性需要的**析取** $(t=0)\vee(t=1)$。

## 进展

1. **等式可表达**（层 1 的 $t_2=0$）——直接推翻了我 367 的"只给开条件"；
2. **布尔性未实现**，且障碍很具体：方程只在最低层出现，而最低层给的是合取；
3. 专家指定"双分支块"的**一半**做到了（有闭条件分支），另一半（两个等式的析取）没有。

## 最终结论

1. **本架构能表达等式**——来源是"最低层 + 部分锚定"，机制是核等式引理；
2. 但等式的出现方式是**合取型**（所有不锚定列必须同时消失）；
3. 布尔性需要**析取型**方程，目前没有构造。

## 放弃原因

- 布尔性构造失败（层 2 时对手自由度过大）；
- 没有尝试"在更高层强制某列消失"的设计（例如用固定行把某列的锚定位置错开）；
- 没有把"最低层等式"与专家建议的"双分支"设计系统化。

## 残留价值

- **一个正面结果**：闭条件（等式）可表达，来源与机制都清楚，且**推翻了我此前"只给开条件"的断言**；
- 一个**精确的负面原因**：方程只在最低层出现 ⟹ 只能给合取，不能给析取；
- 这为下一步指明了方向：**要么在更高层造出"必须消失"的结构，要么找别的析取机制**。

## 下一步

1. **在更高层强制列消失**：例如让某列的锚定位置为 0、而其"消失"由别的秩条件迫使；
2. 若能让两个不同列在**同一层**各自被迫消失，其析取就出来了；
3. 或者：用两个**独立子实例**（各自有最低层等式），再用某种"或"的组合方式——
   但组合又会回到直和，而直和给的是 AND。
