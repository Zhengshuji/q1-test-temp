# c_stratification —— 按 $c$ 分级（算法侧）

> 状态：**活跃**。上级：[q1_false](../README.md)。

## 问题

固定 $c=k-\omega$（压缩核的维数），判定该层是否可行；再问“逐层枚举”能否多项式化。

- $c=1$：超平面层（**Paper III**）。坏集闭 + 分量判据（Theorem A）、非特征层全坏（Theorem B）、
  Prop C/D；$c=1\in\mathrm P$ **尚未证明**——缺口是 S3（移动根）的 PIT。
- $c=2$：像约化与多项式判定（**Paper IV**）：行空间恒等式、可实现性两界、约化判据、单谱 $\mathrm{poly}(n,\tau)$。

## 当前卡点

1. $c=1$ 的 S3：移动根时 gcd 次数会变，需 PIT 或证明它是真障碍；
2. $c=2$ 的实点与位复杂度；
3. 一般 $c$ 的分量描述（只有 $c=1$ 的定理）。

## 下一步

先补 $c=1$ 的 S3（或把它写成显式的 PIT 障碍），再看 $c=2$ 的实设计版本。
