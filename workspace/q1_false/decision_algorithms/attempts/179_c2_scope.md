# $c=2$ 算法的适用范围与完成度（防止过度声称）

> 2026-11-08。165/166/168 之后，需要明确 $c=2$ 算法**证明了什么、没证明什么**。
> 本文件给出适用范围与完成度，供 STATUS/论文使用。状态：**M2（记录）**。

## 目标

精确界定 $c=2$、$q=3$、$\omega=2$ 算法的：
1. 已证完全的参数区间；
2. 只是“搜索”的区间；
3. 未覆盖的 $(q,\omega)$ 情形。

## 设想与理由

专家 60 号确认了 forced-plane 判据（齐次情形），但 $V$ 不被 forced（$\dim W_L>c$）时，
$\operatorname{Gr}(c,W_L)$ 是**无限**的；166 用有限功能网格枚举 $V$，**不是穷尽**。
若不写清楚，容易把“搜索到”当成“判定”。

## 做法：分层陈述

### 1. 已证完全：$\dim W_L=c$

- $V=W_L$ 被唯一确定（159/164）；
- 每个底部行的 $b_i$ 是否被强制 0 由行空间判据判定（165，Lean 内核 178）；
- 两行都强制 $\Rightarrow H$ 秩 $1<\omega$ $\Rightarrow$ **不可行**；
- 某行不强制 $\Rightarrow$ 存在秩 2 的 $H$；在自由参数上构造 $L$ 并检查 $(5a)(5b)$（166/172）。
- 对 $q=3$、$\omega=2$、$c=2$、齐次 $\mathrm{Des}$，这是**完整判定**（可行性 + 不可行证书）。

### 2. 只是搜索：$\dim W_L>c$

- $V\in\operatorname{Gr}(c,W_L)$ 无限多；166 的 `planes_in` 用 $\mathbb P(W_L^*)$ 的小整数网格
  + RREF 去重，只是**有限采样**；
- 对每个采到的 $V$，判据与构造是精确的；
- 因此：**找到 = 可行**（有见证）；**没找到 ≠ 不可行**（可能漏了 $V$）。
- 168 的实例在网格中第一个 $V$ 就成功，说明网格在简单情形够用，但不构成完备性。

### 3. 未覆盖：$q>3$ 或 $\omega\ne2$

- $q=3$ 固定 $\omega=2$、$c=2$；
- $q=4$ 可能对应 $\omega=3$（$c=1$，走 121 的超平面路线）或 $\omega=2$（$c=2$，多一行）；
- $q_{\min}$ 可能在某条**不同 $(q,\omega)$ 层**上达到；当前算法只判定 $q=3,\omega=2$ 这一层。
- 因此：**$q_{\min}=3$ 的判定**可以用当前算法（若可行）；$q_{\min}>3$ 需要另做 $q=4$ 的层。

## $q=4$、$\omega=2$ 的补充检查（2026-11-08）

对 seeds 16/21 试了 $q=4$、$\omega=2$（$c=2$，$V=W_L$ 仍 forced，三个底部行）：
每个底部行的可容许方程与 $q=3$ 时**相同**（行空间判据逐行独立），所以 $b_i$ 仍被强制 0；
三个底部行全强制 $\Rightarrow$ $H$ 秩 $1<\omega=2$ $\Rightarrow$ **$q=4,\omega=2$ 也不可行**。
脚本：`workspace/_exchange/c2_q4.py`（未入库；结论由行空间判据直接可得）。

因此 16/21 若要可行，只剩 $q=4$、$\omega=3$（$c=1$，$V$ 是 $W_L$ 中的线，**不是 forced**）
或更高 $q$ 的其他 $(q,\omega)$ 层。

**$q=4,\omega=3$（$c=1$）的采样探索（2026-11-08）**：对 $L_t=\langle w_0+t w_1\rangle$（$t\in\mathbb P^1$ 的小网格 + $\infty$）
逐 $t$ 解可容许方程、要求三个底部行的 $(b,c)$ 系数秩 2、并检验 $4\times k$ 铅笔的 $3\times3$ 子式 gcd；
seeds 16/21 在样本内**均未找到**可行见证。这不是“不可行”的证明（只采样了有限 $t$ 与有限解组合），
但说明即使 $q=4,\omega=3$ 也很难（或不可行），需要符号消元才能定论。

## 进展

* 适用范围写成三层（完全/搜索/未覆盖）；
* forced-plane 的完备性有纸面（165）+ Lean（178）+ 证书（172）；
* $\dim W_L>c$ 明确标为“搜索”，不是判定。

## 最终结论

* $c=2$、$q=3$、$\omega=2$、$\dim W_L=c$：**完整判定**；
* $\dim W_L>c$：**搜索**（找到即可行；未找到不定）；
* $q=4,\omega=2$：**不可行**（16/21，行空间判据）；$q=4,\omega=3$（$c=1$）：**未做**；
* 任何“$c=2$ 算法完成”的说法都应限定到第一条。

## 放弃原因

* 未做 $\operatorname{Gr}(2,W_L)$ 的穷尽枚举（需要有理参数化 + 消元，工作量大）；
* 未做 $q=4$ / $\omega=3$ 的层；
* 未把完备性写成算法复杂度结论。

## 残留价值

* 防止把搜索当判定；
* 为论文的“算法”一节划定边界。
