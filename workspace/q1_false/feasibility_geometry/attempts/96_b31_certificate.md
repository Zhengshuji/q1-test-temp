# 中间层可行性的真正形式：B.31（必要条件）+ 显式证书

## 目标

把"中间层可行"从观察变成**定理 + 证书**：
1. 证**必要条件**：$(5b)$ 成立且低于终阶 ⟹ $1\le\delta<r_1-p$；
2. 给出**锐利性证书**：中间层确实存在可行候选。

## 设想与理由

两条边界层的排除已经是定理：
* $\delta=r_1-p$ ⟹ $h=q+r_1$ ⟹ **B.22** 失败；
* $\delta=0$ ⟹ $\operatorname{row}(CA)\subseteq\mathcal V$ ⟹ $\mathcal V$ $A$-不变 ⟹ 可观测性 ⟹ $n\le q+p$ 矛盾。

直接取逆否即得必要条件。而"中间层是否非空且可行"不能靠逆否得到，需要**构造**（B.25 的矩形铅笔判据给了判定工具）。

## 做法

1. 写出 B.31 的证明（两行逆否）；
2. 用 `certificate_delta1.py` 搜出一个 $\delta=1$ 的可行候选，固定为证书（`proof/delta1_feasible/`）；
3. 把 B.31 的推论与 B.29 的关系写进文档。

## 进展

| 项 | 结果 |
|---|---|
| **B.31（已证）** | $(5b)$ 且 $q+p<n$ ⟹ $1\le\delta(\mathcal V)<r_1-p$ |
| 推论 | $p=1$ ⟹ $r_1\le2p=2$ ⟹ 中间层空 ⟹ 低于终阶无可行 ⟹ $q_{\min}=n-1$（解释了 B.29 的动机）|
| **证书** | $n=6$、$p=r=2$、$q=3$（$q_0=2$）、$r_1=4$、$\delta=1$：$(5a)$ ✓、$\operatorname{rank}[C;\mathcal L]=5$ ✓、$\operatorname{row}L_0\subseteq\operatorname{row}\mathcal L$ ✓、**$(5b)$ ✓** |
| 结论 | **可行性恰好住在中间层**：两边界层绝不可行（已证），中间层非空且可行（证书）|

## 最终结论

1. **B.31** 是第一个对**任意 $(p,r)$** 成立的"可行性的必要条件"，且把 B.27/B.29 从"两情形巧合"升级为"中间层不存在"的结构性解释；
2. 中间层的可行性由**显式证书**给出（不是统计）；
3. 于是 $q_{\min}$ 的刻画变成：**最小的、能取到中间层 $\delta$ 的阶**——这给了下一个明确目标。

## 放弃原因

不适用。

## 残留价值

* **B.31**：一般 $(p,r)$ 的可行性必要条件；
* **证书**：中间层可行（可复现）；
* 一条新的刻画思路（$q_{\min}$ = 最早取到中间层的阶）。

## 专家 2026-11-05 的复核：B.31 通过，并给出更强的 **B.32** 与新公式 **B.33**

**他确认**：B.31 正确（$q+p<n$ 在 $\delta=0$ 支是本质的）；B.29 是 B.31 的推论；中间层例子他**独立用有理算术复核**
（秩、零空间、可观测性、极大子式 gcd = 1）；"almost always feasible" 只能当经验描述（**不能**说成 genericity 定理）；
$q_{\min}$ 的纯几何刻画**不成立**（中间层条件必要但不充分，谱条件不能去掉）。

**他的新定理 B.32**：$r_1\le p+1\Rightarrow q_{\min}=n-p$（"终端唯一区"）——
$\rho:=r_1-p\le1$ ⟹ 中间层为空 ⟹ B.31 排除一切次终端 ⟹ 只剩终阶。$p=1$ 是它的特例（$r_1\le2=p+1$），
于是 **B.29 成为 B.32 的推论** ✓。数值核验：$\rho\le1$ 的 **385/385** 实例 $q_{\min}=n-p$ ✓；
$\rho\ge2$ 的 **812/812** 实例 $q_{\min}<n-p$ ✓。

**他的新公式 B.33**：$\dim(V/S)=q+\delta-\rho$ ⟹ 约化铅笔尺寸 $(p+q)\times(q+\delta-\rho)$ ——
分层的几何参数 $\delta$ 直接就是铅笔的列数偏移。

**一个必须记录的 bug**：我先前把 $\delta$ 算成了 $\dim(\operatorname{row}(CA)\cap\mathcal V)$（**交维数**），
与 $\delta$ 相差 $\dim\operatorname{row}(CA)$。用正确公式 $\delta=h-(q+p)$ 重扫后：**中间层 1107/1107 全可行**；
"$\delta=0$ 层 0 可行"的样本其实是**等号层** $\delta=\rho$ ✓（结论方向未受影响，但标签错了，已在 B.30 更正）。

**下一步（他的建议）**：先做 $r_1=p+2$、$\rho=2$、$\delta=1$ 这个最窄的中间层；
并把问题**分成两阶段**：几何筛选（$\mathfrak S_{q,\delta}\ne\varnothing$？）与谱筛选（约化铅笔逐点满列秩）。
他还给出 $q_{\min}$ 的精确刻画 (5.1) 与"先做几何维数、后做谱"的实施顺序。
