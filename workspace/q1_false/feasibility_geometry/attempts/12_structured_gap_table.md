# 专家 §Q5 的数据表：结构化实例上"零阶差 vs 正阶差"的对比

## 目标

按专家 2026-11-03 §Q5 的要求，为每个实例记录动力学 / 可观测性 / 代数最小 / 代数族 / 谱条件五类量，
并比较 $q_{\min}=q_0$ 与 $q_{\min}>q_0$ 的实例。

## 设想与理由

专家指出：单看 $A$ 的特征值不足以解释阶差，应把"代数族"的量（可行样本数、$h$ 的可达值）一起记录。
本脚本用三项可算代理量：$q_0$ 阶 $Z$-参数化的**可行样本数**（代数族是否厚）、$h$ 的**可达集合**、
$d_{\\rm fin}$ 的取值；并用有理根定理列出 $A$ 的有理特征值作为动力学摘要。

## 做法

[q0_scan_structured.py](../../../../tools/verification/q0_scan_structured.py)：三族结构化 $A$
（对角互异 / 对角重复 / Jordan 块）× $p\in\{2,3\}$ × $r\in\{1,2\}$，每实例在 $q_0$ 阶抽 60 个
$Z$-参数化候选；记录表中的量。

## 最终结论

（补充）**阶差 2 不是文献例子的专利**：对角族（特征值互异）$n=7,p=2,r=1,q_0=2$ 也出现阶差 2。


1. **Type III 在结构化实例上不是孤例**：7 个正阶差实例中 **2 个是 Type III**（$h<q_0+r_1$ 但仍失败），
   与 [C4](../../../../proof/refuted/C4_type3_counterexample.md) 一致；
2. **阶差与"重复特征值"没有简单对应**：`diag-distinct` 族（特征值互异）同样出现正阶差
   （$n=6,7$、$p=2,3$），所以不能说"必须重特征值"；
3. **代数族的厚度与阶差也没有简单对应**：有的实例 60/60 可行样本却全失败
   （diag-distinct 6/2/1、7/2/2），有的 1/1 就成功；
4. 因此"什么时候 $q_{\min}=q_0$"仍需结构性的判据——**不是** $A$ 的谱型，也**不是**整数不变量
   （$h,q,r_1$ 不够，见 C4）。

## 阶差分布（同族实例往上扫到 $q_0+2$）

[gap_scan.py](../../../../tools/verification/gap_scan.py) 对同一批结构化实例在 $q=q_0,q_0+1,q_0+2$ 各抽 60 个
$Z$-参数化候选（先筛 $(5a)$、再见 $(5b)$），记录**第一个可行阶**：

| 阶差 | 实例数 |
|---|---|
| $0$（$q_{\min}=q_0$）| 13 |
| $1$ | 6 |
| **$2$** | **1** |

阶差为 2 的实例是 `diag-distinct-n7`、$p=2$、$r=1$、$q_0=2$：$q=2$ 与 $q=3$ 均失败（0/3、0/60），
$q=4$ 时 60/60 全部可行 ⟹ $q_{\min}\le4$，配合低阶全失败，**阶差 2 在简单对角族里也出现**。

另有 2 个实例在 $q\le q_0+2$ 内没有找到可行阶。
