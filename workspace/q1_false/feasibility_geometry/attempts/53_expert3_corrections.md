## 进展

### (1) $h=n$ 只能作充分子例，不能作完备搜索

我们曾设想"只在 $(5a)$ 自动成立的图卡（$h=n$）上做单分层"（简报 Q1(b)）。专家纠正：
**不合法作为完备性论证**——因为 $h=n$ 不是必要条件：

> 我们自己的 $n=7$、$q=3$ 见证有 $h=5<n=7$，且两个条件都满足。

⟹ 只可用于**找见证**，不可用于**证不可行**。已记入行动清单（不要重犯）。

### (2) "一般 gcd 次数 0 ⟹ $X_{\rm sp}=X$"**说过头了**

专家 §4.4：一般次数 0 只给出**一般位置**可行（某非空 Zariski 开子集），**不能**推出每点可行。
我们此前对 seed 3023、3027 说"处处可行"，那需要**逐点**验证 $M_\rho$ 满行秩，而不是只看典型值。

正确说法（专家 §4.5）：

> 在代数可容许族的**每个不可约分支**上，典型确定性除子次数决定**一般**谱可行；
> 一般不可行分支上的例外可行点构成**构造性**（constructible）子集，且在该分支中不稠密。

并且可行集一般是 **constructible**，既不必开也不必闭。专家给了反例：
$$f(\theta,\lambda)=\theta\lambda+1,\qquad g(\theta,\lambda)=2\theta\lambda+2$$
在 $\theta\ne0$ 有公共根、在 $\theta=0$ 互素 ⟹ 好集是 $\{\theta=0\}$（**闭**，不是开）。

### (3) 在 $(5a)$ 失败处不能用零空间铅笔判据谈 $(5b)$

专家 §1/§5.1：零空间铅笔判据是在 $(5a)$ 假设下导出的。我们的 $n=6$ 实例在 $\theta=5/4$ 处
$(5a)$ 失败而"谱判据成立"——正确表述是"**辅助的零空间铅笔秩条件**成立"，不是"$(5b)$ 成立"。
要么直接核原始铅笔 $Q_{\mathcal L}(\lambda)$，要么明确标注。

### (4) 更经济的代数路线（专家 §2.1–§2.3）

* **用一次饱和替代见证枚举**：层 $\rho$ 的空集性 ⟺ $J_\rho : I_\rho(B)^\infty = R$
  （$I_\rho(B)$ 为 $[V|Z]$ 的 $\rho$-子式理想），而不是对每个见证子式做 Rabinowitsch；
* **更好：用列空间包含编码 $(5a)$**，避免第二次分层：
  $$A^{\mathsf T}X_c=[X_c\mid W_c]\,T$$
  引入辅助矩阵 $T$ 即可，不必固定 $r=\operatorname{rank}[X_c|W_c]$；
* **Q2：先做"隐式多项式矩阵"路线**——不展开极大子式，直接在 $P_Z(\lambda)$ 上算法秩/确定性除子/Smith 形；
  固定 $\theta$ 时这是标准算法，难点在参数依赖。

### (5) 优先级（专家 §6）

**先写两个主结果**（维数障碍 + 整族一致；$n=6$ 反例及两/三套证明）；
逐阶判定转为**次要但聚焦**的任务，按 (4) 的新表述试。

## 最终结论

| 项 | 结论 |
|---|---|
| $h=n$ 限制 | 只能找见证，不能证不可行（$n=7$ 的 $h=5$ 见证即反例）|
| "处处可行" | 我们说过了头；应为"一般可行"，逐点需另验 |
| 可行集形状 | constructible（不必开/必闭）；按不可约分支讨论 |
| $(5a)$ 失败点 | 不能宣称 $(5b)$；只能称"零空间铅笔秩条件" |
| 代数路线 | 饱和 + 列空间包含（一次饱和、一次分层）；先做隐式铅笔 |
| 优先级 | **先写论文**，逐阶判定作次要 |
