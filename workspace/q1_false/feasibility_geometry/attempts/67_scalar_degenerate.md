# 构件 2 失败：$\dim V=\dim K=1$ 的标量情形是**退化**的（B.13f 的二次方程没有内容）

## 目标

上一轮（attempts/66）把"不可行"写成标量情形下的一个二次方程（B.13f），并把它当作 gadget 的第一个构件。
本轮尝试"构件 2"：让 $V,K$ 依赖设计变量（把变量放进 $C$），使条件成为变量的二次式。

## 设想与理由

B.13f 的条件是 $\det[Av,\ v,\ k]=0$（等价于 B.13e 的单-$\lambda$ 证书）。若 $v,k$ 固定，它对 $A$ 的条目是**一次**的；
只有当 $v,k$ 依赖变量时才可能升次。于是把变量放进 $C$（$C(x)=(1,x,0)$），测条件的次数。

## 做法

`tools/verification/gadget_degree.py`：$n=3$、$p=r=1$、$C(x)=(1,x,0)$、$L_0=(0,0,1)$，
对每个 $x=0,\dots,6$ 精确算 $v,k$ 与 $\det[Av,v,k]$，用有限差分定次数。

## 进展

**条件恒为零**：372 个可用实例上，把 $\det[Av,v,k]$ 看成 $x$ 的函数，在 $x=0..6$ 处全部取 $0$，有限差分阶为 $-1$（恒零）。

**原因是结构性的**（不只是这一个族）：
$$v\in\ker C,\qquad Av\in\ker C\ (\text{因 }CAv=0),\qquad k\in\ker C,$$
三者都落在 $\ker C$ 里，而 $\dim\ker C=n-p$。当 $\dim V=\dim K=1$ 时唯一可能是 $n=p+r+1$ 且 $r_1=n-1$；
取 $p=r=1$ 得 $n=3$、$\dim\ker C=2$ ——**三个向量落在 2 维空间里，行列式必然恒零**。

所以：
$$\text{在 } \dim V=\dim K=1 \text{ 的情形，B.13f 的判据退化为 } v\not\parallel k\ \text{（即 } V\ne K\text{）},$$
二次方程**没有内容**（它恒成立，不提供任何信息）。

## 最终结论

1. **构件 1 需要修正**：B.13f 的"二次方程"在标量情形（唯一可实现的情形）里恒成立，故不构成有效构件；
2. 有内容的 gadget 必须从 $\dim V=\dim K\ge2$ 开始（例如 $n=4$、$p=r=1$、$r_1=2$，此时 $\dim V=\dim K=2$）；
3. 该退化还有独立价值：它说明**小维数下结构过度刚性**，把"不可行"变成了自动现象——
   这也解释了为什么 $n=3$ 上 $q=1$ 阶几乎总是不可行；
4. 方法学：符号秩/符号核在 sympy 里不可靠（本轮先试符号，得 0 个实例；改用逐点精确计算才得到结论），
   与 attempts/64 的教训一致。

## 放弃原因

构件 2 在本情形下无法实现——不是技术失败，而是**该情形结构退化**，二次条件恒为零。

## 残留价值

* 一条**结构性否定结论**：$\dim V=\dim K=1\Rightarrow$ 单-$\lambda$ 证书自动成立（$v,Av,k\subseteq\ker C$）；
* 明确了下限：gadget 必须 $\dim V=\dim K\ge2$；
* 修正了 B.13f 的适用范围（已在 docs/02 注明）。
