# 最窄中间层 $r_1=p+2$（$\rho=2$）：$\delta=1$ 层全可行、阶差 $\le2$

## 目标

按专家 2026-11-05 的建议，攻最窄的中间层情形 $r_1=p+2$（$\rho=2$，中间层只含 $\delta=1$）。

## 设想与理由

$\rho=2$ 时中间层只有一个值（$\delta=1$），几何歧义最小；由 B.33，约化铅笔尺寸为 $(p+q)\times(q-1)$。
剩下的问题按专家的说法"纯粹是谱的"。我们的证书（$n=6,p=r=2,q=3$）已经给出一个可行点，故答案是"可以"。
本轮把这一情形的统计图景做出来。

## 做法

`narrow_intermediate.py`：$n=6,7$、$p\in\{2,3\}$、$r\in\{1,2\}$、两对都可观测、**只保留 $r_1=p+2$** 的实例；
逐阶扫可容许候选，用**修正后的 $\delta=h-(q+p)$** 分层，并求最小可行阶。

## 进展

745 个实例：

| 量 | 结果 |
|---|---|
| $\delta=2=\rho$（等号）层 | **0 可行 / 742**（B.22 ✓）|
| $\delta=1$（唯一中间层）| **745 可行 / 745** |
| $\delta=0$（终阶）| 745 可行 / 745 |
| $q_{\min}-q_0$ | $0$：3 例、$1$：543 例、$2$：**199 例** |
| $q_{\min}<n-p$ | **745/745** |

## 最终结论

1. **$\rho=2$ ⟹ 次终端总是可行**（745/745 的 $q_{\min}<n-p$），与 $\rho\le1$ 的 B.32（终端唯一）形成鲜明对照；
2. $\delta=1$ 层在样本里**全部可行**（但 B.30 的薄集现象说明这只能是"几乎总可行"）；
3. **阶差 $\le2$**（$0/1/2$）——远小于 Class I 的 $n-1-q_0$；
4. 猜想：$\rho=2$ 时 $q_{\min}-q_0\le2$；一般 $\rho$ 时阶差被只依赖 $\rho$ 的函数界住。

## 放弃原因

不适用（统计图景完成；"阶差有界"仍是猜想）。

## 残留价值

* **B.34**：最窄中间层的完整统计（含等号层 0 可行、中间层全可行）；
* 一条可检验猜想（阶差 $\le2$ 当 $\rho=2$）；
* 与 B.32 的对照，构成"$\rho$ 决定是否存在次终端可行"的清晰二分。
