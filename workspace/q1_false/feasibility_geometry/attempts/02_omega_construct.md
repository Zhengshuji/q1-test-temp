# 在 $(5a)$ 可行集内**构造式**抽样，并给出两个实例的精确 $q_{\min}$

## 目标

WP2 第 2 步：不靠在 $\Theta$ 空间盲抽，而是在 $(5a)$ 的**可行集** $\Omega$ 内直接构造增广，
再判 $(5b)$。这样每个样本都是合法候选，$(5b)$ 的统计才有意义；并尽量给出**精确**的 $q_{\min}$。

## 设想与理由

$(5a)$ 等价于子空间形式
$$(5a)\iff \operatorname{row}(\mathcal LA)\subseteq\operatorname{row}(\mathcal L)+W,\qquad W=\operatorname{row}[C;CA].$$
于是：

1. **闭包** $V_{\min}$：最小的 $V\supseteq\operatorname{row}L_0$ 且 $VA\subseteq V+W$（贪心加行至封闭）。
   任何满足 $(5a)$ 的 $\mathcal L$ 都有 $\operatorname{row}\mathcal L\supseteq V_{\min}$，
   所以 $\dim V_{\min}$ 是 $(5a)$ 下的**精确最小行数**，且 $q_{\min}\ge\dim V_{\min}$；
2. **一步前像** $U=\{x:\ xA\in V_{\min}+W\}$。把任意 $u\in U$ 的行加到 $V_{\min}$ 上仍满足 $(5a)$
   （$uA\in V_{\min}+W\subseteq V'+W$）；
3. 抽样：$\mathcal L$ 的行 = $V_{\min}$ 的基 + 从 $U$ 中取的 $q-\dim V_{\min}$ 个模 $V_{\min}$ 独立的向量；
4. 逐点 `assert` $(5a)$，用 [Toeplitz 判据](../../../../proof/toeplitz_criterion/README.md) 判 $(5b)$。

**在 $q=\dim V_{\min}$ 时只有一个候选**（最小性 ⟹ $V$ 必须等于 $V_{\min}$），所以该阶的 $(5b)$
由**一个**铅笔决定——这使得"$q_{\min}=$ 闭包维数 $+k$"可以变成**精确结论**。

## 做法

[tools/verification/omega_construct.py](../../../../tools/verification/omega_construct.py)：
`closure`、`preimage`、`sample_omega`（每阶 40 个样本）。

## 进展

扫 $q=$ 闭包 $\dots\,n$）**：下表是这一版的结果（更广、更能给上界）。

**交叉核对（"是不是我们的族太窄？"）**：对两个顽固实例（$5/1001$、$5/1002$）各抽 60 个**随机满秩**
$5\times5$ 矩阵（含 $L_0$），满足 $(5a)$ 且 $(5b)$ 的**命中 0 个**。与族内结果一致，但都不是证明
（$(5b)$ 是薄条件，见 CLAUDE 纪律 12）。

**两个精确结论**（都用"$q=$闭包时唯一候选 + 该候选失败"）：

* $q_{\min}(5/1000)=3$：闭包 $=2$ 的唯一候选失败，$q=3$ 有显式见证；
* $q_{\min}(6/1001)=5$：闭包 $=4$ 的唯一候选失败，$q=5$ 有 37/40 个见证（$q=6$ 时 40/40）。

## 最终结论

* $(5a)$ 的可行集可以**构造**，不必盲抽：$V_{\min}$ + 一步前像给出全部"在 $V_{\min}$ 上加行"的增广；
* **闭包维数是 $(5a)$ 下的精确最小行数**，且 $q_{\min}\ge$ 闭包；它可以在多项式时间内算出；
* 两个实例的 $q_{\min}$ 被**精确确定**（$3$ 与 $5$），且都严格大于 $q_0$；
* 其余 10 个实例在**这个子族**（含 $q=n$ 的整体空间）里都没有找到 $(5b)$ 见证；随机满秩的交叉核对
  也没有命中。两种解读：(a) 这些实例的 $q_{\min}$ 很大或不存在（与 `h_bound` 的互补障碍同类）；
  (b) 我们的族/随机搜索太弱。**未定论**，需要更完备的 $\Omega$ 参数化或可判定的判据。

## 放弃原因

不适用（达成目标）。**未做**：把 $U$ 迭代下去（多步前像）以覆盖更大的 $\Omega$；以及 $\Omega$ 的完整参数化。

## 值得注意的差异（待核）

**闭包维数可以严格大于 $\Sigma\eta_j$**：$7/1000$（$3$ vs $4$）、$7/1001$（$3$ vs $5$）。

* 闭包是**定义级**计算（$(5a)$ 的最小 $\dim V$，多项式时间），见 `omega_construct.closure`；
* $\Sigma\eta_j$ 是 P1 §III 的全局秩保留算法的输出（本项目实现于
  [tools/ledger/c208_q0_lower_bound.py](../../../../tools/ledger/c208_q0_lower_bound.py)）；
* 二者在 $10/12$ 个实例上相等、$2/12$ 个不相等。可能是：(a) c208 的"某生成元当轮不增秩就永久淘汰"
  过早；(b) 对 P1 Thm 2 的读法（"最小**功能**维数与最小行数"是否同一量）。
  **未定论**，记为待核项；在拿到结论前，本路线的下界一律用**闭包**（定义级），不用 $\Sigma\eta_j$。

## 残留价值

* 可复用的构造式 $\Omega$-采样器（`closure` + `preimage` + `sample_omega`）；
* 两个**精确** $q_{\min}$；
* 一个待核的真实问题（$\Sigma\eta_j$ vs 闭包），它直接影响"$q_0$ 下界"的可信度。
