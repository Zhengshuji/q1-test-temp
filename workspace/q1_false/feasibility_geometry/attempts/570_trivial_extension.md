# 570 定向构造：给 530 加一个“谱不可见”的自由行

> 2026-11-27。按 569 的下一步，从 530 的 $m=0$ 实例出发加自由行。

> 但这是“平凡扩张”：额外行在 $H,H_A$ 中都是零，不改变任何条件。**
> 状态：**[已证-纸面]**。

## 构造

530 的 $q=3$ 实例（$n=7$、$k=3$、$L_0$ 三行、$H$ 秩 2 于门上、可行）。

取 $r=e_4$：$rN=0$（$N$ 取前 3 个坐标，$e_4$ 在前 3 坐标为 0），$rAN=0$（$A$ 的 $K_0$ 列在 $e_4$ 方向无分量）。

于是 $L=[L_0;r]$（$q=4$）：
$$H=\begin{bmatrix}H_0\\0\end{bmatrix},\qquad H_A=\begin{bmatrix}H_{A,0}\\0\end{bmatrix}.$$

- $(5a)$：$\ker H=\ker H_0$（零行不改变），$\ker H_A=\ker H_{A,0}$，条件不变；
- $(5b)$：$P$ 加一行零，秩不变。

所以**可行性不变**；而 $(5a)$ 非平凡（$\operatorname{rank}H=2<3$）。

## 意义与警告

- 这回答了 569 的定向构造：$m>0$ 的非平凡可行例子**存在**；
- 但它是“平凡扩张”：额外行在 $H,H_A$ 中为零，完全不影响谱；
- 因此“非平凡 $(5a)$ + 可行”本身不是困难问题——**真正的问题是额外行是否携带有效自由度**
  （即 $rN\ne0$ 或 $rAN\ne0$，且改变 $(5b)$ 的判据）。
