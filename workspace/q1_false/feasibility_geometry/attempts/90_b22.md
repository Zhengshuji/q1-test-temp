# 等号情形 $h=q+r_1$ 关闭：B.22（专家证明）+ B.8b/B.19/B.11d 全面修正 + Lean 内核

## 目标

按专家 18 号评审的意见收尾等号边界：他给出了一个**不依赖 Kronecker 形**的完整证明（B.22），
并要求我把它并入、修正 B.8b/B.19/B.11d、并形式化其中的方块因子化。

## 设想与理由

专家的证明思路（比 Kronecker 路线干净得多）：
取 $B$（$r_1\times n$，满行秩）使 $\operatorname{row}B=\operatorname{row}[CA;C]$，$H_0=[\mathcal L;B]$。
等号 $h=q+r_1$ ⟹ $H_0$ 满行秩；$(5a)$ ⟹ $\mathcal LA=KH_0$，$K=[K_1\ K_2]$；于是
$$\begin{bmatrix}\lambda\mathcal L-\mathcal LA\\ B\end{bmatrix}
=\begin{bmatrix}\lambda I_q-K_1&-K_2\\0&I\end{bmatrix}\begin{bmatrix}\mathcal L\\B\end{bmatrix}.$$
左端与 $Q_{\mathcal L}$ 同秩，右端秩 $=$ 方块秩（$H_0$ 满行秩），而方块行列式 $=\det(\lambda I_q-K_1)$ 是 $q$ 次首一多项式
—— $q\ge1$ 时必有根 ⟹ 秩跌 ⟹ $(5b)$ 失败。且方块严格等价于 $\operatorname{diag}(\lambda I_q-K_1,I_{r_1})$ ⟹ $d_{\rm fin}=q$、$d_\infty=r_1$。

## 做法

2. 修正 B.8b（正确恒等式 $h=\sum\varepsilon+d_{\rm fin}+d_\infty$，右指标全零次；"无右指标"的说法是错的）；

5. 新增 `B22.lean` 形式化两块基石（方块行列式、正次数有根）。

## 最终结论

1. **等号情形关闭**：$h=q+r_1$（$q\ge1$）⟹ $(5b)$ 必失败；配合行数界得 $h\ge q+r_1\Rightarrow(5b)$ 失败；
2. **CSS 归约（B.11d）现在无条件**（只需 CSS 本身）；
3. 专家的两个额外洞察已采纳：$\nu_\infty=h-\operatorname{rank}A_1$ 数的是**个数**（不是总次数）；
   $d_\infty$ 不能由 $\operatorname{rank}A_0,\operatorname{rank}A_1,h$ 决定（他给了同秩反例）；
4. Lean 内核覆盖方块行列式与"正次数有根"，剩余三步（$H_0$ 满行秩 ⟹ 秩不变、$K$ 存在、秩化归）为纸面。

## 放弃原因

不适用。
