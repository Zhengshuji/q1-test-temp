# 单门实现（九）：固定核 + 变量提升方向的可行族（绕过变量核障碍）

> 2026-11-09。按 68 号 Q3 的绕过思路：**不动核**，让算术变量进入提升方向 $g\in\operatorname{row}[C;CA]$。
> 在 168 实例上找到一个**单参数可行族**：$L_3(s)=s e_2+e_3+e_6$，$s\ne0$ 全部通过七项检查。
> 这是第一个“固定核、变量 $D(X)$”的真可行族。状态：**精确验证（多点）**。

## 目标

绕开 217–222 的变量核障碍：固定 $H$（核固定），用 $gN=0$、$gAN\ne0$ 的提升方向改变 $H_A$。

## 设想与理由

168 实例：$C=e_1$、$CA=e_2$、$K_0=\operatorname{span}\{e_3,\dots,e_6\}$。
$\operatorname{row}[C;CA]=\operatorname{span}\{e_1,e_2\}$；$g=e_2$ 满足
$$gN=0,\qquad gAN=e_3+e_6\ne0.$$
所以把 $e_2$ 加到某行 $L$ 上：$H$ 不变、$H_A$ 改变 $e_3+e_6$。

## 做法

取基见证 $L=[e_3;\ e_3+e_6;\ e_2+e_3+e_6]$，把第三行的 $e_2$ 系数参数化：
$$L_3(s)=s e_2+e_3+e_6,\qquad L(s)=[e_3;\ e_3+e_6;\ L_3(s)].$$
则 $H$ 固定：
$$H=[e_3;\ e_3+e_6;\ e_3+e_6],\qquad
H_A(s)=[e_3;\ e_3+3e_6;\ (1+s)e_3+(3+s)e_6].$$
`check_candidate`（有理精确）：

| $s$ | $(5a)$ | $(5b)$ | $\operatorname{rank}[C;L]$ |
|---|---|---|---|
| $1$ | ✓ | ✓ | $4=p+q$ |
| $2$ | ✓ | ✓ | $4$ |
| $-1$ | ✓ | ✓ | $4$ |
| $0$ | ✓ | ✗（$\lambda=1$ 处秩降，专家 68/69 更正）| $3<4$（$\mathsf P_{\rm ind}$ 不合格）|

专家更正：$s=0$ 时铅笔本身在 $\lambda=1$ 处掉秩（子式 $\Delta_{12}=(\lambda-1)(\lambda-3)$、$\Delta_{13}=(\lambda-1)(\lambda-3)$、$\Delta_{23}=0$，$\gcd=\lambda-1$）。所以 $s\ne0$ 给出一个**真正的单参数可行族**：核固定、$H_A$ 随 $s$ 变、铅笔对所有 $\lambda$ 满秩。

## 意义

1. **绕过变量核障碍**：217–222 的“变量核脆弱/离散”不再阻挡——变量可以走**提升方向**；
2. **$D(X)$ 变量**：$H_A(s)$ 不是固定 $D$ 的像（$D$ 的第 3 行系数随 $s$ 变），符合专家 67 号“$D(X)$ 可变、但保持过滤/无特征向量”的建议；
3. **新杠杆**：$s$ 是提升参数，$\mathsf P_{\rm ind}$ 只要求 $s\ne0$（开条件）；要编码算术，需要让 $s$ 由另一条关系**强制**（例如两行共享同一 $s$，一致性给出 $s=xy$）。

## 进展

* 找到第一个固定核、变量 $H_A$ 的可行族；
* 确认 $d'_C>0$（$g=e_2$ 改变 $H_A$）是杠杆；
* 给出“如何编码算术”的明确下一步。

## 最终结论

* 变量不必进核；**提升方向**是可行的变量通道；
* 单门实现的下一步：设计两行共享提升参数 $s$，使一致性方程形如 $s=xy$；
* 这比重做变量核族更有希望。

## 放弃原因

* 尚未强制 $s=xy$；
* 未证 soundness/completeness；
* $s=0$ 的 $\mathsf P_{\rm ind}$ 资格问题需在 gadget 中排除（用 $s=xy$ + 另一条件）。

## 残留价值

* 一个可复用的固定核变量族；
* 明确的 $d'_C$ 杠杆；
* 为单门 gadget 提供新架构。
