## 压缩 gadget（无坏集）

$$H_0=\begin{bmatrix}z&x&0\\y&1&0\\0&0&1\end{bmatrix},\qquad
H_{A,0}=\begin{bmatrix}-2h_2+2h_3\\-2h_3\\0\end{bmatrix},$$
$h_2=(y,1,0)$、$h_3=(0,0,1)$。（530 落地的版本用 $+2h_3$；$d_{12}$ 相应为 $2(\lambda(x+1)+2)$。）

- $z=xy$ 时 $h_1=xh_2$，$H_{A,0}$ 的行都在 $\operatorname{span}\{h_2,h_3\}$ ⇒ $(5a)$ 成立；
- $z\ne xy$ 时 $\det H_0\ne0$ ⇒ $(5a)$ 自动成立；
- 门上三个 $2\times2$ 子式（在 $(h_2,h_3)$ 坐标里）：
  $$d_{12}=2\big(\lambda(x+1)+2\big),\qquad d_{13}=\lambda(\lambda x+2),\qquad d_{23}=\lambda^2 .$$
  $\gcd=1$：$d_{23}=0\Rightarrow\lambda=0$，而 $d_{12}(0)=4\ne0$。**对所有 $x$ 成立，无坏集**。

核验：$\gcd=1$、$\operatorname{rank}H_{A,0}=2$（sympy，符号 $x,y$）。

因此压缩层
$$\text{可行}\iff z=xy$$
（门外由 518 特征值障碍失败；门上 $(5b)$ 恒成立）。

## 落地障碍（$p=1$，$n=5$）

$p=1$ 时只有一行 $E$ 自由，$H_{A,0}=H_0A_{00}+u\,a$（秩 1 更新）。要得到上面的 $H_{A,0}$：

- 第 3 行为 $0$ ⇒ $h_3A_{00}+u_3a=0$；
- 第 2 行为 $-2h_3$ ⇒ $h_2A_{00}+u_2a=-2h_3$；
- 第 1 行含 $-2h_2-2h_3$，但 $h_1A_{00}=x\,h_2A_{00}$ 只能给出 $h_2A_{00}$ 的倍数，
  $u_1a$ 又必须与 $h_2A_{00}$ 线性相关——逐步代入得 $h_2A_{00}=0$，与第 2 行矛盾。

所以 $p=1$ 的 $n=5$ 族**不能**实现这个无坏集 $H_{A,0}$。
