# 540 非对角 $B$ 的第一例：resultant 不含 $u_3-u_1u_2$ 因子

> 2026-11-27。按 ChatGPT 的建议试 $A_0=\operatorname{diag}(0,1,0)$、
> $B=\begin{bmatrix}0&1&0\\0&0&1\\1&0&0\end{bmatrix}$（循环置换）。状态：**[精确符号计算]**。

## 计算

$H=[I_3;u;v]$、$H_A=[A_0;uB;vB]$，$P=\lambda H-H_A$，10 个非零的 $3\times3$ 子式。
对每一对子式计算 $\operatorname{Res}_\lambda$，检查是否被 $u_3-u_1u_2$ 整除
（用“代入 $u_3=u_1u_2$ 后为零”判定，因为 target 关于 $u_3$ 线性且系数为 1）。

结果：**没有**任何一对 resultant 在 $u_3=u_1u_2$ 上为零。

## 解释

- 该 $A_0,B$ 结构下，子式之间的公共根集合与 $u_3=u_1u_2$ 无关；
- 这与 538 的分次一致：对角/循环结构给的公共根条件仍是线性的；
- ChatGPT 的结构警告也成立：即便某个 resultant 含目标因子，也还要验证**其余**子式在门上无额外公共根。
