# 单门实现（五）：模板的单参数变形在 $t\ne0$ 处失败

> 2026-11-09。在 6 维模板上试最自然的变量变形：第二行改为 $e_2^*+t e_3^*$。
> 结果：$t=0$ 可行；$t=\pm1,2$ 时 $(5a)$ 仍成立但 $(5b)$ 失败。变量核在模板附近是**脆弱的**。
> 状态：**精确验证（4 点）+ 观察**。

## 目标

检验“在已验证模板上直接加变量”能否得到变量核的可行族。

## 设想与理由

模板（214）：$Ae_1=e_5$、$Ae_2=e_1$、$Ae_5=e_6$、$C=e_6^*$、$L_0=e_1^*$、
$L=[e_1^*;e_2^*;e_1^*+e_2^*+e_5^*]$，$H$ 核固定 $V=\operatorname{span}\{e_3,e_4\}$。
把第二行改为 $e_2^*+t e_3^*$，核应随 $t$ 变；检查 $(5a)(5b)$。

## 做法

用 `check_candidate`（有理精确）：
```
t=0 : (5a)=True, (5b)=True
t=1 : (5a)=True, (5b)=False
t=2 : (5a)=True, (5b)=False
t=-1: (5a)=True, (5b)=False
```
即：任意非零 $t$ 都破坏铅笔的常秩；$(5a)$ 不受影响。

## 进展

* 模板附近最自然的变量变形被 $(5b)$ 排除；
* 说明变量核不能靠在模板行上直接加参数得到。

## 最终结论

* 变量核需要在**结构层**（$A$ 的块、泄漏链、$D$ 的过滤）重新设计，而不是微调已验证的行；
* 与 217/218/219 的障碍一致：固定 $L_0$ 的变量核非常受约束。

## 放弃原因

* 只试了 4 个 $t$ 值（精确点，不是连续证明）；
* 未尝试其他行/其他模板；
* 未给出“所有 $t$ 失败”的证明。

## 残留价值

* 一个明确的失败实验；
* 支持“变量核脆弱”的判断；
* 提醒不要用微扰路线（专家 67 号也警告过）。
