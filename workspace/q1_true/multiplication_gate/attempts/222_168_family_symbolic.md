# 单门实现（七）：168 实例的变量核族符号化——只有 $t=0$ 可行

> 2026-11-09。把 221 的族 $V_t=\operatorname{span}\{e_4,e_5+t e_6\}$ 做成**符号**计算：
> 对一般 $t$ 求可容许行空间、铅笔子式 gcd。结果：$t\ne0$ 时 $\gcd=\lambda-1$（坏），
> $t=0$ 时 $\gcd=1$（好）。故该族上可行集是**孤立点**。状态：**符号证明（单族）**。

## 目标

严格判定 168 实例上 $V_t$ 族的可行 $t$。

## 设想与理由

对固定 $t$，可容许行空间 $\mathcal L_{V_t}=(V_t+A V_t)^\perp$（201）；取基后算
$H_A=LAN$、$P=\lambda H-H_A$ 的 $2\times2$ 子式 gcd。若 gcd 非常数则坏。

## 做法

sympy 计算 $\mathcal L_{V_t}$ 的零空间：基为
$$e_1,\qquad e_3,\qquad l_1=-2e_2-t e_5+e_6.$$
$e_1$ 是 $\ker\Psi$ 的不可见方向（$e_1N=e_1AN=0$）；有效行是 $e_3$ 与 $l_1$。
压缩：
$$h_0=e_3^*,\quad h_{A,0}=e_3^*;\qquad
h_1=(0,0,-t,1),\quad h_{A,1}=(0,0,-t,3).$$
铅笔的两行：
$$(\lambda-1)e_3^*,\qquad (0,0,-t(\lambda-1),\lambda-3).$$
$2\times2$ 子式：
$$-t(\lambda-1)^2,\qquad (\lambda-1)(\lambda-3),\qquad 0.$$
所以：
- $t\ne0$：$\gcd=\lambda-1$，在 $\lambda=1$ 处秩降 ⇒ **坏**；
- $t=0$：子式为 $0,(\lambda-1)(\lambda-3),0$，$\gcd=1$ ⇒ **好**。

这与 221 的数值检查（$t=\pm1,2$ 失败、$t=0$ 成功）完全一致，并且是**对所有 $t$** 的证明。

## 进展

* 168 实例的 $V_t$ 族被符号化解决：只有 $t=0$ 可行；
* 可行集在该族上是孤立点；
* 支持“可行核离散”猜想（但只证了一个族）。

## 最终结论

* 在 168 实例上，变量核的最自然方向**不给出连续可行族**；
* 若其他方向也如此，则“可行核离散”成立，算术 gadget 的 $V(X)$ 路线需要重新考虑；
* 需要检验更多族/给出一般定理。

## 放弃原因

* 只证了一个族；
* 未证明一般离散性；
* 未尝试其他实例。

## 残留价值

* 一个完整的符号族判据；
* 对离散性猜想的强证据；
* 可作为“刚性定理”的起点。
