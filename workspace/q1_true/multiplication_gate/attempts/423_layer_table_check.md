# 385 完整层表（含 $\omega=0$）：$r_0=0$ 恒可行的确认；布尔性门判定不变

> 承接 384（平凡层 $\omega=0$ 与 $r_0=0$ 恒可行）。本文件按专家 104 号的**层表纪律**做完整表，
> 复跑布尔性门与其去固定行变体，确认：**$\omega=0$ 那一行是判定的一部分**。

## 目标

1. 把可行性扫描改成**完整层表**（$\omega=0,1,2,\dots$，不静默跳过任何层）。
2. 复跑既有实例，确认 384 的解释与既有的"不可行"判定都成立。

## 设想与理由

判定是"**某层可行**"，所以表必须逐层给结论：

| 层 | 判据 |
|---|---|
| $\omega=0$ | 闭式：$L_0[N\ AN]=0$ 且 $n>d_0$ ⟹ 平凡可行 |
| $\omega\ge1$ | 在 $\operatorname{Gr}(\omega,k)$ 的坐标卡上逐 $W$ 验 (i) 相容、(ii) 秩补全、(iii) 生成铅笔 $\gcd=1$ |

## 做法

[c375](../../../../tools/verification/c375_layer_table.py)：对每层打印 `feasible` 与理由（**不跳过**），
最后给出总判定"某层可行=是/否"。

## 进展（结果）

**$r_0=1$（布尔性门）**

| $x$ | $\dim\mathcal S$ | $\omega=0$ | $\omega=1$ | $\omega=2$ | 判定 |
|---|---|---|---|---|---|
| $0$ | 4 | 0（$L_0$ 不消去） | **1**（一个 $W$） | 0 | **可行** ✓ |
| $1/2$ | 4 | 0 | 0 | 0 | **不可行** ✓ |
| $1$ | 3 | 0 | **1** | 0 | **可行** ✓ |

**$r_0=0$（固定行置零）**

| $x$ | $\omega=0$ | $\omega=1$ | $\omega=2$ | 判定 |
|---|---|---|---|---|
| $0$ | **1**（$\operatorname{ann}$ 平凡层） | 0 | 0 | 可行 |
| $1/2$ | **1** | 0 | 0 | 可行 |
| $1$ | **1** | 0 | 0 | 可行 |

## 最终结论

1. **$r_0=0$ 恒可行**——由 $\omega=0$ 平凡层，与 $x$ 无关 ✓（384 的预测被确认）；
2. **布尔性门的判定不变**：$x\in\{0,1\}$ 可行、$x=\tfrac12$ 不可行 ✓；
3. $\omega=2$ 在这两个实例里都不可行——$k=2$、$H$ 是 $2\times2$、$r=k$ ⟹ **方阵铅笔障碍** ✓；
4. **层表纪律的价值**：若只看 $\omega\ge1$，就会把 $r_0=0$ 的实例误判为"全不可行"；
   完整表（含 $\omega=0$）给出的是"**平凡可行**" ✓。

## 放弃原因

- 只在 $k=2$ 上跑；$\operatorname{Gr}(2,3)$ 等更大情形未跑；
- 未把"跳过任何层都要打印原因"写成工具里的**断言**（现在是打印，不是断言）；
- 未系统复查更早的扫描脚本（c362/c363/c365/c366）——其中 c366 明确处理了 $\omega=0$ ✓，其余需要逐个核对。

## 残留价值

- **一张可直接复核的表**，把"某层可行"的判定义务落到实处；
- 确认了平凡层的影响，并给出**归约必要条件**（$L_0$ 在 $K_0$ 上非零）；
- 专家强调的"层表纪律"在实现层落地。
