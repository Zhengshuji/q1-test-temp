# 515 五种 $l_1$ 形状的符号消元：都没有给出可用的门

> 2026-11-27。按 514 的下一步，对 $l_1$ 的候选形状做符号消元：
> 固定 $r_1=(1,0,0)$、$r_2=(1-y,0,1)$、$r_3=(p,q,r)$、$l_2=(a,b,c)$，
> 先解 $D_1|_{\rm gate}\equiv0$，再检查 $D_2$。状态：**[精确符号计算]**。

## 结果

| $l_1$ | $D_1$ 方程数 | 解 | $D_2$ |
|---|---|---|---|
| $(z,y,1)$ | 4 | 无 | — |
| $(z,0,x)$ | 2 | 族 1：$b=0,q=0$ | $D_2=0$（退化） |
| $(z,0,x)$ | 2 | 族 2：$b=aq/p,\ c=a(r-1)/p$ | $D_2=\frac{a^2q}{p^2}\big[qxy-px-q+(q+r-1)z\big]$ |
| $(z,1,x)$ | 5 | 无 | — |
| $(1,z,x)$ | 5 | 无 | — |
| $(z,y,x)$ | 7 | 无 | — |

## 分析

- 四个形状（$(z,y,1)$、$(z,1,x)$、$(1,z,x)$、$(z,y,x)$）的 $D_1|_{\rm gate}\equiv0$ 与 $l_2$ 常数**不相容**；
- $(z,0,x)$ 的族 1 使 $D_2\equiv0$，没有门；
- 族 2 的 $D_2$ 含 $x$ 项 $-\frac{a^2q}{p}x$，要等于 $c_0(z-xy)$ 需 $p=0$，但族 2 本身要求 $p\ne0$（分母）——矛盾。

所以这五种形状都没有给出可用的门。

## 下一步

- 允许 $l_2$ 或 $r_3$ 含 $x,y,z$ 的一次项（不只是常数）；
- 或改 $r_1,r_2$（例如 $r_2$ 不含 $1-y$）；
- 或接受固定行路线到此为止，回到自由行 + equality gadget。

## 状态

- 五种形状：**[精确符号计算]**（无可用门）；
- 一般 $l_1,l_2,r_i$：**[未穷尽]**。
