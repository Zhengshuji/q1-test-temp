## 做法：逐条裁决与落实

### 1. 六条裁决

| 断言 | 裁决 | 落实 |
|---|---|---|
| $\lambda=0$ 上界 $\operatorname{rank}H\le\dim(A K_0)$ | **正确**（建议显式写 $\operatorname{rank}(AN)=\dim(A K_0)$） | 354 已补 |
| 钉住引理 | **正确** | 不变 |
| Zariski 稠密 | **正确**（须指明域：复/实/有理） | 354 补"域"一段 |
| 极大性引理 | **正确，且是全文最强的一条**；他不建议当"已知定理"引用，保持自证 | 355 保留证明 |
| $d_0\le n-p$ | **正确**；但结论只能是"**逐行直接编码**无法忠实表示任意 $n$ 维载体行（$p\ge1$）"，**不是**一般不可行定理 | 352 收窄 |
| "钉住给仿射约束" | **需要更正**：$\mathcal L$ 给的是**线性（齐次）**限制，不是任意仿射约束；要模拟 $x_1+x_2=1$ 这种需要单独构造 | 353 更正 |

### 2. 更正一：$(\mathcal F=\mathcal L\cap\mathcal O)$ 需要固定行协调条件

他指出的缺口：$\mathcal L$ 只约束**自由行**，不保证固定行部分 $H_{A,0}=L_0AN$ 落在 $W_0$ 里。
若固定行违反 $(5a)$，则**无可行解**，而 $\mathcal L\cap\mathcal O$ 可能非空。
两种修法，他偏好 **Repair A**：把
$$\operatorname{row}H_{A,0}\subseteq W_0$$
作为**显式假设**。

**落实**：354 的定理加上这个假设，并把域说明补上（复/实/有理三点，见他的 §1.4）。

### 3. 更正二：极大性是"扩展极大"，不是"全局极大"

他给的区分（355 原先混在一起）：

| 概念 | 定义 | 我们证明了？ |
|---|---|---|
| **扩展极大** | 不能在**当前见证上**加一行使秩变大 | ✓ 极大性引理 |
| **秩极大** | 同一实例没有**别的**可行见证有更大秩 | ✗ |
| **包含极大**（可行行空间之间） | 没有严格更大的可行行空间包含当前 | ✓（扩展意义下）|

并给出修正后的逃逸分类：

| 逃逸方式 | 实际已确立的 |
|---|---|
| 加一行（$h\notin W$，保留旧见证） | **不可能**（引理 3） |
| 加一行（$h\in W$） | 不增秩，仍需单独检查可行性 |
| 换成一个**行空间更大**的**别的**可行见证 | **引理 3 没排除** |
| 缩小到更低秩层 | 除非被固定行的下界排除，否则可能 |
| 同秩换行空间 | **钉住时不可能**；秩 $>\omega_0$ 时**可能** |

**落实**：355 的标题与分类表按此改写；"逃逸只有缩小一条路"降级为
"引理 3 排除单调增秩扩展；钉住时无行空间移动；未钉住时'缩小'是已证实的逃逸机制之一，但不排除其它"。

### 4. 他给的可直接使用的定理（pinned no-go）

> **定理（pinned-instance no-go）.** 设
> 1. 实例钉住：$\dim(A K_0)=\operatorname{rank}H_0$；
> 2. 固定行协调：$\operatorname{row}H_{A,0}\subseteq\operatorname{row}H_0$；
> 3. 可行集非空；
> 4. 编码变量 $x,y,z$ 是自由行参数的**仿射线性**函数。
>
> 若 $z-xy$ 在**每个**可行见证上为零，则它在整个线性参数空间 $\mathcal L$ 上恒零。

证明：由修正后的定理 2，可行集在 $\mathcal L$ 中 Zariski 稠密；$f=z-xy$ 在可行集上为零 ⟹ 其零集（闭）含闭包 $=\mathcal L$。$\square$

**意义**：钉住实例**不可能用谱条件强加新的乘法恒等式**——任何这样的恒等式必须已经是线性参数化的推论。这是**可写入论文的负结果**（明确的 gadget 类）。

### 5. 候选线性原理（他给的下一个靶子）

> **Candidate linearity principle.** 固定 $(A,C,L_0)$ 与秩值 $\omega$。秩 $\omega$ 的可行轨迹的每个不可约分量上，
> 可行集要么空、要么在自由行参数空间的某个**线性子空间**中 Zariski 稠密。

若真：钉住不是孤例，**任何秩层都无法强加新的乘法恒等式**（在仿射线性解码下）；
若假：反例会指出乘法的几何机制。他建议**先在小维上精确算**（有理算术 + 符号消元），不要先攻一般证明。

### 6. 分阶段路线

1. **Stage 1**：把 pinned no-go 定稿（够用了）；
2. **Stage 2**：非钉住秩层的几何（主问题）；
3. **Stage 3**：全局秩极大的刻画；
4. **Stage 4**：再回到乘法——那时才决定造 gadget 还是证更广的 no-go。
