# 508 固定行构造的“一次项障碍”：为什么 $k=2$ 枚举 0 命中

> 2026-11-27。507b 的 0 命中不是偶然：固定行、$q=r_0$ 时 $(5a)$ 是
> $l_1AN\parallel l_1N$，其行列式条件对 $(l_1,A)$ 是双线性的；要产生 $z-xy$ 中的**一次项 $z$**，
> 需要一个因子为常数，这迫使 $A$ 的条目做除法。状态：**[已证-纸面]**（$k=2$ 的表述）。

## 设定

$k=2$、$N=I_2$、$L_0=[l_1;0]$、$H_0$ 秩 1，$(5a)\iff\det[l_1AN;\,l_1N]=0$：
$$D=\big(l_1A\big)_1 (l_1)_2-\big(l_1A\big)_2 (l_1)_1 .$$
$l_1$ 的条目与 $A$ 的条目都是输入变量的多项式（次数 $\le1$），故 $D$ 的每一项是
“$l_1$ 的一个条目 × $A$ 的一个条目 × $l_1$ 的另一个条目”，次数 $\le3$，但**至少含两个 $l_1$ 因子**。

## 观察

目标 $z-xy$ 的单项式是 $z$（一次）与 $xy$（二次）。
$D$ 中要出现一次项 $z$，必须有某个 $l_1$ 条目为常数且另一个因子恰为 $z$；这要求
$l_1A$ 的对应分量为常数——解 $l_1A=e_j$ 需要 $A$ 的条目含 $1/l_1$，**不是多项式**。

所以 $k=2$ 的固定行构造不可能给出 $D=c(z-xy)$；507b 的 0 命中与此一致。

## 推论与下一步

- 固定行（无自由行）路线要产生一次项，必须允许 $l_1$ 或 $A$ 的条目**非常数**（例如 $A$ 含 $1/z$），
  或改用**两行都非零、但 $H_0$ rank 1** 的构造（此时 $(5a)$ 不是单个 $2\times2$ 行列式）；
- 更现实的方向仍是回到“自由行 + equality gadget”：让门变量由 $A$ 控制（输入），
  自由行只提供 $(5a)$ 的偏移。
