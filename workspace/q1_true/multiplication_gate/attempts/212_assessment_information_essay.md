## 做法：逐部分评估

### 1. 信息论部分（信息充分性、信息维数、动态压缩）

- 对确定性线性系统 $x\in\mathbb R^n$，Shannon 微分熵/信息维数在无概率分布时没有定义；
  文稿把“信息量”与“动态维数”类比，但没有给出概率空间或可计算的定义；
- “下界一定可实现”是断言，没有证明；
- 因此：**不构成定理**，只能作为研究方向的口号。

### 2. PBH 商空间重述

- 命题 1（谱条件 ⇔ 商空间铅笔 $(\lambda J_Z-\overline A_Z)$ 满列秩）在数学上是**正确**的，
  但本质上是把项目的压缩铅笔 $P(\lambda)=\lambda H-H_A$ 换到商空间坐标；与 B.4/191 的块判据等价；
- 作为**表述**（把谱条件讲成 PBH 可观测性）有价值，但不是新定理，也不直接推进 $q1$。

### 3. Hankel 秩分解

- $q=\operatorname{rank}\mathscr H_s(\mathcal Z)+\dim\ker C/(\mathcal U+\mathcal Z)$ 是**定义式/断言**，
  没有证明；其中 $s=\operatorname{rank}\mathscr H_s$ 的“可实现性”也未证；
- 与可观性指数/Hankel 秩的经典结果可能相关，但文稿没有给出严格推导；
- 作为“下界”方向的启发可以，但不能直接采用。

### 4. 数值例子

- $n=8,p=2,r=2$、$q_0=3$、$\nu_{\min}=5$ 与 Fernando 的例子一致；
- 文稿的计算是说明性的，不是新证明。
