# 362 新架构第一块砖：非空性条件可以 **AND 组合**（块对角直和）

> 承接 361（架构诊断：变量应进 $(A,C,L_0)$，$R$ 只当见证）与 360（99 号建议"不用乘法门的归约"）。
> 本文件检验搭归约的第一块砖：**"可行"（非空性）能否做 AND 组合**。
> 结论：**能**（在块对角直和、且 $C$ 正确堆叠时），有显式见证。

## 目标

判断：给定两个"非空性条件"实例（各自"可行 $\iff$ 条件成立"），它们的块对角直和是否
"可行 $\iff$ 两个条件同时成立"。

## 设想与理由

361 说 $R$ 这一侧只能提供非空性。那么归约要么只用**一个**条件（太弱），要么必须能**组合**条件。
最自然的组合是直和——但 297 号的"直和 unsound"曾否定过它。**注意那是在旧范式（变量在 $R$ 里）**；
新范式下变量在 $(A,C,L_0)$ 里，两块的条件由各自的实例数据决定，$R$ 只是共同的见证。

所以值得重测——而且要当心一个**构造陷阱**（本轮真踩了）：

> $C$ 必须**堆叠**成块对角（两行），不能把两个 $1\times3$ 的 $C$ 拼成 $1\times6$。
> 否则 $C=[0,0,1,0,0,1]$ 会**耦合**两块，$K_0=\ker[C;CA]$ 变成 4 维、条件不再可分。

## 做法

每块用 303C 的输入非零门（变量 $x$ 在 $A$ 里，块内可行 $\iff x\ne0$）：
$$C_i=[0\ 0\ 1],\quad A_i(x)=\begin{pmatrix}0&0&0\\x&0&0\\0&1&0\end{pmatrix},\quad L_{0,i}=[1\ 0\ 0].$$

直和：
$$C=\begin{pmatrix}C_1&0\\0&C_2\end{pmatrix}\ (2\times6),\qquad A=\operatorname{diag}(A_1(x_1),A_2(x_2)),\qquad L_0=[L_{0,1}\ L_{0,2}].$$

对 $(x_1,x_2)\in\{0,1\}^2$，采样自由行 $R$（$2\times6$，条目 $\in\{-2,\dots,2\}$，每个情形 3000 次），
检验 $(5a)(5b)$。

## 进展（结果）

**两块**（$m=2$）：

| $(x_1,x_2)$ | 直和可行 | 期望 |
|---|---|---|
| $(0,0)$ | 否 | 否 ✓ |
| $(0,1)$ | 否 | 否 ✓ |
| $(1,0)$ | 否 | 否 ✓ |
| $(1,1)$ | **是**（$\omega=2$） | 是 ✓ |

见证：$R=\begin{pmatrix}-2&1&-2&2&-2&0\\0&-2&-2&-1&1&2\end{pmatrix}$（$\gcd\equiv1$）。

**三块**（$m=3$ 与 $m=2$ 都测了）：

| $x$ | 可行 | 期望 |
|---|---|---|
| $(1,1,1)$，$m=3$ | **是**（$\omega=3$） | 是 ✓ |
| $(1,1,0)$ | 否 | 否 ✓ |
| $(0,0,1)$ | 否 | 否 ✓ |
| $(1,1,1)$，$m=2$ | **是**（层号更低，$\omega=2$） | 是 ✓ |

**一处自我更正**：我一度从 $\lambda=0$ 的秩计数推出"必须 $m\ge$ 块数"，并据此判三块 $(1,1,1)$ 不可行——
**错了**。那只是采样太稀（101 个层点）；加大到 279 个层点后找到了见证。
真实情形是：**$m$ 决定落在哪一层**（$m=2$ 时三块的可行层是 $\omega=2$，不是顶层的 3），
而不是"块数超过 $m$ 就不可行"。

**构造陷阱**（这条仍然成立）：$C$ 若拼成 $1\times6$（而不是堆叠成 $2\times6$），
$K_0$ 会被耦合（$k=4$、$H_0=[1,1,0,0]$、样本 $\gcd\equiv\lambda^3$），**所有情形**都判不可行。

**工具说明**：以上由 Matlab R2023b（Symbolic）跑，脚本
[c362_and_composition.m](../../../../tools/verification/c362_and_composition.m)——
先做数值预筛（少数几个 $\lambda$ 上验秩），只对候选做精确 $\gcd$，比纯符号循环快很多。

## 最终结论

1. **AND 组合可行**（2 块与 3 块都有精确见证），机制是**块对角直和 + 堆叠的 $C$**；
2. 这推翻了"直和一定 unsound"的旧印象（那条属于**旧范式**：变量在 $R$ 里）；
3. 新架构至少有了第一块砖：**合取 = 块对角直和**；
4. $m$ 的作用是**选择层**，不是可行性开关。

## 放弃原因

- **只验证了"可行"的方向**（找到见证）；"不可行"是 3000 次搜索未找到，**不是证明**；
- 没有证明两个方向：
  - (⇐) 两块都可行 ⟹ 直和可行（直觉：把两块各自的见证放进同一 $R$ 的块分量里，
    因为 $\mathcal T=\mathcal T_1\oplus\mathcal T_2$）；
  - (⇒) 直和可行 ⟹ 两块都可行（**这是 soundness，真正需要证的方向**）；
- 没有做三块以上的检验；
- 没有考虑 OR / NOT（若只有 AND 与常量，表达力可能不够）。

## 残留价值

- **一个正面的、可复现的组合机制**（块对角直和 + 正确堆叠的 $C$）；
- 一个**构造陷阱**的记录（$C$ 拼 vs 堆叠），避免后来者重复踩；
- 明确的两个待证方向——其中 (⇒) 是 soundness 的关键。

## 下一步

1. 证明 (⇐) 与 (⇒)（(⇒) 可以尝试从"块列独立 + 铅笔秩可加"入手，或用 $c=1$ 线里那套 $\lambda=0$ 界的工具）；
2. 若 (⇒) 不成立，找反例并记录（那会说明直和不可用于 AND）；
3. 之后再看 OR / 否定：非空性天然给"存在"，负条件需要"不可行 $\iff$ …"，那是另一块砖。
