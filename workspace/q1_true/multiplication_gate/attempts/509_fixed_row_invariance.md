# 509 固定行 $q=r_0$ 的精确刻画：$(5a)\iff$ 压缩行空间在 $A$ 下不变

## 刻画

$q=r_0$（无自由行）、$N=I_k$（$K_0$ 为坐标子空间）。则
$$H_0=L_0[:,1..k],\qquad H_{A,0}=(L_0A)[:,1..k].$$
$(5a)$ 即
$$\operatorname{row}\big((L_0A)[:,1..k]\big)\subseteq\operatorname{row}\big(L_0[:,1..k]\big).$$
记 $P=\operatorname{row}(L_0[:,1..k])$；若 $L_0$ 的前 $k$ 列行满秩，则条件等价于
$P$ 在右乘 $A$ 下不变（在压缩坐标里）。

## $H_0$ rank 1 不提供新东西

若 $\operatorname{rank}H_0=1$，则 $L_0$ 的所有行在压缩坐标里都是同一个 $l_1$ 的倍数，
$H_{A,0}$ 的行也都是 $l_1AN$ 的倍数。于是 $(5a)\iff l_1AN\in\operatorname{span}(l_1N)$——
与 508 的 $k=2$ 情形完全相同。**所以“两行都非零但 $H_0$ rank 1”没有绕开一次项障碍。**

## $H_0$ rank $\ge2$：新的可能

若 $\operatorname{rank}H_0=2$（$r_0=2$、$k\ge3$），条件是两条线性方程（每行 $H_{A,0}$ 落在 2 维平面 $P$ 里），
即三个 $3\times3$ 行列式为零。每个行列式是 $L_0$ 条目（一次）与 $A$ 条目（一次）的乘积之和，
次数可达 3——**可以出现 $z-xy$ 这样的二次式**。

## 一个立即的观察：$z$ 容易在两边抵消

取 $L_0=[e_1;\,(z,y,1)]$、$A$ 的第一行为 $(0,y,1)$（使 $e_1A\in P$）。则 $z$ 通过 $z\cdot A_{1j}$
在条件两边同时出现并抵消（见 507b 后的手算）。要用 $z$ 做门，必须让 $z$ 只出现在**一侧**的行里，
例如 $z$ 只出现在 $L_0$ 的第一行、而 $A$ 的第一行不含常数项。

判据是“$(5a)$ 的多项式 $\equiv c\,(z-xy)$”；先限制 $L_0$ 每行支撑 $\le2$、$A$ 每行支撑 $\le2$。
