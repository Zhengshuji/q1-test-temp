# 两副本直和实验：阶差在第一个测试上可加（$q_0$ 与 $q_{\min}$ 都加倍）

## 目标

专家 2026-11-04 §8 第三项、§Q4：把 gap-2 实例与自身作直和，检验
* **Lemma B（上界可加）**：块对角增广应可行；
* **Lemma A（下界可加，难点）**：是否存在**混合**（非块对角）增广以更低阶越过障碍。

## 设想与理由

若"最小可行阶"在直和下可加，则 $k$ 个 gap-2 副本应给出阶差 $2k$——这是构造**任意阶差**的最直接方式
（专家 §Q4）。可加性拆成两条：上界（块对角增广可行，容易）与下界（任何可行增广必须"按块贡献"，
难点在于排除**混合**增广：它的行可以混用两个副本的状态坐标）。

## 做法

把 gap-2 实例与自身作直和，逐阶（$q=q_0..n_0-p$）在图卡上采样（稠密网格 + 随机 $	heta$），
用 B.12 可观性检验判 $(5b)$；并显式构造块对角见证以核上界。

## 构造

$$A=A_1\oplus A_1\ (12\times12),\qquad C=\operatorname{diag}(C_1,C_1)\ (4\times12),\qquad
L_0=\operatorname{diag}(L_{0,1},L_{0,1})\ (4\times12).$$

单副本：$n=6$、$p=r=2$、$q_0=2$、$q_{\min}=4$（阶差 2）。

## 进展

| 量 | 直和实例 | 期望（若可加）|
|---|---|---|
| 可观测指数 $n_0$ | 12 | — |
| 代数最小阶 $q_0$ | **4** | $2+2=4$ ✓ |
| 阶区间 | $[4,8]$ | — |
| 块对角增广（$4+4=8$ 行）| $(5a)$ ✓、$(5b)$ ✓ | Lemma B ✓ |
| $q=4$ 阶可行 | **0 / 120** | 0 |
| $q=5$ 阶可行 | **0 / 480** | 0 |
| $q=6$ 阶可行 | **0 / 720** | 0 |
| $q=7$ 阶可行 | **0 / 500**（稠密网格 $\theta\in\{-2..2\}^3$，4 张卡）| 0 |
| $q=8$ 阶 | 可行（块对角见证）| ✓ |

即
$$\boxed{q_{\min}(\text{1}\oplus\text{2})=8=q_{\min}(1)+q_{\min}(2),\qquad \text{阶差}=4=2+2}$$
在**第一个两副本测试**上，阶差可加；且 $q<8$ 的 1820 个候选（含稠密网格）里**没有**找到混合增广。

## 最终结论

1. **Lemma B（上界可加）**：已核实（块对角构造，$(5a)(5b)$ 都通过）；
2. **Lemma A（下界可加）**：两副本上有**强证据**——$q=4,5,6,7$ 共 1820 个候选无可行点；
   但仍是**采样**证据，不是证明（要证必须排除一切混合增广，专家说这是难点）；
3. $q_0$ 也加倍（$4=2+2$），与"$\eta$ 在直和下相加"的预期一致；
4. **未发现**专家预言的"混合增广揭示新机制"——在本次搜索范围内，混合增广没有优势。

## 放弃原因

不适用（实验完成；Lemma A 的证明留作下一步）。

## 残留价值

* 阶差可加的**第一个数据点**（gap 2+2=4），并给出可复现脚本；
* 一个明确的下界证明目标：**排除混合增广**（等价于说：任何可行 $\mathcal L$ 必须"按块贡献"）；
* 若今后要找混合增广的反例，本脚本（稠密网格 + 随机）是最好的搜索起点。
