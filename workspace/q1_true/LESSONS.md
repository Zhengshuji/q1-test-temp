# q1_true · 经验记录

> 给下一个做硬度的人/子 agent：这些是已经踩过的坑，别再重复。

## 死路（不要重走）

1. **拟阵 / TAP（树增广）**：$(T)$ 有反例 + 圈空间不可实现。
2. **min-rank / 覆盖 / 反馈设计**：落在公开的 min-rank $k=1$ 问题上。
3. **谱切割 / $\mathbb F_p$ 伪影**：小素数上的构造不能提升到 $\mathbb Q/\mathbb C$。
4. **图归约（CYCLIC-COVER）**：与拟阵同源。
5. **条件乘法门（234/239）**：漏了 $L_0A$；补上后 $(5b)$ 恒有复根，无可行 $L$。
6. **rank 门**：$q=4$ 的 rank-one 门在压缩层成立但不可逐行提升；$q=5$ 只是 2000 例搜索边界，不是关闭定理。

## 有效做法

1. **逐行提升判据**：任何压缩门先检查 $(H_i,H_{A,i})\in\operatorname{row}[N\ AN]$；$[N\ AN]$ 秩 $\le n-p<n$，永不满射。
2. **soundness 三分**：C（completeness）、S（所有可行 $R$ 解码）、R（强制秩层）。
3. **复制整行会引入 $y_1=1$**：需要 copy/format gadget，不是直接复制。
4. **先查 q1_false 的 LESSONS**：层语言的负结果常能直接排除一类门。

## 判定“是不是定理”的底线

- 压缩层成立 $\ne$ 观测器层成立（必须逐行提升）；
- 搜索不到 $\ne$ 不存在；
- 只有在**所有**可行 $R$ 上都强制同一条件（S）且能解码（C）时，才叫 sound 归约。
