# arm_reduction · 经验

1. 先做“一个 gate 的翻译”，不要一上来写完整归约。
2. 压缩层的约束是行空间型/二次型；ARM 的仿射约束不能直接照搬。
3. 任何翻译都要过 S（所有可行 $R$ 解码）与 C（completeness）两条义务。
4. **载体界 $d_0\le n-p$** 是硬约束：逐行忠实编码任意 $n$ 维载体不可能，别再试。
5. **不要再泛化乘法门 gadget**（2026-11-27 评估）：乘法 gadget 已 unsound；只做
   $X=[L;L_{\rm fix}]$ 行包含接口的短程检验，失败就写该接口的 no-go。
